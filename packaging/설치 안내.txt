치지직 보관함 0.16.0 · macOS Apple Silicon 로컬 검증 버전

1. 치지직 보관함.app을 응용 프로그램 폴더로 복사합니다.
   현재 사용자만 설치하려면 홈 폴더의 Applications(~/Applications)에 복사해도 됩니다.
2. 복사한 앱을 실행하면 작은 실행 창과 브라우저 보관함이 열립니다.
3. 기존 보관함은 ‘가져오기 → 저장 폴더 → VOD 보관함 폴더 → 폴더 확인’으로 엽니다.
   선택한 상위 폴더는 다음 앱 실행에 유지됩니다.
4. 브라우저 탭을 닫아도 다운로드·분석은 계속됩니다.
   끝낼 때는 앱 실행 창의 ‘작업 정리 후 종료’ 또는 Command+Q를 사용합니다.
5. 앱 교체 전에 종료하고 새 앱으로 바꾸세요. VOD 폴더·모델 캐시·설정을 삭제하지 않습니다.

Python·yt-dlp·FFmpeg/ffprobe·whisper-cli·llama.cpp·화자·SAM·BS-Roformer 도구가 포함됩니다.
음성 모델은 앱 밖 사용자 캐시에 별도로 준비합니다. 기존 검증 모델은 재사용합니다.
기본 보관함: ~/Movies/치지직 보관함
로그: ~/Library/Logs/치지직 보관함
설정: ~/Library/Application Support/치지직 보관함
모델: ~/Library/Caches/chzzk-archive

이 패키지는 임시 서명만 되어 있으며 Developer ID 서명과 Apple 공증은 없습니다.
현재 Mac에서 직접 만든 패키지의 로컬 실행을 검증했습니다. 인터넷으로 받은 다른 Mac에서는
Gatekeeper가 차단할 수 있습니다. 차단되면 보호 기능을 끄지 말고 서명·공증된 배포본을 사용하세요.
macOS 27.0.1 / M1 Pro에서 검증했습니다. Windows·Intel Mac·다른 macOS는 미검증입니다.

구성요소 조건은 앱 Contents/Resources/안내에 있습니다.
외부 공개 배포용 대응 소스 전체와 서명·공증 준비는 아직 완료되지 않았습니다.

이번 버전은 DMG 없이 앱 패키지만 제공합니다.
VOD 삭제는 해당 폴더 전체를 휴지통으로 옮깁니다. 공용 모델 캐시는 유지됩니다.
별도 AI 문맥 정리는 Gemma 4 E4B·사고 켜기를 기본으로 로컬에서 실행합니다.
SAM·BS 전체 분리/전사/화자 분석은 최대 20시간을 지원하도록 구성했습니다.
20시간 전체 AI 처리와 정확도는 미검증이며 선택 구간 음원 비교는 1초~5분입니다.
20시간 분리용 여유 공간은 영상·모델과 별도로 BS 약 130GB, SAM 약 86GB 이상 필요합니다.

공용 AI 모델 경로도 가져오기 → 저장 폴더에서 확인·변경합니다.
기존 모델을 자동으로 이동하지 않습니다. 복사한 폴더를 지정하거나 새 위치에서 모델을 준비하세요.
작업 중에는 모델 경로를 변경할 수 없습니다. 다음 앱 실행에도 선택 경로가 유지됩니다.
