# GitHub 배포용 기본 패키지

`docs/GitHub-빌드-배포.md`의 순서로 각 운영체제에서 빌드합니다. 기존 `packaging/backend.spec`, `build_macos.py`는 로컬 전체 엔진 패키지용으로 유지하며 이번 기본 배포에서는 이 폴더의 별도 spec을 사용합니다.

모델, 개발 가상환경, 개인 보관함, 자격증명, 이전 앱 패키지는 업로드하지 않습니다. `sources.json`의 해시가 다르면 빌드를 중단합니다. 모든 빌드 및 앱의 상태 자료는 `build`, `dist`, 사용자 보관함에 저장하며 원본 소스와 분리합니다.
