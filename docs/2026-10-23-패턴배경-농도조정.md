# 패턴 배경 농도 조정

작업일: 2026-10-23

사용자가 패턴 배경이 너무 연하다고 피드백하여 앱과 HTML 매뉴얼의 공통 CSS 불투명도를 12%에서 28%로 높였다. 이미지 파일과 용량, 8종 무작위 선택 방식, 반복 크기는 그대로다.

## 변경 범위와 영향

- `pattern-background.css`의 `body::before` 불투명도 한 줄 변경.
- 개발 앱·로컬 매뉴얼·GitHub 앱 소스·공개 매뉴얼에 같은 값 반영.
- 흰색 본문 카드·입력창과 기존 클릭 처리 유지. 인쇄·강제 고대비에서는 계속 배경을 숨긴다.
- 이미지 원본, 저장된 VOD와 분석 결과에는 영향 없음. 배포 이미지의 전체 용량은 183,728바이트로 동일하다.
- 패턴 대비가 높아져 여백의 장식이 더 눈에 띈다. 검은 본문 글자와 흰색 카드로 내용을 구분한다.

## 확인

- 실제 macOS 내부 브라우저에서 앱을 새로고침해 뿔·꽃가지 패턴의 윤곽과 본문 가독성을 확인했다.
- 8종 무작위 선택·로컬 자원 검사, 매뉴얼 정합성 검사와 Git 공백 오류 검사를 수행했다.
- 공개 매뉴얼 게시 [39925025221](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/39925025221) 성공. 게시 커밋은 `b24649fc8e446f3daca415b1193808c70ceb3545`이며, 실제 페이지를 새로고침해 4번 모자·리본 패턴이 더 진하게 표시되고 흰색 설명 카드의 가독성이 유지되는 것을 확인했다.

이번 요청은 표시 농도 수정으로 처리했다. 앱 패키지를 새로 만들지는 않으며, 직전 다운로드 ZIP에는 12% 설정이 남아 있다. 다음 빌드부터 28% 설정이 포함된다. 실행 중인 개발 앱은 새로고침하면 바로 반영된다.
