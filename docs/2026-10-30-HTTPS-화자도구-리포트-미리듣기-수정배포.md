# HTTPS·Windows 화자 도구·사양 리포트·미리듣기 수정

## 범위와 보존

2026-10-30 Windows 지원 재점검의 네 항목을 수정한다. 기존 VOD 영상·채팅·전사·화자 배정·문맥 결과·편집 초안을 변경하지 않는다. 기존 화자 모델과 설치 버전도 남긴다. 검증은 별도의 합성 자료와 임시 폴더에서 진행하며 사용자 보관함을 실행 대상으로 사용하지 않는다.

## 변경

- Windows FFmpeg는 Schannel, macOS FFmpeg는 SecureTransport를 명시한다. 원격 구간 수신은 인증서 검증을 켠다. 단순 프로토콜 목록 검사 외에 공개된 동일 커밋의 4초 합성 영상을 HTTPS로 받아 1~3초 구간 생성·전체 디코드를 검사한다.
- FFmpeg 오류는 프로토콜 미지원·인증서·공간 부족·시간 초과를 구별하고 로그의 전체 경로를 안내한다. 서명된 영상 URL이나 로그 본문은 화면에 노출하지 않는다.
- Windows sherpa·pyannote 실행 도구를 별도 ZIP으로 빌드한다. pyannote는 본체 NumPy 환경과 분리된 PyTorch CPU 전용 환경을 사용한다. 기존 macOS 도구는 교체하지 않는다. 앱 설치기의 SHA-256 검사, 검사 완료 후 활성화, 기존 모델·결과·이전 버전 보존을 실제 ZIP으로 검증한다.
- Windows 사양 조회는 절대 경로의 시스템 PowerShell을 사용한다. 기존 패키지 PATH 제한은 유지하며 UTF-8 출력을 명시한다. 조회가 거부되면 미확인 값으로 남기고 과거 리포트를 다시 쓰지 않는다.
- 선택 오디오 미리듣기는 HTTP 전송 중 파일을 유지하고 캐시 교체·종료 시 삭제를 유예한다. Windows 파일 점유로 삭제가 거부돼도 새 미리듣기 파일과 캐시 목록이 손상되지 않도록 했다.

## 예외·영향

- 인증서 검증 실패를 우회하지 않는다. 시스템 시각·인증서·네트워크 문제는 오류와 로그 경로로 확인한다.
- FluidAudio는 계속 macOS Apple Silicon 전용이다. pyannote의 Community-1 모델 이용 동의·HF 인증과 모델 다운로드는 실행 도구 설치와 별도다.
- 다른 프로그램이 임시 미리듣기 파일을 계속 잡고 있으면 OS 임시 폴더에 파일이 남을 수 있다. 원본·분할 결과는 정리 대상이 아니다.
- GPU 없는 CI의 통과는 Windows NVIDIA GPU 추론이나 사용자 PC 전체 GUI 검증을 뜻하지 않는다.

## 검증 진행

- 신규 사양 조회·캐시 검사 10개: macOS 9개 통과, Windows 열린 파일 전용 1개는 Windows CI에서 실행 예정.
- HTTPS 관련 단위·범위 보존 검사 14개 통과(HTTPS 실제 수신은 공개 커밋 이후 CI 진행).
- Python 3.11 로컬 배포 환경에는 현재 FontTools가 없어 전체 검사 환경으로 사용할 수 없었다. 의존성이 갖춰진 개발 환경으로 회귀 검사하며, 실제 패키지는 Python 3.11 CI에서 검증한다.
- 두 OS 빌드, Windows 실행 도구 설치 검사, 배포 ZIP 무결성, 공개 자산 확인: 진행 중. 완료 결과와 링크를 아래에 추가한다.
