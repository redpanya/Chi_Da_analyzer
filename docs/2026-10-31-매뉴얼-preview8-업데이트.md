## 원본·공개 범위와 영향

- 앱 소스·설정·실제 보관함·모델·기존 분석 결과를 변경하지 않았다. 앱 패키징도 하지 않았다.
- 별도 임시 보관함에 60초 테스트 영상·2개 오디오 트랙·가상 전사·가상 결과를 만들어 촬영했다. 화면이 실제 AI 처리 결과나 성능 실측으로 읽히지 않도록 명시했다.
- 공개 이미지에 실제 사용자 경로·VOD 제목·채팅·전사 원문·인증 토큰을 넣지 않았다. 예시 경로는 임시 촬영 자료 경로이다.
- 이미지 원본을 수정하지 않고 설명별 크롭·강조 영역을 사용한다. 기존 스크린샷·배경 원본은 보존했다.
- 외부 AI 전송과 오류 JSON 이메일은 사용자가 직접 보내는 절차로 설명했다. 로컬 처리와 외부 전송을 구분했다.
- 기존 주요 장 앵커를 유지했다. 항목별 번호 앵커는 내용 재구성에 따라 달라질 수 있으므로 공유 링크는 장 앵커를 권장한다.

## 확인 결과

- 생성기: 13개 주제·83개 안내 생성.
- 정합성 검사: 기본 펼침 83개, 설명별 이미지 37개, 중복 ID·깨진 내부 링크·필수 자원 누락 없음. 원본/크롭/강조 경계 및 배경 캐시 해시 통과.
- 자바스크립트 문법 검사 통과.
- 내부 브라우저: 검색어 `오디오 트랙` 3건, `PNG` 3건, 없는 검색어의 빈 상태 표시 확인. 전체 접기 0개 → 전체 펼치기 83개 확인.
- 이미지 확대·닫기, 설명에 맞는 크롭 표시 확인. 로드된 이미지 오류 없음.
- 현재 소스 UI와 구현 기록을 대조했다. 전사 모델은 선택 드롭다운이 아닌 기본 모델 준비 과정, 댓글 시간은 별도 편집창, 자막의 글꼴과 색상 템플릿은 독립 설정으로 정리했다.
- 앱의 전사·LLM·장시간 처리나 Windows 실기기 전체 검증은 이번 문서 작업에서 수행하지 않았다. 이미지의 가상 결과를 그 검증의 근거로 사용하지 않는다.
