# 다운로드·검증 완료 후 음성 추출 상태 갱신 수정

## 요청과 범위

- 영상 다운로드·검증이 끝났는데 음성 추출 화면에서는 새로고침해야 완료 상태를 인식하는 문제를 수정했다.
- 로컬 개발 소스와 GitHub용 로컬 작업본에 같은 수정 내용을 반영한다. 앱 빌드·패키징·GitHub 푸시·Actions 실행은 하지 않는다.
- 영상·채팅·추출 음성·전사·수동 교정·화자 배정·요약 등 사용자 자료는 읽거나 변경하지 않는다.

## 확인한 원인

`web/app.js`는 1초 간격으로 프로젝트 상태를 받아 `speech.setProject()`에 전달한다. 그러나 `web/speech.js`는 VOD 전환, 모델 경로 변경, 음성 작업 종료 등의 경우에만 `speech-info`를 조회하고, **영상 작업의 다운로드·검증 완료 전환을 갱신 조건에 포함하지 않았다.**

처음 프로젝트를 열 때 영상이 준비되지 않았다면 서버의 `speech_media.source()`가 `영상 다운로드와 검사를 먼저 완료하세요` 오류를 반환한다. 이후 영상 상태가 `complete`로 바뀌어도 오디오 트랙 정보가 없는 상태가 유지되어 추출 버튼이 비활성화될 수 있었다. 페이지를 새로고침하면 프로젝트를 새로 여는 경로로 정보를 다시 조회하므로 버튼이 활성화됐다.

특정 VOD나 운영체제에 대한 예외가 아니라, 완료 전환을 감지하지 못하는 공통 프런트엔드 문제다. 자동 검사에서 수정 전 코드는 ‘검증 완료 후 음성 추출이 자동 활성화되어야 함’ 조건에 실패했다.

## 수정 내용

1. 영상 작업 상태 또는 재생 파일 경로가 바뀌면 음성 입력 정보를 갱신한다.
2. 영상이 `complete`가 되기 전에는 `speech-info`를 호출하지 않고 대기 안내와 비활성 버튼을 표시한다. 완료를 수신하면 자동으로 오디오 트랙·모델 정보를 확인한다.
3. 재조회 중에는 이전 입력 정보를 무효화하고 추출·전사 시작을 막는다. 조회 요청 번호를 대조하여 같은 VOD에서 먼저 보낸 요청의 성공·실패 응답이 최신 상태를 덮어쓰지 않도록 한다.
4. 기존 VOD 전환용 세대 번호 검사도 유지하여 다른 VOD 또는 선택 해제 뒤의 응답을 무시한다.
5. 영상 상태와 경로가 그대로인 일반 진행 폴링에는 추가 조회를 보내지 않는다. 전사 옵션·용어 힌트도 초기화하지 않는다.

백엔드의 영상 검증 기준과 자료 저장 형식은 바꾸지 않았다. 이미 처리 중인 작업을 중복 시작하지 못하도록 하는 `project.locked` 검사도 유지한다.

## 영향과 예외 처리

- 다운로드뿐 아니라 로컬 비디오 가져오기도 같은 영상 상태 계약을 사용하므로 동일한 갱신 조건을 적용한다. 실제 로컬 파일 가져오기 전체 실행은 이번 확인 범위에 포함하지 않았다.
- 영상 완료 후 채팅 등 다른 작업이 보관함을 잠그고 있다면 추출 버튼은 잠금이 풀릴 때까지 비활성 상태를 유지한다.
- 재검증·파일 교체 시 정보 조회가 끝날 때까지 버튼이 잠시 비활성화될 수 있다. 오래된 트랙 정보로 추출을 시작하지 않기 위한 동작이다.
- 실제 조회 실패나 오디오 트랙 없는 영상은 계속 오류·안내를 표시하며 추출을 허용하지 않는다. 완료 여부를 강제로 바꾸거나 검증을 생략하지 않는다.
- 해당 VOD에서 조회가 실제로 실패한 경우 무한 자동 재시도를 추가하지 않았다. 원인 해결 후 프로젝트를 다시 열면 정보를 재조회한다.
- 현재 설치된 앱·배포 ZIP은 변경하지 않았다. 이번 수정은 소스 실행 또는 이후 별도로 만드는 빌드에 적용된다.

## 검증 결과

macOS에서 Node.js를 사용해 관련 GUI 모듈만 확인했다. 실제 네트워크 다운로드·모델 추론·미디어 파일 처리 없이 모의 API 응답과 DOM으로 상태 전환을 검사했다.

| --- | --- |
| 수정 전 `test_speech_readiness.mjs` 실행 | 다운로드·검증 완료 후 추출 버튼 비활성 문제 재현 |
| 수정 후 `node tests/test_speech_readiness.mjs` | 통과 |
| 다운로드 → 검증 → 완료, 새로고침 없는 추출 시작 | 통과 |
| 일반 진행 폴링에서 정보 조회 반복 방지 | 통과 |
| 채팅 등 작업 잠금 유지 및 해제 반영 | 통과 |
| 같은 VOD의 재검증·파일 교체 중 늦은 성공/오류 응답 무시 | 통과 |
| 다른 VOD 전환·선택 해제 뒤 응답 무시 | 통과 |

기존 `test_speech_ui.mjs`에는 현재 앱에서 제거된 상시 안내 요소 `speech-vad-hint`를 참조하는 오래된 검사가 있었다. 이번 수정 전 GitHub용 로컬 원본에서도 같은 실패를 확인했다. 이 검사를 현재 도움말 오버레이의 선택값 표시 검사로 바꾸고, 모의 프로젝트에 실제 API 계약인 영상 완료 상태를 추가했다.

전체 기능 검사, 실제 VOD 다운로드·음성 추출, Windows 실행, 설치 앱 검증, 빌드·배포는 수행하지 않았다.

## 수정 파일

- `web/speech.js`: 영상 준비 상태 감지, 입력 정보 재조회, 오래된 응답 배제.
- `tests/test_speech_readiness.mjs`: 새로고침 없는 완료 인식과 비동기 응답 순서 회귀 검사.
- `tests/test_speech_ui.mjs`: 영상 상태 fixture 및 현재 도움말 구조 반영.

위 파일과 이 문서를 `로컬 개발 소스` 및 `GitHub 배포용 작업 사본`에 동일하게 반영한다. 원격 저장소에는 아직 반영하지 않는다.
