# 실패·전사 없음 댓글 선택 — 두 OS 빌드와 릴리즈

작업일: 2026-10-26

## 범위와 배포 방식

요약 실패·사용 가능한 전사 없음 항목의 댓글 선택을 포함해 macOS Apple Silicon과 Windows x64 앱을 빌드한다. 기존 공개 릴리즈와 태그는 유지하고 `v0.20.0-preview.3` 사전 검증판으로 구분한다. 앱 표시 버전은 기존 0.20.0을 유지한다. DMG는 생성하지 않는다.

댓글 선택·상태 제목·편집 후 추가를 수정한 소스와 도움말을 배포한다. 실패 항목을 요약 성공 개수에 포함하지 않으며, 처리 중·시각 확인 대상의 제한은 유지한다. 보관함·원본·전사·수동 교정·화자 배정·이전 요약과 댓글 초안을 변경하지 않는다.

## 예외와 검증 한계

두 OS 중 하나라도 실패하거나 산출물 검증이 실패하면 공개를 보류하고 원인을 확인한다. 일시적 네트워크 오류는 TLS·체크섬 검사를 유지한 채 재시도한다. 개인 자료와 모델은 패키지에 포함하지 않는다.

macOS는 임시 서명·미공증, Windows는 미서명 상태를 유지한다. CI 실행 검사는 사용자 실기기의 GPU·장시간 VOD 처리·AI 모델 품질 검증을 대신하지 않는다.
