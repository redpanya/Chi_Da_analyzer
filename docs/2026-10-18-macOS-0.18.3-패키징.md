# macOS 0.18.3 앱 패키징

작성일: 2026-10-18
요청 범위: 최신 VOD 리스트 통합 작업을 포함한 **macOS 앱 패키징만**.

## 산출물

- 앱: `outputs/releases/ChiDaanalyzer-0.18.3-macOS/ChiDaanalyzer.app`
- 버전: `0.18.3`
- 대상: Apple Silicon(arm64), macOS 14 이상
- 앱 일반 파일 합계: 276,921,415바이트(약 277 MB), 261개
- 내용 목록 SHA-256: `74e612f0d76f1172101c8494dc30fb93672a52982d6aed2574e6322d20528c6e`
  - 일반 파일의 정렬된 상대 경로와 각 SHA-256을 합산한 식별값이다. ZIP 파일 해시가 아니다.
- 검사 기록: 같은 출력 폴더의 `package-check.json`, `smoke.json`

이번에는 `.app`만 생성했다. DMG·전달용 ZIP·Windows 빌드·GitHub 업로드·릴리스는 수행하지 않았다. 기존 0.18.2 앱과 현재 실행 중인 개발 앱은 교체하거나 종료하지 않았다.

## 포함 변경과 빌드

VOD 리스트 등록으로 온라인 입력 통합, 저장 VOD 선택/순서 변경, 완료 단계 재사용, 대기 설정 적용, 로컬 파일 첨부 흐름 유지가 포함된다. 외장 보관함의 채팅 작업용 내장 임시 DB 수정도 유지한다.

화면·새 리포트·패키지 버전과 패키지 검사 기대 버전을 0.18.3으로 맞췄다. 기존 리포트 내용은 수정하지 않는다. 로컬 GitHub 작업 사본의 빌드 버전도 맞췄지만 워크플로는 실행하지 않았다.

별도 빌드 스냅샷 `outputs/builds/chida-0.18.3-vod-list`에서 Python 실행기를 다시 동결하고 앱을 조립했다. 네이티브 도구는 0.18.2 빌드와 고정 소스 목록이 같은 것을 확인해 재사용했다. 사용자 영상·채팅·전사·요약·모델·인증 파일은 패키지에 포함하지 않았다.

## 확인 결과

- 앱 조립 및 최종 출력 폴더 복사 후 `codesign --verify --deep --strict` 통과.
- 번들 내부 파일명 ASCII 확인, 번들 버전/최소 macOS 확인.
- 최종 앱의 웹 파일과 빌드 스냅샷 파일 일치 확인. 신규 `queue-saved.js` 포함.
- 포함 도구 실행, 합성 H.264/AAC 영상 읽기·디코딩, 한글·공백 경로 처리 통과.
- 임시 자료의 원음 정보·음성 추출, 영상 수신 후 검사 재개, 시간축·채팅 경계 복구 통과.
- 순차 작업 상태·리포트·VOD 번호·기존 리포트 사본 보존·이메일 안내 확인.
- 패키지 백엔드의 로컬 HTTP 서버 시작 및 정상 종료 통과.
- 실제 보관함을 대상으로 다운로드나 AI 추론을 재실행하지 않았다. 기능 회귀 결과는 [VOD 리스트 통합 구현 기록](2026-10-18-VOD리스트등록-통합-구현검증.md)을 참조한다.

## 서명과 미검증 범위

**임시(ad-hoc) 서명**이며 Developer ID 서명·Apple 공증은 없다. 서명 무결성 통과는 Gatekeeper의 배포 허용이나 다운로드 격리 상태의 최초 실행 성공을 의미하지 않는다.

이번에는 Finder/LaunchServices 실행, 인터넷에서 받은 격리 파일의 최초 실행, Intel Mac, Windows, 전체 모델 추론을 검사하지 않았다. 패키지에 포함된 백엔드 실행과 합성 자료 기반 기본 동작까지만 확인했다.
