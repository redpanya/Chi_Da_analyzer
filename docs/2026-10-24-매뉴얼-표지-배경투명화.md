# 매뉴얼 표지의 노란 배경 제거

작업일: 2026-10-24

- 사용자가 지정한 첫 화면 `#top.hero`의 노란 배경과 내부 개정판 안내 상자의 노란 배경을 투명하게 변경했다. 기존 픽셀 패턴이 이 영역에도 보인다.
- 글자·버튼·스티커·테두리·배치와 패턴 불투명도 40%, 소품 크기·간격은 유지했다. 앱 화면이나 분석 기능은 변경하지 않았다.
- 공통 `--lime` 색상 변수는 유지해 로고와 다른 메뉴의 강조색에 영향을 주지 않는다. 인쇄용 흰 배경도 유지한다.
- 매뉴얼 본문 CSS에도 내용 해시를 붙여 이전 노란 배경이 브라우저 캐시에 남지 않게 했으며, 생성·검사 스크립트에 같은 기준을 적용했다.
- 로컬·배포 매뉴얼의 링크·자원·해시 정합성 검사 통과: 11개 주제, 62개 안내, 화면 31개. 문구·원본 이미지·스크린샷과 기존 분석 자료는 변경하지 않았다.
- 공개 매뉴얼 변경 커밋: `7effbeb`. 앱 패키지는 빌드하지 않는다.
- 공개 페이지에서 표지·안내 상자 배경이 모두 `rgba(0, 0, 0, 0)`이고 패턴 불투명도는 `0.4`임을 확인했다. 고양이·넥타이 패턴이 표지 안쪽에서도 보이는 화면을 확인했다. CSS 해시: `1ddd749aed10`.
