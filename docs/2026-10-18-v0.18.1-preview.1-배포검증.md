# v0.18.1-preview.1 배포·패키지 검증

작성일: 2026-10-18

## 배포 범위

- GitHub 공개 저장소 `redpanya/Chi_Da_analyzer`의 새 사전 검증판. 기존 릴리즈와 자산은 유지한다.
- macOS Apple Silicon: `ChiDaanalyzer-macOS-arm64.zip` 안의 `ChiDaanalyzer.app`.
- Windows x64: `ChiDaanalyzer-Windows-x64.zip` 안의 `ChiDaanalyzer/ChiDaanalyzer.exe`.
- 앱/리포트 버전 0.18.1. DMG·모델 가중치·실제 VOD/전사/요약·개인 설정·인증정보는 포함하지 않는다.

## 포함한 변경

1. 다운로드·검증 완료 뒤 새로고침 없이 음성 추출 준비 상태를 갱신한다.
2. 여러 VOD 주소의 순차 목록과 다운로드→원음 추출→전사→선택 화자 구분→반응 분석→Gemma 요약 자동화를 제공한다. 말소리 분리는 제외한다.
3. 선택한 VOD의 실행 기록, PC 사양, 처리 시간·수치 리포트를 제공한다.
4. 성능 JSON에 VOD 번호를 포함하고 현재 PC와 실행 당시 사양을 구분한다. 구형 리포트는 내보내는 사본만 보완한다.
5. JSON 저장 후 `redpanyaday@gmail.com`으로 직접 첨부하는 안내를 제공한다. 서버·Google Drive 자동 전송은 제거했다.

## 기존 자료와 예외

기존 앱을 종료한 뒤 새 ZIP을 별도 위치에 풀고 기존 보관함·모델 경로를 선택한다. 기존 다운로드·전사·화자 배정·수동 교정·요약·리포트를 업데이트 과정에서 이동·삭제하지 않는다. 자동 목록은 중단 상태로 복구하며 앱 실행만으로 다시 시작하지 않는다.

새 기능의 모델/공간 부족·부분 실패·기존 자료 호환성 처리는 해당 구현 문서의 기준을 유지한다. 리포트 전송은 사용자의 메일 앱에서만 진행한다. 메일 수신이나 발송 자체는 패키지 검사 범위가 아니다.

- `git diff --check` 통과.
- 기존 리포트 사본의 VOD 번호 보완, 원본 보존, 폐기된 자동 제출 API의 410 반환을 확인했다.

## OS별 패키지 검사

GitHub Actions의 macOS arm64·Windows x64 러너에서 각각 빌드한다. 기존 잠금·포함 도구·미디어 생성/검증/복구·원음 추출·시작/종료 검사에 순차 작업/리포트 검사를 추가했다.

패키지 검사에는 실제 원음 추출에서 생성한 리포트, VOD 번호·버전, 구형 파일의 무변경 내보내기, 이메일 안내, 자동 업로드 제거, 빈 큐의 비실행 상태를 포함한다. 외부 VOD 수신과 모델 추론은 수행하지 않는다.

현재 상태: 원격 빌드 실행 전. 완료 후 실행 링크·소스 커밋·파일 크기·체크섬·검증 결과를 아래에 추가한다.

## 서명과 남은 확인

macOS는 임시 서명이며 Developer ID 서명·Apple 공증은 없다. Windows Authenticode 서명도 없다. macOS ZIP 해제 후 서명·실제 앱 시작과 인터넷 다운로드 후 Gatekeeper 허용은 구분한다. 다운로드 앱의 첫 실행 허용을 보장하지 않는다.

실제 사용자 장치의 장시간 VOD 처리, 모델 최초 다운로드·추론 품질·GPU 처리 속도, 최소 OS 버전 실행은 이번 자동 검사로 대신하지 않는다. OS별 자동 검증 결과를 확인한 뒤 동일 산출물을 공개 사전 검증판으로 게시한다.
