# 치다 분석기 v1.1.0

- 가져오기 화면에서 다운로드를 중단한 뒤 화질을 변경하거나, 완료한 VOD의 영상만 다른 화질로 다시 받을 수 있다. 완료본은 새 영상 검증 후 교체하며 기존 영상을 보존하거나 삭제할 수 있다. 채팅·전사·수동 교정·AI 결과는 재사용한다.
- 같은 VOD의 화질별 재생 시간이 조금 다를 때 허용 범위와 음성 일치 여부를 확인한다. 클립 편집기에서는 전사용 원음과 현재 영상의 음성을 대조해 일정한 시차만큼 자막을 보정한다. 미리보기, 영상에 입히는 자막과 편집용 SRT·ASS에 적용한다.
- 일부 VOD의 별도 음원 트랙 때문에 목록 등록이 실패하던 문제를 수정했다.
- 전사 화면에서 발언을 클립에 담을 수 있다. 클립마다 화면과 자막 설정을 정하거나 여러 구간에 같은 프리셋을 적용할 수 있다. 프리셋을 전환할 때 단일 화면의 PNG 미리보기 위치도 저장 결과와 맞췄다.
- 상세 문맥·타임스탬프·클립 후보의 목록 탐색 방식을 통일하고 분석·재생의 공통 시간축에 클립 후보를 표시한다.
- 영상 나누기에서 MP4와 함께 지원 코덱을 사용한 M4V·MOV·MKV·WebM도 재인코딩 없이 나눌 수 있다. 앱 아이콘과 브라우저 로고를 교체했다.

## 배포와 확인

macOS Apple Silicon과 Windows x64 포터블 ZIP을 대상으로 한다. 각 빌드에서 등록·교체, 전사 클립 담기, 자막 동기화, 프리셋과 영상 나누기를 검사하고, 조립한 패키지를 실행해 정적 자산·합성·다운로드 경로를 확인한다. SHA-256 목록, 두 운영체제의 검증 기록과 외부 구성요소 고지·대응 소스를 실행 파일과 함께 제공한다.

11월 3일 [GitHub 최신 정식 릴리즈](https://github.com/redpanya/Chi_Da_analyzer/releases/tag/v1.1.0)로 공개했다. 릴리즈 태그와 [성공한 빌드](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/41621440065)는 같은 소스 커밋 `22ad3a15a4c3d62331d6c43ef0599030e975b242`을 가리킨다.

| 운영체제 | 빌드 시간 | 앱 ZIP 크기 | SHA-256 |
|---|---:|---:|---|
| macOS Apple Silicon | 7분 26초 | 118,872,212바이트 | `d8a0a9eebed935743882bb0ae304f38d696813303ec98900cb18111be057b30a` |
| Windows x64 | 4분 38초 | 141,480,131바이트 | `79a5a890cdacdd29ddeee714528406d908b4370b1f64888e30626a74790a0a08` |

- 초기 검사에서 전사 원문과 미리보기 데이터의 객체 동일성을 요구하던 검사를 수정했다. 원문의 시각을 보존하면서 영상 미리보기가 보정된 시각을 쓰는지 확인했다.
- Windows에서 이전 영상 정리 목록과 보호할 파일의 경로 구분자가 다르면 현재 영상이 정리 대상에 들어갈 수 있었다. 운영체제의 파일 경로로 비교하도록 수정하고 현재 영상과 사용자가 보존한 버전의 보호를 Windows 러너에서 확인했다.
- 파이썬 기본 검사 142건 및 미디어·기능 검사 199건을 OS별로 실행했다. Windows는 미디어 테스트 자료 생성 인코더가 없는 6건을 건너뛰었다. macOS는 Windows 전용 기본 검사 2건과 미디어·기능 검사 7건을 건너뛰었다. 두 OS 패키지를 각각 기동해 HTTPS 구간 수신, 원음 추출, 자막·이미지 렌더링, 선택 오디오 분할 등의 실행 검사를 통과했다. 실제 스트리머 장시간 방송이나 개별 PC의 GPU 추론을 새로 실측한 결과는 아니다.
- 공개 전 앱 ZIP 두 개를 내려받아 GitHub 자산 해시와 배포 체크섬을 대조하고 ZIP 전체 무결성, 실행 파일, 아이콘과 주요 화면 파일을 확인했다. Windows HTML과 자바스크립트는 줄바꿈만 정규화해 비교했다. 공개 후 최신 릴리즈 상태, 태그의 커밋, 배포 자산 9개, 두 앱의 비로그인 다운로드 주소 HTTP 200을 확인했다.
