# 치다 분석기 v1.1.0

- 가져오기 화면에서 다운로드를 중단한 뒤 화질을 변경하거나, 완료한 VOD의 영상만 다른 화질로 다시 받을 수 있다. 완료본은 새 영상 검증 후 교체하며 기존 영상을 보존하거나 삭제할 수 있다. 채팅·전사·수동 교정·AI 결과는 재사용한다.
- 같은 VOD의 화질별 재생 시간이 조금 다를 때 허용 범위와 음성 일치 여부를 확인한다. 클립 편집기에서는 전사용 원음과 현재 영상의 음성을 대조해 일정한 시차만큼 자막을 보정한다. 미리보기, 영상에 입히는 자막과 편집용 SRT·ASS에 적용한다.
- 일부 VOD의 별도 음원 트랙 때문에 목록 등록이 실패하던 문제를 수정했다.
- 전사 화면에서 발언을 클립에 담을 수 있다. 클립마다 화면과 자막 설정을 정하거나 여러 구간에 같은 프리셋을 적용할 수 있다. 프리셋을 전환할 때 단일 화면의 PNG 미리보기 위치도 저장 결과와 맞췄다.
- 상세 문맥·타임스탬프·클립 후보의 목록 탐색 방식을 통일하고 분석·재생의 공통 시간축에 클립 후보를 표시한다.
- 영상 나누기에서 MP4와 함께 지원 코덱을 사용한 M4V·MOV·MKV·WebM도 재인코딩 없이 나눌 수 있다. 앱 아이콘과 브라우저 로고를 교체했다.

## 배포와 확인

macOS Apple Silicon과 Windows x64 포터블 ZIP을 대상으로 한다. 각 빌드에서 등록·교체, 전사 클립 담기, 자막 동기화, 프리셋과 영상 나누기를 검사하고, 조립한 패키지를 실행해 정적 자산·합성·다운로드 경로를 확인한다. SHA-256 목록, 두 운영체제의 검증 기록과 외부 구성요소 고지·대응 소스를 실행 파일과 함께 제공한다.
