# v1.2.1 사용설명서 보강

2026년 11월 17일

## 변경 내용

기존 공개판의 13개 주제와 83개 안내를 앱 v1.2.1 기준 17개 주제와 100개 안내로 개편했다. 첫 VOD로 댓글용 타임스탬프 만들기, 한 방송의 장면 저장, 여러 방송의 클립을 믹스로 보내 따로 편집하는 과정을 실제 버튼 순서로 설명한다.

- macOS DMG 수동 교체와 Windows 포터블 교체 후 재실행을 나눠 설명했다. 기능별 모델 설치와 삭제, 발화 검출과 화자 엔진 선택을 추가했다.
- 전체와 지정 구간 다운로드, 동시 다운로드 개수, 화질 교체, 수신 속도와 처리 배속, 중단 복구와 자동화의 동시 실행 조건을 정리했다.
- 자료 준비의 다섯 단계, 전사 교정, 문맥 결과 버전, 외부 AI의 부분 결과 가져오기, 댓글 목록과 담은 클립을 설명했다.
- 클립과 믹스의 편집 대상, 프리셋 적용 범위, 드래그 정렬, 카드의 ×, 컷과 디졸브, 초안과 영상 파일의 차이를 설명했다.
- 영상 나누기의 실제 분할 시각과 오디오 트랙 선택, VOD별 리포트와 오류 기록, 첨부 전 확인 방법을 추가했다.

## 화면과 검증

공개판의 신규 화면 20장은 예제 방송 두 개와 예제 전사로 별도 보관함에서 촬영했다. 실제 방송 장면과 사용자 보관함 자료는 이번 공개 변경에 포함하지 않았다.

- 내부 브라우저에서 예제 전사 한 줄을 댓글 목록에 담았고 같은 발언의 내용근거에서 교정 입력칸, 교정 저장, 원문 복원을 확인했다.
- 예제 클립과 믹스 편집기에서 현재 구간과 전체 프리셋 대상을 비교하고 저장 패널을 확인했다. 믹스에서 현재 카드의 ×를 누르자 두 구간 중 한 구간만 빠지고 다음 카드가 편집 대상으로 열렸다. 앱 설정, 작업 상세와 VOD별 오류 기록도 실제 화면과 대조했다.
- 공개용 HTML을 생성한 뒤 17개 목차, 100개 안내, 20개 이미지 연결과 이전 개별 안내 주소 83개를 검사했다. 이전 주소는 주제가 이동했어도 대응하는 새 안내를 연다.
- 내부 브라우저에서 ‘미수신 보완’ 검색이 한 항목을 찾는지, 없는 검색어는 빈 결과와 지우기 버튼을 보여 주는지 확인했다. 목차 이동, 믹스 화면 확대와 닫기, 테마 전환과 기존 자막 파일 저장 북마크도 확인했다.

이번 검증은 설명서와 화면의 동작을 대상으로 했다. 실제 방송 다운로드, 모델 설치, 운영체제 업데이트와 영상 전체 렌더링은 실행하지 않았다.
