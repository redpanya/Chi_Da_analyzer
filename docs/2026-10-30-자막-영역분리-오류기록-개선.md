# 자막 미리보기 독립 처리와 공통 오류 기록

## 수정 내용

### 자막과 화면 영역

- 자막 예시 및 영상 위 자막 생성 요청은 글꼴·자막 디자인·문장·출력 크기만 검사한다. 게임·얼굴 영역 값 때문에 자막 생성이 중단되지 않는다.
- 세로 2단 화면의 영역이 잘못되면 해당 게임/얼굴 설정 아래에 구체적인 오류를 표시한다. 미리보기에서만 잘못된 영역을 전체 화면으로 대체하며 입력값은 변경하지 않는다.
- 해당 영역을 실제로 사용하는 초안 저장·영상 저장은 정상 영역으로 수정하기 전까지 차단한다. 단일 화면에서는 사용하지 않는 2단 영역의 합계 초과가 저장을 막지 않는다.
- 정상으로 수정하면 영역 오류를 즉시 지운다. 자막 예시 요청이 성공하면 이전 자막 렌더링 오류도 지운다.
- 글꼴 미지원·잘못된 자막 옵션 등 자막 자체의 오류는 계속 검사한다.

### 작업 기록과 이메일 첨부 안내

- 공통 HTTP 요청 오류, 브라우저 실행·미디어·로컬 요청 오류, 다운로드·채팅·오디오·전사·화자·AI·자동화·클립·영상 나누기의 작업 실패를 공통 진단 기록에 연결했다. 부분 요약 오류도 기록한다.
- 작업 기록 페이지에서 VOD 선택 여부와 관계없이 최근 오류, 기능명, 시각, 반복 횟수, 종료 코드와 로컬 상세 메시지를 확인할 수 있다.
- 설정에 `오류 진단 로그 저장` 옵션을 추가했다. 기본값은 켜짐이며 끄면 새 진단 기록을 저장하지 않는다. 기존 진단 기록과 복구용 작업 상태·개별 엔진 로그는 유지한다.
- 최대 1,000건/약 4MiB를 보관하며 초과 시 오래된 진단 항목부터 정리한다. 짧은 시간에 같은 오류가 반복되면 횟수로 합친다.
- 로컬 경로: macOS는 `~/Library/Application Support/치지직 보관함/diagnostics/errors.json`, Windows는 `%LOCALAPPDATA%/ChiDaAnalyzer/diagnostics/errors.json`이다. 외장 VOD 보관함과 분리한다.
- 첨부용 JSON 미리보기·저장·동의 후 이메일 작성 안내를 제공한다. 수신 주소는 `redpanyaday@gmail.com`이며 사용자가 파일을 직접 첨부하고 전송한다. 자동 업로드/자동 발송은 없다.
- 첨부 JSON은 앱 버전, OS/구조, 시각, 기능 식별자, VOD 번호, 결과 식별자, 오류 종류/코드/고정 요약, 코드 위치, 반복 횟수만 포함한다. 자유 형식 오류 메시지·전체 경로·명령줄·전사·채팅 본문은 제외한다. 파일 미리보기 후 공유 여부를 결정할 수 있다.
- 로컬 상세 메시지는 주소·인증정보·이메일·일반적인 절대 경로를 가린다. 모든 자유 형식 문자열의 민감정보 제거를 보장하는 방식은 아니므로 로컬 상세 메시지를 별도로 복사해 보내는 경우 사용자가 내용을 확인해야 한다.

## 기존 자료 영향과 예외 처리

- 원본 영상·채팅·전사·화자 배정·요약 결과를 다시 쓰거나 삭제하지 않는다. 기존 초안의 영역/자막 설정을 자동으로 보정하지 않는다.
- 잘못된 영역이 포함된 예전 초안도 불러와 자막을 확인할 수 있다. 영상 저장 전 화면 설정에서 영역을 수정해야 한다.
- 로그 저장 실패가 원래 작업의 성공·실패·재개 결과를 바꾸지 않는다. 공간/권한 오류는 작업 기록에서 안내한다. 손상된 기존 진단 파일은 덮어쓰지 않는다.
- 사용자의 의도적인 취소와 재생 탐색 중 연결 종료는 오류로 남기지 않는다. 이미 프로그램이 강제 종료된 상태, 전원 차단, OS가 종료한 시점의 기록까지 보장하지는 않는다.
- 기존 루프백 바인딩, 실행별 임의 주소, Host/Origin 검사, 패키지 CSP는 유지한다. 이메일 기능 때문에 외부 수집 서버나 열린 수신 포트를 추가하지 않는다.
- 테스트 실행기의 진단 저장 위치는 임시 폴더로 분리한다.

## 검증 결과

- macOS 소스 회귀 검사: Python 142건 통과, 환경 조건에 따른 2건 건너뜀. JavaScript UI 회귀 검사 통과.
- 5개 화면비 × 단일/2단 화면에서 잘못된 영역을 넣어도 같은 자막 PNG가 생성되는 것을 확인했다. 실제 영상 저장 계약은 활성화된 잘못된 영역을 거부한다.
- 로그 켜기/끄기, 기존 설정 보존, 종료 코드 3221226505 보존, 반복 합치기, 동시 기록, 용량 제한, 손상 파일 보존, 저장 실패 격리, 첨부 사본의 자유형식 메시지 제외를 검사했다.
- HTTP 오류 수집과 외부 Origin 거부, 브라우저 오류 중복/빈도 제한을 검사했다.
- 내부 브라우저: 얼굴 가로 위치 99% + 너비 22%의 오류 상태에서도 실제 영상 위 자막 및 `현재 자막 문장 렌더링 확인 완료` 표시를 확인했다. 기존 가로 위치 78%로 복원하면 오류 안내가 즉시 사라졌다. 검증 중 초안을 저장하지 않았다.
- Windows 실제 빌드/검사는 GitHub Actions 완료 후 아래에 기록한다. 사용자 Windows PC의 특정 GPU·글꼴·장시간 실사용 확인과 CI 검사는 별개다.

## 배포

- macOS arm64 / Windows x64 빌드와 패키지 독립 실행 검사를 진행한다. DMG는 만들지 않는다.
- Windows 전사 엔진의 별도 네이티브 종료 문제까지 이번 자막 수정으로 해결됐다고 판단하지 않는다. 해당 종료 코드도 새 공통 기록에 남길 수 있다.
