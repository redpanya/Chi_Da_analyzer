# 결과 확인 UI·UX 통합 구현과 검증

작성일: 2026-10-20
범위: [개선 설계](2026-10-20-결과확인-UIUX-및-문맥안내-개선검토.md)와 버튼 내부 글자 클릭 보강.
상태: 로컬 소스 구현·회귀 검사·macOS 내부 브라우저 확인 완료. 패키징·GitHub 업로드·배포 없음.

## 1. 반영한 내용

| 영역 | 변경 |
|---|---|
| 가져오기 | 새 `내 비디오 사용` 입력과 업로드 UI 모듈 제거. VOD 리스트 등록과 저장 폴더 설정 유지 |
| 과거 로컬 영상 | 완료된 자료의 판독·재생·분석·VOD 시각 오프셋은 유지. 신규 업로드 API는 410으로 명시적으로 종료 |
| 음성 전사 | 전사 조회·검색·TXT/CSV/JSON 내보내기를 화자 결과와 분리. 화자 분석·이름 변경만으로 전사 목록을 다시 읽거나 페이지 위치를 초기화하지 않음 |
| 수동 교정 | 전사 원문과 교정 저장소 유지. 화자 검토·요약은 같은 교정문을 참조하며 본문 복사본을 추가하지 않음 |
| 화자 검토 | `화자 목록 / 배정된 전사 / 인식 실패` 탭, 각 건수, 키보드 좌우·처음·끝 이동. 목록 높이 제한과 기존 100개 단위 조회 유지 |
| 화자 조작 | 이름·건수·대표 음성을 간결한 행으로 표시. 실패 발언의 배정 입력은 해당 행을 펼쳐 사용. 검색·후보 묶음·일괄 배정·되돌리기 유지 |
| 준비 상태 | 기존 도구 설치·검사·모델 준비 버튼 유지. 결과와 준비된 모델이 있으면 설정은 접고 검토를 우선 표시 |
| 통합 분석·재생 | 우측 통합 검색·채팅·발언 목록과 저장 구간 UI 제거. 재생·배속 아래에 공통 시간축 배치. 원본 영상·채팅 내보내기는 가져오기 진행 화면으로 이동 |
| 시간축 | 전체 / 30분 / 10분 / 2분, 확대·축소·전체·현재 위치, 범위 중심 슬라이더, 이전·다음 범위, 드래그 가로 이동, 키보드 5초 이동 |
| 재생 | 시간축 이동 시 재생/정지 상태 유지. 강제 `scrollIntoView` 제거. AI 문맥 구간 재생·끝 정지·배속·오류 안내 유지 |
| AI 문맥 | 선택적인 VOD별 방송 배경 설명(500자). 정상 결과의 대화 문맥과 채팅 반응을 함께 기본 노출 |
| 실패 참고 | 붉은 굵은 `요약 실패` 유지. 읽을 수 있는 발언의 처음·중간·끝 최대 3개와 보존된 채팅 근거 최대 3개 표시. 시각으로 영상 확인 가능 |
| 공통 밀도 | 본문 행간 약 1.5, 일반 입력·버튼 최소 높이 34px, 목록·카드·패널 간격 축소. 데스크톱 배치·💡 도움말·진행·오류 표시 유지 |

기존 반응 분석을 덮어쓰는 새 자동 실행은 추가하지 않았다. 통합 화면에서는 저장 결과를 표시하고 필요하면 `채팅 반응 분석`을 누른다. 기존 순차 자동화와 AI 문맥 처리의 자동 반응 분석은 유지한다. 경계 미검증 채팅의 사용 허용도 그대로 적용한다.

## 2. 버튼 내부 글자·아이콘 클릭

- 버튼 자식의 장식 글자·아이콘이 별도 포인터 대상이 되지 않도록 공통 CSS에서 버튼 본체로 클릭 영역을 통일했다.
- 버튼 내부 텍스트 선택을 막고, 기본 버튼 클릭과 키보드 동작을 유지했다.
- 위임 방식인 💡 도움말은 요소뿐 아니라 텍스트 노드가 클릭 대상으로 들어오는 경우에도 부모 버튼을 찾는다.
- 별도 강제 클릭 재전송은 넣지 않았다. 한 번의 조작으로 두 작업이 실행되는 방식은 사용하지 않는다.
- 비활성 버튼은 그대로 차단한다. 현재 UI에는 버튼 내부에 입력·선택·다른 버튼이 중첩된 구조가 없음을 확인했다.

기존 증상의 정확한 발생 버튼·브라우저·조건은 특정되지 않아 단일 원인을 확정하지 않았다. 수정 화면에서 저장 VOD 제목 글자, 단계 버튼의 글자, 도움말 아이콘과 키보드 조작을 확인하는 방식으로 검증했다.

## 3. 방송 배경 설명과 보존 정책

추가 저장 파일은 각 VOD의 `context/background.json`이다. 기존 영상·채팅·전사·교정·화자 배정 파일에 설명을 섞어 쓰지 않는다.

- 빈 설명은 기존 입력 지문과 같다. 기존 무설명 결과의 이어받기 조건을 바꾸지 않는다.
- 새 실행은 설명을 실행 결과와 입력 지문에 포함한다. 설명이 다른 요약을 같은 결과로 재사용하지 않는다.
- 이어하기는 실행 당시 저장한 설명을 사용한다. VOD 기본 설명을 바꿔도 과거 결과·완료 부분을 덮어쓰지 않는다.
- 토큰 계산과 실제 추론에 동일한 설명을 넣는다. 모델·사고 설정은 기존 Gemma 설정을 유지하며 추가 LLM 호출은 없다.
- 실제 발언·채팅을 근거로 우선한다. 설명만으로 사건·결말·원인·화자 신원을 추가하지 않도록 지시한다.
- 순차 등록의 각 항목에 별도 설명을 넣을 수 있다. 공통 설정 적용이 서로 다른 VOD의 설명을 덮어쓰지 않는다.
- 설명을 저장하는 동안 VOD를 바꾸면 이전 저장 응답으로 다른 VOD의 분석을 시작하지 않는다.
- 진행 중 작업 잠금, 길이·자료형·제어문자 검사, 경로·심볼릭 링크 경계 검사를 적용한다.
- 성능 리포트는 기존 허용 필드만 포함하므로 설명 본문을 제출 JSON에 넣지 않는다.

설명은 참고 자료로 구분하지만 모델의 추론 오류를 없애는 보장은 아니다. 잘못된 배경 설명의 품질 영향이나 처리 시간 변화는 아직 실측하지 않았다.

## 4. 사이드이펙트·예외 처리

| 경우 | 처리 |
|---|---|
| 과거 로컬 가져오기가 미완료 | 파일을 삭제하지 않고 미완료로 유지. 새 UI에서 추가 첨부·재첨부는 제공하지 않음 |
| 전사에서 내보내기 | 화자 이름 없는 전사로 별도 내보냄. 내보내기 시각은 `exported_at`에 기록하여 화자 내보내기 유효성을 불필요하게 무효화하지 않음 |
| 원문 수동 교정 | 교정문은 화자·요약 조회에도 반영. 과거 결과를 자동 재생성하지 않으며 기존 입력 변경 판정 유지 |
| 화자 탭 이동 | 기존 DOM·검색·선택을 유지. 다른 VOD·분석 버전에서는 이전 선택을 초기화 |
| 화자 이름 입력 중 갱신 | 수정 중인 이름만 임시 보존. 저장 성공이나 버전 변경 후 이전 이름을 새 결과에 덮어쓰지 않음 |
| 화자 분석 없음·0개 발언 | 발언 트랙과 화자 배정 실패를 혼동하지 않음. 감지 음성은 있지만 전사 배정 0개인 기존 안내 유지 |
| 20시간 자료·전체 보기 | 같은 화면 열의 채팅 최고값 유지. 확대 시 보이는 구간만 표시. 경계 미검증 빗금은 해당 영역만 그려 반복 비용 제한 |
| 채팅 보정·영상 끝 초과 | 표시 범위와 영상 길이를 구분. 영상 탐색은 실제 영상 범위로 제한. 기존 세션의 채팅 보정값 보존 |
| 기존 실패 요약 | 원문 참고를 읽기 전용으로 구성. 원 오류·실패 상태 유지, 댓글 자동 복사 선택 제외 |
| 채팅 후처리 없는 실패 자료 | 보존된 채팅 근거가 없다고 표시. 실제 채팅 반응이 없었다는 판정으로 바꾸지 않음 |
| 연속 요약 오류 | 기존 부분 복구·다음 구간 처리 정책 유지. 이번 UI 보강으로 실패를 성공 처리하거나 추가 모델 재시도를 만들지 않음 |
| 다른 페이지와 공유한 플레이어 | 문맥 구간 끝 정지와 일반 시간축 탐색을 구분. 페이지 이동 시 이전 재생 범위 제한 해제 |

기존 음원 분리본은 열람 경로를 유지했다. 새로운 분리 기능이나 모델 변경은 추가하지 않았다.

### macOS 내부 브라우저

실제 자료는 읽기·화면 이동·탐색으로 확인했다. 다운로드·전사·화자 추론·전체 요약을 다시 실행하거나 실자료에 수동 배정을 저장하지 않았다.

- 약 13시간 52분 자료의 21개 화자, 배정 전사 5,000개, 실패 3,813개가 독립 탭으로 표시됨.
- 정상 문맥과 실패를 포함한 기존 요약 756개가 열림. 실패 132개에 원문 참고가 표시되고 정상 항목에는 채팅 반응이 기본 노출됨.
- 저장한 VOD 제목 글자와 단계 버튼의 글자를 눌러 화면 이동 확인.
- 2분 시간축에서 영상 52.587초 → 57.587초 이동 시 일시정지 유지, 세로 스크롤 725.5px → 725.5px 유지.
- 일반 전사 표시, 화자 탭, 확대 시간축, 문맥 결과에 새 JavaScript 콘솔 오류 없음.
- 현재 좁은 내부 브라우저에서도 데스크톱 최소 배치와 가로 스크롤 유지. 별도 모바일 배치를 추가하지 않음.

화면 기록: `outputs/uiux-validation-20261020/timeline.png`, `final-timeline.png`(작업 공간 기준).
최종 화면에서도 10분 범위(00:00~00:10)에서 2분으로 확대하면 같은 중심(00:05)을 기준으로 00:04~00:06이 표시됨을 확인했다.
개발 서버 위치 기록: `outputs/uiux-20261020-ready.json`. 실행 중 주소는 재실행마다 바뀐다.

## 6. 남은 확인 범위

- 실제 모델로 배경 설명 없음/정확함/부정확함/혼합 장르를 비교하는 품질·시간 검증은 별도 진행이 필요하다. UI·입력·보존 검사 통과를 요약 품질 개선 실측으로 해석하지 않는다.
- Windows, 독립 Safari·Chrome, 고정 1280×720·1440×900, 브라우저 200% 확대를 각각 실측하지 않았다. 과거 Safari 재생 멈춤까지 해결했다고 판정하지 않는다.
- 전체 다운로드부터 장시간 추론까지의 새 실행과 패키징은 수행하지 않았다.
- 방송 설명은 자유 입력과 예시 문구로 제공한다. 구간별 설명 편집기·자동 장르 판정은 없다.
- 화자 페이지에서 본문을 별도로 편집하지 않는다. 본문 교정은 음성 전사 페이지에서 진행한다.

변경 전 소스 사본은 `outputs/uiux-20261020-before`에 보존했다. 제품 소스의 검증 결과이며, 이미 설치된 앱이나 배포 파일이 자동 갱신되는 작업은 아니다.
