# 치다 분석기 1.2.2 배포 기록

## 반영한 변경

첫 실행의 보관함 설정과 VOD 등록 안내, 메뉴별 첫 방문 안내와 다시 보기를 포함한다. 보관함 폴더를 선택하기 전에는 다운로드를 차단하고, 등록할 자료가 없으면 다음 단계로 진행할 수 없다.

클립 만들기는 오른쪽 패널을 포함한 18개 코치마크를 제작 순서에 맞춰 연다. 믹스클립에서는 분석에서 담은 클립을 보내는 방법만 한 번 설명한다. 두 편집기에서 자막 글꼴 목록이 비어 보이던 문제도 수정했다.

## 빌드와 검증

이전 정식 버전은 1.2.1이다. Python 처리기와 Electron 앱, 잠금 파일의 버전을 1.2.2로 맞췄다. 공개용 소스 체크아웃에서 자바스크립트 검사 173건이 통과했다. 패키지 실행 검사에 튜토리얼 파일 네 개의 내용 비교를 추가했다.

첫 빌드에서 출처 거부 시험이 운영체제의 연결 종료 시점에 영향을 받았고, 다운로드 복구 시험은 선택한 보관함 밖의 자료를 사용했다. 출처 거부와 큰 본문 처리를 따로 검사하고, 복구 시험용 VOD를 선택한 보관함 안에 만들도록 고쳤다. 제품의 출처 검사와 보관함 제한은 그대로 적용한다.

두 운영체제 모두 같은 커밋 `a135548a19344b46712dd15b92f15e1e06e9ef74`에서 빌드했다. 각 플랫폼에서 완성된 패키지를 실행해 Electron 설정 화면에 1.2.2가 표시되고 Python 처리기가 기동하는지 확인했다. 다운로드 복구, 원음 추출, 한글 자막 렌더링, 영상 나누기와 원본 보존 검사도 통과했다. Windows에서는 실제 배포 ZIP으로 정상 교체와 재실행, 시작 실패 시 이전 실행 파일 복원과 기존 자료 보존을 확인했다. [공식 빌드 기록](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/44005100147)

DMG 무결성 검사를 통과했다. DMG와 ZIP에서 바뀐 웹 파일 14개, 데스크톱 버전 정보, 업데이트 코드와 공개 키를 꺼내 배포 커밋과 대조했다. 17개 모두 일치했다. Windows 텍스트 파일은 줄바꿈 형식을 통일한 뒤 비교했다.

| 배포 파일 | 크기(바이트) | SHA-256 |
| --- | ---: | --- |
| macOS Apple Silicon DMG | 207,344,538 | `0326031f6050f003891ac3f42f2c8d8409883589adbe0626e9529bff1c45f750` |
| Windows x64 포터블 ZIP | 285,497,858 | `d7d41b0a0dcfcaa5b9fd3b71c8711da819b5683978c58f02a82031d6bef566fb` |

## 공개와 업데이트 확인

2026년 11월 17일 오전 11시 59분(한국 시간)에 GitHub 최신 정식 버전으로 공개했다. 태그가 두 패키지를 만든 커밋을 가리키는지 확인했다. 업로드한 13개 파일의 크기와 SHA-256이 초안과 공개 릴리스에서 모두 로컬 배포본과 일치했다. 배포 파일에 라이선스 고지, 대응 소스, 업데이트 목록과 전자서명을 포함했다. [1.2.2 정식 릴리스](https://github.com/redpanya/Chi_Da_analyzer/releases/tag/v1.2.2)

기존 1.2.1 배포본의 업데이트 코드를 격리된 임시 폴더에서 실행했다. macOS와 Windows 모두 1.2.2를 찾았고, 공개 파일을 끝까지 내려받아 업데이트 서명과 파일 해시를 검증했다. macOS는 DMG 다운로드 완료 상태, Windows는 포터블 교체 준비 상태에 도달했다. 1.2.2 자체에서는 두 플랫폼 모두 최신 버전으로 표시했다. 사용자 컴퓨터의 기존 앱과 실제 VOD 자료는 별도로 교체하거나 처리하지 않았다.
