# 치다 분석기 1.2.0 정식 배포

## 배포 대상

- macOS Apple Silicon용 DMG와 Windows x64용 포터블 ZIP을 같은 커밋에서 빌드했다. macOS 앱은 Developer ID 서명 및 공증 없이 배포한다. Windows는 ZIP 전체를 풀어 사용한다.
- 공식 저장소의 Electron 검증 브랜치 이력을 이어서 현재 앱 소스와 배포 안내를 반영했다. 커밋은 `f00a1b1e0b3360d5936f1facdef2f68c7e5ff556`이다. [배포 커밋](https://github.com/redpanya/Chi_Da_analyzer/commit/f00a1b1e0b3360d5936f1facdef2f68c7e5ff556)
- GitHub Actions에서 두 운영체제의 소스 검사, 패키징, 실제 배포 이미지 기동과 Windows 교체 및 실패 복원 검사를 통과했다. [빌드 실행 기록](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/43889387553)

## 배포 소스 사전 검사

- 공개할 소스를 별도 체크아웃에 내보내 앱 자산 해시와 Git 변경분을 확인했다. 개인 VOD, 모델, 사용자 설정, 배포 개인키는 내보내기 대상에서 제외했다.
- 해당 체크아웃의 자바스크립트 테스트 170개가 통과했다. 모델 관리, 경로, 화자 도구, Windows 교체 코드 관련 Python 검사 52개 중 51개가 macOS에서 통과했고 1개는 Windows 전용 실행 파일 교체 검사로 Windows 빌드에서 실행했다.
- 화자 도구 별도 배포에서 macOS 및 Windows용 sherpa 파일을 확인했다.

- macOS 실행기에서 DMG를 읽기 전용으로 마운트한 뒤 그 안의 앱을 기동했다. Windows 실행기에서는 최종 ZIP을 풀고 실행했다. 두 환경에서 버전 1.2.0, Electron 화면, Python 처리기 기동, 설정과 업데이트 버튼을 확인했다.
- Windows 교체 시험에서 정상 교체 후 새 버전이 실행됐고, 새 버전 기동을 실패시킨 시험에서는 이전 실행 파일로 복원하고 재실행했다. 두 경우 모두 시험용 기존 자료가 보존됐다. [Windows 교체 시험 결과](https://github.com/redpanya/Chi_Da_analyzer/releases/download/v1.2.0/windows-update-smoke.json)
- 다운로드한 패키지의 SHA-256과 파일 크기를 GitHub 자산 및 배포 체크섬과 대조했다. DMG 내부 체크섬과 Windows ZIP 압축 무결성도 별도로 검사했다. 양쪽 고지와 대응 소스 압축 파일을 릴리스에 첨부했다.
- 두 패키지의 크기와 해시를 담은 업데이트 목록에 Ed25519 서명을 붙였다. 공개 후 앱의 업데이트 확인 코드로 공식 서버에 접속했다. 비교용 현재 버전을 1.1.0으로 주면 각 플랫폼에서 서명을 검증하고 해당 다운로드를 찾았다. 1.2.0으로 주면 두 플랫폼 모두 최신 상태를 반환했다. 기존 브라우저판에서 처음 전환할 때는 설치 파일을 직접 받는다.
- macOS는 사용자가 DMG 안의 앱을 복사해 교체한다. 인터넷에서 받은 앱의 첫 실행 시 나타나는 Gatekeeper 안내를 사용자 기기에서 수동으로 확인하는 절차는 이번 자동 검사 범위 밖이다.
