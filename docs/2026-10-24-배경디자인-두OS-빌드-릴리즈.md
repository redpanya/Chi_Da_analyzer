# 배경 디자인 반영 macOS·Windows 빌드 및 릴리즈

작업일: 2026-10-24

## 범위

개별 소품 50% 표시, 156px 반복 간격, 불투명도 40%, 8종 무작위 배경을 포함한 앱을 macOS-arm64와 Windows-x64용으로 빌드한다. 공개 매뉴얼의 노란 표지 제거는 매뉴얼 브랜치에 이미 적용됐다.

기존 공개 `v0.20.0-preview.1`을 유지하고 동일 0.20.0 앱의 새 배포본 `v0.20.0-preview.2`로 공개한다. 앱과 함께 라이선스 고지·대응 소스·검사 기록·체크섬을 배포한다. DMG는 만들지 않는다.

## 영향과 예외

기존 릴리즈를 덮어쓰거나 기존 태그를 이동하지 않는다. 두 OS 중 하나라도 실패하면 공개하지 않고 원인을 수정한다. 보관함·모델·설정·인증 자료·개발 환경은 배포하지 않는다. 원본 소품과 생성 원본 이미지를 포함하지 않고 배포용 WebP 8종만 포함한다.

macOS 임시 서명·미공증, Windows 미서명 상태는 기존과 같다. CI의 소스·독립 실행 검증을 실제 장시간 모델 추론·Windows GPU 실기 검증으로 해석하지 않는다.

## 결과

- 첫 실행의 Windows 빌드·패키지 실행 검사 성공.
- 첫 실행의 macOS는 LGPL·MPL 대응 소스 다운로드 중 `SSL: UNEXPECTED_EOF_WHILE_READING`으로 실패했다. 소스·배경 검사 이후의 외부 HTTPS 연결 종료이며, TLS·체크섬 검사를 우회하지 않고 동일 커밋의 실패 작업만 재실행했다.
- 2차 실행의 macOS 빌드와 릴리즈 초안 생성 성공. 첫 실행에 성공한 Windows 산출물과 함께 배포했다.
- [v0.20.0-preview.2 공개 릴리즈](https://github.com/redpanya/Chi_Da_analyzer/releases/tag/v0.20.0-preview.2) 게시 완료: 2026-10-24 19:10 KST. 사전 검증판 상태를 유지한다.
- 실행 ZIP 2개, OS별 고지 ZIP 2개, 대응 소스 ZIP 2개, OS별 실행 기록 2개, 체크섬 파일 1개: 총 9개 첨부 파일을 확인했다.

## 검증 결과

- 두 OS 소스·화면 검사와 독립 패키지 실행 검사 통과.
- 포함 도구 실행, H.264/AAC 생성·읽기·디코딩, 원음 추출 API, 중단 복구, 원본·채팅 보존, 한글·공백 경로, 순차 작업·리포트, HTTP 정적 자원 제공 검사 통과. 다운로드 검사는 실제 방송 수신 대신 생성 자료를 사용했다.
- macOS: `ditto`·`unzip` 두 방식 해제 후 서명·영문 경로 확인, LaunchServices 실제 앱 실행과 서버 응답 검사 통과.
- 실제 내려받은 두 OS 앱 ZIP의 무결성 확인. CSS·JS와 WebP 8종이 빌드 소스와 일치한다. Windows CSS·JS만 CRLF 개행 차이를 정규화했고 이미지 바이트는 그대로 비교했다.
- 두 OS 아티팩트의 체크섬 검증 후 배포 파일을 합쳤다. 배포용 9개 파일의 SHA-256이 GitHub 첨부 파일 digest와 모두 일치한다.
- 패턴 불투명도 40%, 반복 간격 156px, 개별 소품 배율 0.5가 실제 ZIP에 포함됨을 확인했다.
- README·매뉴얼 다운로드 링크를 preview.2로 갱신했다. 매뉴얼 링크·자원·캐시 해시 검사 통과.

## 남은 검증 범위

macOS 임시 서명은 정상이나 Apple 공증이 없고, CI의 Gatekeeper 평가는 거절 상태다. 실제 인터넷 다운로드 후 최초 실행 승인까지 검증한 것은 아니다. Windows Authenticode 서명도 없다. 장시간 실제 VOD 분석, 모델 품질·추론 속도와 Windows GPU 실기 시험은 이번에 수행하지 않았다.
