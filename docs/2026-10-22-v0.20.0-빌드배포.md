# 0.20.0 GitHub 빌드·배포 기록

## 범위

기존 0.19.0 이후 완료된 전사·화자 입력 선택과 개별 삭제, 장치 안내 수정, 빠른 타임스탬프 모드, 외부 AI 파일 내보내기·결과 가져오기, VOD 길이 표시, 편집한 댓글에 항목 추가, 분할 JSON·작업서 ZIP과 결과 ZIP 왕복 처리를 배포한다.

소스·화면·리포트·패키지 버전을 0.20.0으로 통일했다. 앱 파일명은 ChiDaanalyzer이며 macOS arm64와 Windows x64 ZIP을 만든다. DMG는 생성하지 않는다. 기존 공개판·다른 초안·모델·사용자 자료는 변경하지 않는다.

## 영향과 예외 처리

- 실행 코드와 해당 자동 검사, 공개용 안내만 반영한다. VOD 영상·채팅·전사·Gemini 결과·로컬 인증·다운로드 모델·개인 진단 파일은 저장소나 릴리스에 넣지 않는다.
- 기존 보관함은 새 앱에서 그대로 선택한다. 새 외부 결과는 독립 버전으로 저장하고 원본·수동 교정·화자 배정·기존 요약을 덮어쓰지 않는다. 사용자가 명시적으로 실행하는 개별 버전 삭제는 기존 휴지통 처리 계약을 따른다.
- 외부 AI ZIP은 자동 전송되지 않는다. 일부 오류는 정상 결과 미리보기와 분리하고 명시적으로 부분 저장한 뒤 추가 자료를 합친다. 혼합 작업 ID·위험 ZIP·검사 후 입력 변경은 거절한다.
- 두 OS의 소스 검사와 패키지 실행 검사가 모두 통과해야 새 초안 릴리스를 만든다. 실패하면 기존 배포본을 교체하지 않는다.
- MIT 자체 코드와 외부 도구·모델 조건을 구분한다. OS별 고지 ZIP, 네이티브 및 LGPL·MPL 대응 소스 ZIP, SHA-256 목록을 함께 제공한다.

## 검증 계획과 진행

- 배포 후보 체크아웃에서 기존 실행·잠금·미디어·복구·리포트 검사와 신규 입력 선택·ZIP 왕복·댓글 편집·화면 모듈 검사를 실행한다.
- GitHub Actions에서 macOS 15 arm64 / Windows Server 2022 x64로 패키징하고 동봉 도구·HTTP·원음 추출·복구·정상 종료를 확인한다. macOS ZIP은 해제 후 서명과 LaunchServices 실행도 확인한다.
- Windows Vulkan 실행 파일 동봉은 확인하지만 GPU가 없는 러너에서 실제 GPU 추론을 검증한 것으로 기록하지 않는다.
- 모델 다운로드·실제 장시간 전사·Gemma 추론 품질·외부 AI 서비스 처리·사용자 PC의 Safari 재생은 이번 배포 자동 검사의 범위가 아니다.
- macOS는 임시 서명이며 Developer ID 서명·Apple 공증은 없다. Windows Authenticode 서명도 없다.

## 로컬 배포 후보 검사

배포 체크아웃에서 `packaging/release/check_source.py`를 실행했다. Python 104개 중 102개 통과, Windows 전용 2개는 macOS에서 제외됐다. 제외 항목은 Windows Job Object의 자식 프로세스 종료와 Windows 문자 디코딩 오류 재현이며 Windows CI에서 실행한다. JavaScript 검사 스크립트 13종도 모두 통과했다. `git diff --check`도 통과했다.

개인 경로·인증 문자열·실제 Gemini 결과 파일이 배포 변경 파일에 포함되지 않는지 확인했다. 테스트 코드의 가상 VOD 번호와 일반화한 경로는 보존했다.

GitHub Actions 결과와 릴리스 링크는 완료 후 아래에 기록한다.

## 첫 Windows 검사에서 발견한 차이와 보완

첫 실행 [39760830437](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/39760830437)의 Windows 검사에서 ZIP 역슬래시 경로 거절 항목 1개가 실패했다. Windows의 표준 ZIP 라이브러리가 읽기·쓰기 중 역슬래시를 슬래시로 바꾸므로 정규화된 파일명만 검사하면 OS별 판정이 달라졌다.

실제 읽기 코드는 ZIP의 원래 파일명(`orig_filename`)을 먼저 검사하도록 수정했다. 테스트도 모든 OS에서 같은 원시 파일명을 기록하도록 바꾸고 Windows 정규화 동작을 재현하는 검사를 추가했다. ZIP 관련 8개 검사 모두 로컬 통과했다. 이 수정은 정상 결과와 기존 파일을 변경하지 않으며, 디스크 압축 해제를 하지 않는 기존 처리도 유지한다.

실패한 실행의 남은 macOS 작업은 중단하고 수정 커밋으로 두 OS 빌드를 다시 실행한다. 첫 실행에서는 릴리스가 생성되지 않았다.

## OS별 패키지 검사 진행

배포 소스 커밋은 `17f2be2005443e0f1473adc98ad65168e4f1ae66`이다. [수정 후 Actions 실행 39761299122](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/39761299122)에서 Windows Python 검사 105개와 화면 검사 13종이 모두 통과했다. Windows x64 패키징·포함 도구·미디어·HTTP·복구·정상 종료 검사도 통과해 아티팩트를 생성했다.

같은 실행에서 macOS 소스 검사는 통과했으나 LGPL·MPL 대응 소스 다운로드가 `SSL: UNEXPECTED_EOF_WHILE_READING`으로 실패했다. 고지·대응 소스 단계를 생략하거나 TLS 검증을 끄지 않고, 같은 커밋의 실패 작업만 재실행했다. 성공한 Windows 산출물은 재사용한다.

## 최종 결과

- [0.20.0 공개 사전 검증판](https://github.com/redpanya/Chi_Da_analyzer/releases/tag/v0.20.0-preview.1) 게시 완료. 태그 이름은 `v0.20.0-preview.1`, 대상 커밋은 `17f2be2005443e0f1473adc98ad65168e4f1ae66`이다. 최초 초안 생성 후 사용자의 공개 릴리스 요청에 따라 게시했다. 기존 공개판은 유지하고 README의 현재 다운로드 링크를 새 릴리스로 변경했다.
- [Actions 39761299122](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/39761299122) 재시도 후 macOS·Windows·초안 생성 모두 성공했다.
- macOS: Python 105개 중 103개 통과, Windows 전용 2개 제외. JavaScript 13종 통과. 앱 패키지 독립 실행·포함 도구·한글 경로·미디어 디코딩·원음 추출·기존 자료 복구·HTTP·정상 종료 통과.
- Windows: Python 105개 모두 통과, JavaScript 13종 통과. 포터블 패키지 독립 실행과 같은 미디어·복구·HTTP 검사 통과. UTF-8 강제 환경을 해제한 cp1252 실행에서도 한글·일본어·이모지 메타데이터 처리 통과.
- macOS ZIP을 `ditto`와 `unzip`으로 각각 풀어 ASCII 파일명과 임시 서명을 검증했다. LaunchServices를 통한 앱 실행·로컬 서버 응답도 통과했다. `spctl` Gatekeeper 검사는 미공증으로 거절됐다. 인터넷에서 다운로드한 앱의 첫 실행 승인은 검증하지 않았다.
- Windows Vulkan 엔진 동봉과 CPU 처리 경로는 확인했다. 러너에 Vulkan 드라이버가 없어 GPU 추론 실측은 미검증이다.
- 배포 파일 9개의 업로드 완료 상태를 확인했다. 체크섬 목록의 8개 SHA-256이 GitHub가 제공한 업로드 digest와 일치했다. 내려받은 두 검사 JSON과 체크섬 목록도 각각 해시가 일치했다. 이 Mac에서 대용량 배포 ZIP 전체를 다시 다운로드·실행하지는 않았다.
- 모델 추론을 실행한 검증은 아니다. 실제 VOD 다운로드, 장시간 전사·요약, 외부 AI 결과 품질과 사용자 장치 사용성 검증은 별도다. 원본·기존 결과를 변경하는 실사용 작업은 실행하지 않았다.

## 공개 릴리스 게시 확인

2026-10-22 20:00:34 KST에 `v0.20.0-preview.1`을 공개했다. GitHub 응답은 `isDraft=false`, `isPrerelease=true`이며 일반 이용자가 다운로드할 수 있는 사전 검증판이다.

GitHub 최신 main과 빌드 커밋의 차이는 배포 검증 문서뿐임을 확인했다. 실행 코드·의존성·패키징 설정이 같으므로 Actions 39761299122에서 성공한 macOS arm64·Windows x64 패키지를 재사용했다. 불필요한 재빌드나 기존 첨부 교체는 하지 않았다.

공개 전 첨부 9개의 상태와 SHA-256을 다시 확인하고 검사 보고서를 읽었다. macOS·Windows 다운로드 링크를 릴리스 본문에 추가하고, 저장소 README와 배포용 README 템플릿을 새 릴리스 주소로 갱신했다. 원본 VOD·모델·사용자 분석 결과에는 접근하거나 변경하지 않았다.

공개 후 인증 없는 HTTP HEAD 요청으로 두 OS ZIP 주소가 모두 HTTP 200을 반환함을 확인했다. ZIP 전체를 다시 내려받는 검사는 반복하지 않았다.

서명·공증 및 실제 모델 추론 검증의 한계는 위 기록과 동일하다.
