# 개별 소품 50% 축소와 간격 재배치

작업일: 2026-10-24

## 요청 해석 정정

2026-10-23 작업은 여러 소품이 담긴 512px 시트를 256px로 줄이고, 시트 묶음 사이에 96px 간격을 넣었다. 사용자가 원한 것은 소품 하나하나의 50% 축소와 소품 사이 간격 조정이므로 해당 묶음 배치를 이번 작업으로 대체했다.

## 변경 내용

- 기존 픽셀 WebP 8종에서 독립된 소품 영역 20개를 지정한다. 각 폴더의 소품 종류는 모두 사용하며, 같은 종류의 중복 그림은 대표 영역 하나를 재사용한다.
- 시트 전체를 반복하지 않고, 각 칸에 뿔·꽃가지·리본·장신구 하나씩만 표시한다.
- 개별 소품의 가로·세로는 기존 512px 시트에서 보이던 크기의 정확히 50%다. 이전 256px 시트를 다시 절반으로 줄여 25%로 만드는 변경은 아니다.
- 반복 칸은 156×156px이며 소품은 칸 중앙에 둔다. 표시 영역은 최대 97×100px로, 인접 칸의 소품 사이에는 최소 56px 여백이 생긴다. 남는 가로 공간은 균등 분배한다.
- 행마다 소품 순서를 한 칸 이동시켜 같은 장식만 세로로 계속 쌓이지 않게 한다. 문서를 열 때 8종 중 하나를 무작위 선택하고, 창 크기나 메뉴 변경에서는 선택을 유지한다.
- 불투명도는 이전에 조정한 28%를 유지한다.
- 앱·매뉴얼은 같은 CSS/JS를 사용한다. 매뉴얼 HTML의 파일 해시를 갱신해 이전 배치가 캐시에 남지 않게 한다.

## 영향 및 예외 처리

- WebP·원본 PNG는 수정하거나 다시 생성하지 않는다. 기존 시트의 일부를 CSS 배경 위치와 영역 크기로 표시하므로 이미지 파일 수와 용량은 증가하지 않는다. WebP 총 183,728바이트 유지.
- 선택된 시트 한 장만 요청하며 기존 서버 허용 경로, 보안 설정, 패키징 자원 목록을 그대로 사용한다.
- 장식은 본문 공간을 차지하지 않고 클릭을 받지 않는다. 보조기술, 인쇄, 강제 고대비에서는 제외한다.
- 창 크기 변경 시 필요한 행·열만 다시 계산한다. 행·열이 같으면 DOM을 다시 만들지 않는다. 156px보다 좁은 창은 한 칸을 부분 표시하며 장식 때문에 스크롤이 추가되지는 않는다.
- 이미지가 없는 경우 기존 단색 배경을 유지한다. VOD·분석 결과·사용자 설정에는 변경이 없다.
- 다음에 시트 그림의 좌표나 구성이 바뀌면 소품 영역도 함께 갱신해야 한다. 현재 시트의 픽셀 형태를 보존하기 위해 이미지 재생성 대신 표시 영역을 지정했다.
