# 치(지직) 다(시보기) 분석기 사용 안내

치지직 VOD를 가져와 채팅·음성 전사·AI 문맥 요약을 함께 탐색하는 로컬 프로그램입니다.

## 0.20.0 변경 내용

- `v0.20.0-preview.5`: 작업 단계·다운로드 화질·지정 구간 설정, Gemma/외부 AI 클립 후보와 채팅 탐색 근거, 댓글 시각 편집을 추가했습니다. 클립 만들기에서 화면 배치·전사 자막·설치 글꼴·맞춤 템플릿·PNG 이미지를 편집합니다. 별도 영상 나누기에서는 전체 또는 선택 오디오를 재인코딩 없이 보존합니다. 배포 FFmpeg의 PNG 지원과 동봉 한국어 글꼴도 보완했습니다.

- `v0.20.0-preview.4`: 댓글을 한 줄씩 편집하는 목록으로 변경했습니다. 나중에 체크한 항목도 시각순으로 들어가고 기존 편집 제목은 유지합니다. 목록에 담은 영상 구간만 이어 재생하며 빈 시간은 건너뜁니다. 목록 초기화와 AI 문맥 미리보기의 3초 앞뒤 이동을 제공합니다. 이전 메모 원문도 보존합니다.

- `v0.20.0-preview.3`: 요약 실패·사용 가능한 전사 없음 항목도 댓글에 포함할 수 있습니다. 시작 시각과 상태 문구로 추가되며 제목은 직접 편집할 수 있습니다. 편집한 제목은 보존합니다. 아직 처리 중이거나 시각 확인이 필요한 항목은 제외합니다.
- AI 문맥 정리에서 사용할 전사·화자 결과를 이름과 처리 조건으로 확인해 선택합니다. 개별 전사·화자 버전은 휴지통으로 보낼 수 있으며 기존 요약과 원본은 유지합니다.
- 기존 Gemma 상세 요약과 별도로 대화 주제 변경 중심의 빠른 타임스탬프 모드를 제공합니다. 두 결과는 별도 탭에서 확인합니다.
- 더보기 → 외부 AI 파일 분석에서 분할 JSON과 `작업서.txt`를 ZIP 하나로 저장합니다. 외부 AI에 직접 전달해 묶음별 JSON 결과를 받은 뒤 결과 ZIP 또는 JSON을 가져와 검사하고 새 버전으로 저장합니다. API 연결과 자동 전송은 없습니다.
- 일부 결과 오류는 파일별로 표시합니다. 정상 묶음만 먼저 저장할 수 있으며 나머지는 추가로 가져와 합칠 수 있습니다. 외부 AI의 연속 처리·파일 생성과 요약 정확도는 서비스에 따라 달라집니다.
- 댓글용 타임스탬프를 편집한 뒤에도 새로 선택한 항목이 시간순으로 추가됩니다. 저장한 VOD 제목 옆에는 전체 길이를 표시합니다.
- Mac에서 과거 Windows 전사의 GPU 안내가 현재 장치 정보처럼 표시되던 부분을 수정했습니다.

### 외부 AI 파일 사용 순서

1. 더보기 → 외부 AI에서 전사·선택 화자 데이터와 결과 종류를 골라 내보내기를 만듭니다.
2. `분할 JSON + 작업서 ZIP 저장`을 눌러 받은 ZIP을 외부 AI에 직접 첨부합니다. ZIP을 읽지 못하는 서비스는 압축을 풀어 작업서와 자료를 첨부합니다.
3. 작업서에 따라 파일 번호순으로 처리하고 개별 결과 JSON을 받습니다. 서비스가 멈추면 완료한 파일을 보관하고 다음 번호부터 이어서 요청합니다.
4. 결과 JSON만 ZIP으로 묶어 가져옵니다. `결과 검사·미리보기` 후 `새 결과 버전으로 저장`을 누릅니다. 일부 오류가 있으면 오류를 확인하고 `정상 결과만 부분 저장`에 동의해야 저장됩니다.
5. 누락된 결과를 나중에 추가하면 같은 외부 작업의 기존 정상 결과와 합쳐 새 버전으로 저장합니다. 기존 Gemma 결과·원문·수동 교정은 덮어쓰지 않습니다.

외부 서비스에 전달하는 파일에는 선택한 전사 내용·시각·화자 정보와, 상세 문맥·클립 후보 모드인 경우 채팅 내용이 포함됩니다. 서비스의 데이터 처리 방침을 확인하고 필요한 자료만 직접 첨부하세요. 기존 전체/분할 TXT 방식도 접힌 메뉴에서 계속 사용할 수 있습니다.

## 다운로드와 실행

GitHub Releases의 운영체제에 맞는 ZIP 전체를 풀어 사용합니다. 실행 파일만 옮기면 동작하지 않습니다.

배포 파일명은 `ChiDaanalyzer-macOS-arm64.zip`·`ChiDaanalyzer-Windows-x64.zip`입니다. 앱 내부 안내 파일은 `README.ko.md`이며 본문과 화면은 한국어입니다. 이전 이름의 앱을 종료한 뒤 새 앱으로 기존 보관함을 선택합니다. 앱 이름 변경으로 모델·보관함 경로가 이동하지 않습니다.

- macOS Apple Silicon: `ChiDaanalyzer.app`을 응용 프로그램 폴더로 복사합니다. macOS 14 이상을 빌드 대상으로 삼으며 실제 실행 확인 OS는 릴리스 검증 기록에서 확인합니다. Intel Mac은 이번 배포 대상에서 제외합니다.
- Windows x64: `ChiDaanalyzer` 폴더를 풀고 `ChiDaanalyzer.exe`를 실행합니다. Windows 10/11 x64, AVX 지원 CPU가 필요합니다. 창과 브라우저가 열립니다. 브라우저를 닫아도 작업은 계속되며 실행 창에서 Ctrl+C로 작업을 정리한 뒤 종료합니다.
- macOS 추론은 기존 Metal을 사용합니다. Windows는 왼쪽 아래 설정 → Windows AI 처리 장치에서 `CPU만 사용`(기본) 또는 `CPU + GPU 가속 (Vulkan)`을 적용합니다. 기존 CPU 전용 ZIP에는 GPU 엔진이 없으므로 새 Windows x64 배포본이 필요합니다.
- GPU 선택은 전사·Gemma 요약에 적용합니다. Vulkan 지원 그래픽 드라이버가 필요하며 SDK는 사용자 PC에 설치하지 않아도 됩니다. GPU 감지 실패 시 CPU로 실행하고 사유를 표시합니다. GPU 메모리 부족·실행 오류는 CPU로 변경 후 재시도하세요. CPU도 입력 처리와 일부 연산을 담당하며 CPU/GPU 사용률을 강제로 높이지 않습니다. 다운로드·음성 추출·재생·화자 구분은 이 옵션의 대상이 아닙니다.

macOS는 임시 서명만 적용합니다. Developer ID 서명과 Apple 공증이 없으며 Windows Authenticode 서명도 없습니다. 운영체제 경고가 나타날 수 있으므로 출처와 SHA-256을 확인하세요. 보안 기능 전체를 끄는 조치는 필요하지 않습니다.

macOS의 ZIP 해제 후 서명·앱 실행 검사와 인터넷 다운로드 앱에 대한 Gatekeeper 허용은 별도입니다. 미공증 초안은 Gatekeeper에서 차단될 수 있습니다. 파일 출처와 체크섬이 확인된 경우 Apple의 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 `확인 없이 열기`가 제공되는지 확인할 수 있습니다. 이 버튼이 없으면 실행이 보장되지 않습니다. 정상 서명·공증 배포가 준비되기 전까지 경고 없는 일반 배포본으로 취급하지 않습니다. 앱이 손상됐다고 나오면 서명 검사 결과를 먼저 확인하고, 보안 설정 전체를 해제하지 마세요.

## 준비와 순서

1. 왼쪽 아래 설정에서 VOD 보관함과 모델 폴더를 정합니다.
2. VOD 리스트 등록에 주소 또는 저장한 VOD를 추가합니다. 새 자료는 영상·제공 채팅을 받고 완료된 단계는 재사용합니다.
3. 음성 전사에서 모델을 내려받고 원본 음성으로 전사합니다.
4. 필요하면 sherpa 화자 모델을 내려받아 화자를 구분합니다. 화자 구분 없이도 요약할 수 있습니다.
5. Gemma 4 E4B 모델을 내려받아 문맥을 정리합니다. 문맥·채팅 반응의 시각을 눌러 영상을 확인하고 댓글용 타임스탬프를 선택·편집·복사합니다.

AI 모델과 개인 자료는 앱에 포함하지 않습니다. 처음 준비할 때만 각 모델 배포처에 접속하며, 내려받은 모델로 전사·요약은 로컬에서 처리합니다. 전사·요약·화자 배정은 자동 추론 결과이므로 오류가 있을 수 있습니다. 모델별 이용 조건은 각 다운로드 출처의 조건을 따릅니다.

기본 ZIP의 화자 엔진은 sherpa입니다. 화자 구분 화면에서 sherpa·pyannote·FluidAudio 실행 도구의 설치 상태를 확인하고 별도로 설치할 수 있습니다. 추가 도구는 이 경량 ZIP에 포함하지 않습니다. Windows의 추가 도구는 해당 OS 파일이 배포된 경우에 설치할 수 있습니다. Community-1을 별도로 설치하면 첫 모델 다운로드에 Hugging Face 계정의 이용 동의와 로컬 인증이 필요합니다. FluidAudio는 Apple Silicon 전용입니다.

## 여러 VOD와 자동 분석

가져오기 → VOD 리스트 등록에서 ＋/−로 주소 입력칸을 조절한 뒤 목록에 등록합니다. 다운로드만 또는 원음 추출 → 전사 → 선택 화자 구분 → 채팅 반응 → Gemma 요약까지 진행합니다. 말소리 분리는 사용하지 않습니다. 필요한 모델을 먼저 준비하세요.

한 VOD의 선택한 단계가 끝나면 다음 VOD를 처리합니다. 일시정지 후 이어갈 수 있으며 앱 재실행만으로 작업이 시작되지는 않습니다. 기존 유효 결과는 재사용하고 원본·수동 수정·이전 분석을 보존합니다. 목록에서 제거해도 VOD 파일은 삭제하지 않습니다.

## 성능 리포트 이메일 제공(선택)

더보기 → 작업 기록에서 실행 기록과 PC 사양·단계별 시간·처리량을 확인합니다. JSON 미리보기 → 파일 저장 후, 제공을 원하는 경우 `redpanyaday@gmail.com`으로 직접 첨부해 보내세요. 앱에서 자동 전송하거나 Google Drive에 업로드하지 않습니다.

JSON에는 같은 영상의 기기별 성능 비교를 위해 VOD 번호가 포함됩니다. 전사·채팅·요약 원문, 파일 경로, 인증정보와 로컬 상세 로그는 포함하지 않습니다. 메일 발송 시 발신 주소·표시 이름이 수신자에게 전달될 수 있습니다. 보내주신 정보는 분석기 개선에 사용하며 보내지 않아도 분석 기능을 사용할 수 있습니다. 삭제 문의도 같은 주소로 보내주세요.

## 저장과 복구

- macOS 기존 설정: `~/Library/Application Support/치지직 보관함`. 기본 모델: `~/Library/Caches/chzzk-archive`.
- Windows 설정: `%LOCALAPPDATA%/ChiDaAnalyzer`. 기본 모델: 그 아래 `models`. 기본 보관함: `~/Videos/ChiDaAnalyzer`.
- 실제 저장 위치는 설정 페이지에서 확인·변경합니다. 기존 macOS 폴더 이름은 호환성을 위해 유지합니다.
- 포터블은 별도 Python 설치가 필요 없다는 뜻입니다. 설정·모델은 위 사용자 폴더에 저장하므로 앱 폴더 하나만 옮겨 모든 자료가 이동되는 방식은 아닙니다.
- 강제 종료 후 앱을 다시 열면 완료 자료를 유지하고 중단 상태를 복구합니다. 작업 종류에 따라 조각 이어받기 또는 재시작이 필요합니다. 실행 중인 VOD 폴더를 직접 수정하거나 이동하지 마세요.
- 원본·전사·수동 수정·이전 분석은 앱 업데이트만으로 삭제하지 않습니다. 운영체제를 옮겨 기존 보관함 전체를 이어 쓰는 이관 기능은 이번 검증 범위에 포함하지 않습니다.

## 배포 상태

현재 공개 저장소의 사전 검증판입니다. CI의 실행 파일 시작·포함 도구·잠금·파일 처리 검사는 실제 VOD 전체 다운로드, 장시간 전사·Gemma 추론의 품질·속도 검증을 대신하지 않습니다. 실제 사용 장치에서 대표 작업을 확인해야 하며, 자동 검사 통과를 모델 품질·속도 검증으로 해석하지 마세요.

## 0.19.0 결과 확인 화면

일반 전사와 화자 배정 전사를 분리했습니다. 화자 검토는 화자 목록·배정된 전사·인식 실패 탭으로 나뉩니다. 통합 분석은 재생기 아래 공통 시간축에서 전체·30분·10분·2분으로 확대해 탐색합니다. AI 문맥 정리에는 선택적인 방송 배경 설명을 저장할 수 있으며 정상 요약의 채팅 반응과 실패 요약의 원문 참고를 함께 보여줍니다. 새 로컬 영상 첨부는 제거했지만 기존 가져온 자료와 결과는 유지합니다.

외장 보관함의 채팅 정리는 내장 임시 폴더의 SQLite DB에서 수행합니다. 이미 받은 채팅 응답은 재사용하며 실제 보관함과 결과 파일은 기존 경로에 남습니다.
