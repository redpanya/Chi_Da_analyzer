# 치(지직) 다(시보기) 분석기 사용 안내

치지직 VOD 또는 로컬 영상을 가져와 채팅·음성 전사·AI 문맥 요약을 함께 탐색하는 로컬 프로그램입니다.

## 다운로드와 실행

GitHub Releases의 운영체제에 맞는 ZIP 전체를 풀어 사용합니다. 실행 파일만 옮기면 동작하지 않습니다.

- macOS Apple Silicon: `.app`을 응용 프로그램 폴더로 복사합니다. macOS 14 이상을 빌드 대상으로 삼으며 실제 실행 확인 OS는 릴리스 검증 기록에서 확인합니다. Intel Mac은 이번 배포 대상에서 제외합니다.
- Windows x64: `Chi_Da_analyzer` 폴더를 풀고 `Chi_Da_analyzer.exe`를 실행합니다. Windows 10/11 x64, AVX 지원 CPU가 필요합니다. 창과 브라우저가 열립니다. 브라우저를 닫아도 작업은 계속되며 실행 창에서 Ctrl+C로 작업을 정리한 뒤 종료합니다.
- 첫 기준판: macOS 추론은 Metal, Windows 추론은 CPU입니다. Windows CUDA/Vulkan GPU 가속 패키지는 포함하지 않습니다. Windows GPU가 있어도 이 빌드의 AI 추론은 빨라지지 않습니다.

macOS는 임시 서명만 적용합니다. Developer ID 서명과 Apple 공증이 없으며 Windows Authenticode 서명도 없습니다. 운영체제 경고가 나타날 수 있으므로 출처와 SHA-256을 확인하세요. 보안 기능 전체를 끄는 조치는 필요하지 않습니다.

## 준비와 순서

1. 가져오기에서 VOD 보관함과 모델 폴더를 정합니다.
2. 치지직 주소로 영상·제공 채팅을 받거나 로컬 영상과 치지직 주소를 함께 입력합니다.
3. 음성 전사에서 모델을 내려받고 원본 음성으로 전사합니다.
4. 필요하면 sherpa 화자 모델을 내려받아 화자를 구분합니다. 화자 구분 없이도 요약할 수 있습니다.
5. Gemma 4 E4B 모델을 내려받아 문맥을 정리합니다. 문맥·채팅 반응의 시각을 눌러 영상을 확인하고 댓글용 타임스탬프를 선택·편집·복사합니다.

AI 모델과 개인 자료는 앱에 포함하지 않습니다. 처음 준비할 때만 각 모델 배포처에 접속하며, 내려받은 모델로 전사·요약은 로컬에서 처리합니다. 전사·요약·화자 배정은 자동 추론 결과이므로 오류가 있을 수 있습니다. 모델별 이용 조건은 각 다운로드 출처의 조건을 따릅니다.

기본 ZIP의 화자 엔진은 sherpa입니다. 기존 개발 환경의 pyannote·FluidAudio와 기존 결과 열기 기능은 유지하지만 이 경량 ZIP에 추가 엔진은 포함하지 않습니다. Community-1을 별도로 설치하면 첫 모델 다운로드에 Hugging Face 계정의 이용 동의와 로컬 인증이 필요합니다. FluidAudio는 Apple Silicon 전용입니다.

## 저장과 복구

- macOS 기존 설정: `~/Library/Application Support/치지직 보관함`. 기본 모델: `~/Library/Caches/chzzk-archive`.
- Windows 설정: `%LOCALAPPDATA%/ChiDaAnalyzer`. 기본 모델: 그 아래 `models`. 기본 보관함: `~/Videos/ChiDaAnalyzer`.
- 실제 저장 위치는 가져오기 페이지에서 확인·변경합니다. 기존 macOS 폴더 이름은 호환성을 위해 유지합니다.
- 포터블은 별도 Python 설치가 필요 없다는 뜻입니다. 설정·모델은 위 사용자 폴더에 저장하므로 앱 폴더 하나만 옮겨 모든 자료가 이동되는 방식은 아닙니다.
- 강제 종료 후 앱을 다시 열면 완료 자료를 유지하고 중단 상태를 복구합니다. 작업 종류에 따라 조각 이어받기 또는 재시작이 필요합니다. 실행 중인 VOD 폴더를 직접 수정하거나 이동하지 마세요.
- 원본·전사·수동 수정·이전 분석은 앱 업데이트만으로 삭제하지 않습니다. 운영체제를 옮겨 기존 보관함 전체를 이어 쓰는 이관 기능은 이번 검증 범위에 포함하지 않습니다.

## 배포 상태

현재 비공개 저장소의 사전 검증판입니다. CI의 실행 파일 시작·포함 도구·잠금·파일 처리 검사는 실제 VOD 전체 다운로드, 장시간 전사·Gemma 추론의 품질·속도 검증을 대신하지 않습니다. 공개 전 실제 두 OS에서 대표 작업을 확인해야 합니다. 준비가 끝나도 저장소 공개 전환은 소유자가 별도로 진행합니다.
