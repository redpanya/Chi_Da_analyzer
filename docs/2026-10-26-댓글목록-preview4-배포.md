# 댓글 목록·구간 이어 재생 릴리즈

작업일: 2026-10-26
대상: v0.20.0-preview.4, macOS Apple Silicon 및 Windows x64

## 범위

이전 로컬 구현에 대한 추가 배포 요청으로 패키징·GitHub 게시를 진행한다. 기존 preview.3 릴리즈·태그와 방송 원본·전사·화자 배정·요약 결과는 유지한다. 앱 표시 버전은 0.20.0이며 릴리즈 태그로 이번 수정 빌드를 구분한다.

## 포함 기능

- 댓글용 타임스탬프를 항목별로 편집하고 늦게 선택한 항목도 시각순 중간 위치에 삽입한다.
- 선택 구간만 시간순 이어 재생하며 구간 사이의 공백은 건너뛰고 중첩 구간은 한 번만 재생한다.
- 목록 전체 복사·목록 초기화, AI 문맥 미리보기의 3초 앞뒤 이동을 제공한다.
- 이전 자유 메모와 제목을 보존하며 구간을 확정할 수 없는 기존 줄은 복사에 유지하고 이어 재생에서는 제외한다. 첫 목록 저장 시 구형 댓글 JSON을 별도로 보관한다.
- 일부 요약 실패·전사 없음 항목의 댓글 선택은 유지한다. 구형 앱이 목록 형식을 덮어쓰는 요청과 동시 편집 충돌을 차단한다.

## OS별 검증 결과

- 두 OS 각각 Python 109개, JS 14개 검사 파일과 픽셀 패턴 검사 1개 통과. 댓글 목록 저장·구형 메모 보존·동시 편집 충돌 및 시각순 삽입·이어 재생을 포함한다.
- 독립 패키지 실행, 난수 경로 HTTP·정적 모듈 응답, 원음 추출, 이미 받은 영상·채팅의 오프라인 복구와 원본 보존 검사 통과.
- macOS ZIP을 ditto·unzip으로 각각 해제한 뒤 임시 서명과 영문 경로, LaunchServices 앱·백엔드 시작·HTTP 응답을 확인했다.
- macOS Gatekeeper는 미공증 때문에 rejected로 기록됐다. 인터넷에서 내려받은 앱의 최초 실행 허용은 검증하지 않았다.
- Windows CI는 Vulkan 드라이버 없는 CPU 실행을 확인했다. 사용자 Windows PC에서 GPU 재생·추론 실측은 하지 않았다.
- 배포 첨부 9개 크기·GitHub digest·SHA256SUMS 일치. ZIP 6개 CRC 무결성 검사 통과. 양쪽 앱의 변경 웹 소스 및 배경 자원 20개가 소스와 일치했다(Windows 텍스트 CRLF만 정규화).

## 매뉴얼

시간순 삽입·항목별 편집·이전 메모 보존·선택 구간 이어 보기·3초 이동·전체 복사·목록 초기화를 안내한다. 예전 메모 편집기 화면을 새로운 가상 목록 화면으로 대체했다. 11개 주제·63개 안내·설명별 화면 32개 및 링크·로컬 자원·표시 범위 검사를 통과했다. 내부 브라우저의 로컬 file URL 열기는 보안 정책으로 차단돼 이번 매뉴얼 시각 재검사는 수행하지 않았다. 기존 실제 브라우저의 기능 검증 및 이번 HTML 정합성 결과와 구분한다.

## 검증 한계

Windows 실기기·GPU·장시간 VOD/AI 추론을 다시 실행하지 않는다. macOS Developer ID 서명·공증 및 Windows Authenticode 서명은 이번 작업에 포함하지 않는다. 사용자 자료를 CI로 전송하지 않으며 CI는 가상 자료를 사용한다.
