# 치다 분석기 1.2.1 정식 배포

## 변경 내용

믹스 편집기에서 구간 카드의 × 버튼으로 해당 구간을 제거할 수 있다. 현재 구간을 제거하면 편집 단계를 유지하면서 다음으로 편집할 수 있는 구간을 연다. 마지막 구간을 제거하면 빈 목록을 표시한다. 각 VOD의 담은 클립과 원본 영상은 보존한다.

1.2.0에서 변경한 배포 파일은 편집기 소스 네 개, 회귀 검사, 버전 정보와 사용 안내다. Electron 앱과 Python 처리기의 버전은 1.2.1이다. [배포 커밋](https://github.com/redpanya/Chi_Da_analyzer/commit/4883a04e20e00e7d454c3cfdca692e06de30c824)

## 검증

배포 체크아웃에서 자바스크립트 검사 172개와 믹스 처리 검사 8개가 통과했다. 두 운영체제의 빌드에는 같은 커밋을 사용했다. [GitHub Actions 실행](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/43896626578)

- Windows x64는 GitHub Actions에서 최종 포터블 ZIP을 풀어 Electron 화면과 Python 처리기 기동을 확인했다. 업데이트로 실행 파일을 교체하고 재시작하는 경우와 새 앱 시작에 실패해 이전 앱을 복원하는 경우 모두 기존 사용자 자료를 보존했다. [Windows 검사 결과](https://github.com/redpanya/Chi_Da_analyzer/releases/download/v1.2.1/windows-update-smoke.json)
- GitHub의 macOS arm64 실행기가 수용량 부족으로 배정되지 않아 Apple Silicon Mac에서 같은 커밋으로 빌드했다. 로컬 개발용 FFmpeg는 HTTPS 수신 검사에서 탈락했다. 외부 도구의 소스와 빌드 설정이 1.2.0과 동일한 것을 확인하고 체크섬을 확인한 1.2.0 정식 DMG의 네이티브 도구를 재사용했다. Python 처리기와 앱은 1.2.1 소스로 다시 빌드했다. 완성된 DMG의 무결성을 검사하고 읽기 전용으로 열어 앱 기동, 설정, 버전, HTTPS 범위 수신을 확인했다. [macOS 검사 결과](https://github.com/redpanya/Chi_Da_analyzer/releases/download/v1.2.1/macOS-arm64-smoke.json)
- macOS 소스 검사 243개 중 240개, 기능 검사 234개 중 227개가 통과했다. 나머지 10개 중 4개는 Windows 전용이며 6개는 테스트 영상 생성용 인코더가 없어 건너뛰었다. 두 패키지 안의 편집기 파일 네 개와 업데이트 공개키도 배포 커밋과 대조했다.
