# 픽셀 배경 GitHub 반영·공개 매뉴얼 갱신·OS별 빌드

작업일: 2026-10-23

## 요청과 범위

검수 통과 이미지로 만든 8종 픽셀 패턴을 앱 소스와 공개 HTML 매뉴얼에 반영하고, macOS Apple Silicon과 Windows x64 패키지를 빌드한다. 기존 공개 앱 릴리스는 유지하며, 이번 빌드는 GitHub Actions 아티팩트로 제공한다. DMG는 생성하지 않는다.

원본 이미지, VOD, 채팅, 전사와 분석 결과, 모델·설정·인증 자료는 배포하지 않는다. 공개되는 신규 이미지 자원은 최적화한 패턴 8종(전체 183,728바이트)뿐이다.

## 배포 구성

- 저장소: `redpanya/Chi_Da_analyzer` (공개)
- 앱 소스: `main`
- 매뉴얼: `codex/manual-site`의 루트 → https://redpanya.github.io/Chi_Da_analyzer/
- 앱 빌드: 기존 `앱 빌드` 워크플로의 macOS-arm64·Windows-x64 작업 사용
- 앱 표시 버전: 0.20.0 유지. 새 빌드는 커밋·Actions 실행 번호로 식별한다.
- 기존 소스 검사에 패턴 8종 선택 검사를 추가하고, 패키지 독립 실행 검사에서 CSS·JS·8종 이미지가 원본 소스와 정확하게 일치하는지 확인한다.

## 영향과 예외

- 배경 표현과 해당 정적 자원 제공 외에 다운로드·분석 동작은 변경하지 않는다.
- 공개 매뉴얼은 게시 성공 후 CDN 캐시가 갱신되어야 변경 사항이 보일 수 있다.
- CI가 실패하면 기존 공개 릴리스는 유지되며 불완전한 빌드를 배포하지 않는다.
- Apple 임시 서명·미공증, Windows 미서명 상태는 기존과 같다. 배경 추가가 OS 보안 경고를 해결하는 변경은 아니다.
- CI의 기본 실행 검사는 모델 추론 정확도·GPU 성능·실제 VOD 전체 흐름 검증과 구분한다.
