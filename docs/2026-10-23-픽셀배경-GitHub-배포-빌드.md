# 픽셀 배경 GitHub 반영·공개 매뉴얼 갱신·OS별 빌드

작업일: 2026-10-23

## 요청과 범위

검수 통과 이미지로 만든 8종 픽셀 패턴을 앱 소스와 공개 HTML 매뉴얼에 반영하고, macOS Apple Silicon과 Windows x64 패키지를 빌드한다. 기존 공개 앱 릴리스는 유지하며, 이번 빌드는 GitHub Actions 아티팩트로 제공한다. DMG는 생성하지 않는다.

원본 이미지, VOD, 채팅, 전사와 분석 결과, 모델·설정·인증 자료는 배포하지 않는다. 공개되는 신규 이미지 자원은 최적화한 패턴 8종(전체 183,728바이트)뿐이다.

## 배포 구성

- 저장소: `redpanya/Chi_Da_analyzer` (공개)
- 앱 소스: `main`
- 매뉴얼: `codex/manual-site`의 루트 → https://redpanya.github.io/Chi_Da_analyzer/
- 앱 빌드: 기존 `앱 빌드` 워크플로의 macOS-arm64·Windows-x64 작업 사용
- 앱 표시 버전: 0.20.0 유지. 새 빌드는 커밋·Actions 실행 번호로 식별한다.
- 기존 소스 검사에 패턴 8종 선택 검사를 추가하고, 패키지 독립 실행 검사에서 CSS·JS·8종 이미지가 원본 소스와 정확하게 일치하는지 확인한다.

## 영향과 예외

- 배경 표현과 해당 정적 자원 제공 외에 다운로드·분석 동작은 변경하지 않는다.
- 공개 매뉴얼은 게시 성공 후 CDN 캐시가 갱신되어야 변경 사항이 보일 수 있다.
- CI가 실패하면 기존 공개 릴리스는 유지되며 불완전한 빌드를 배포하지 않는다.
- Apple 임시 서명·미공증, Windows 미서명 상태는 기존과 같다. 배경 추가가 OS 보안 경고를 해결하는 변경은 아니다.
- CI의 기본 실행 검사는 모델 추론 정확도·GPU 성능·실제 VOD 전체 흐름 검증과 구분한다.

## 새 빌드 받기

- [macOS-arm64 빌드 아티팩트](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/39922919200/artifacts/12487702737)
- [Windows-x64 빌드 아티팩트](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/39922919200/artifacts/12488286285)

GitHub Actions 다운로드에는 로그인이 필요할 수 있으며 보관 기간은 워크플로 설정상 14일이다. 각 아티팩트에는 실행 앱 ZIP, 라이선스 고지·대응 소스 ZIP, `SHA256SUMS.txt`, `smoke.json`이 들어 있다. 앱 ZIP 이름은 `ChiDaanalyzer-macOS-arm64.zip`, `ChiDaanalyzer-Windows-x64.zip`이다.

로컬 사본은 프로젝트 상위의 `outputs/github-builds/2026-10-23-pixel-backgrounds/`에 OS별로 저장한다. `workflow-result.json`에 빌드 커밋과 각 단계의 성공 결과를 보존했다.

## 내려받은 배포물 확인

두 아티팩트를 실제 다운로드했고 OS별 ZIP 4개씩, 총 8개의 SHA-256이 동봉된 `SHA256SUMS.txt`와 일치했다. 앱 ZIP 내부의 패턴 이미지 8종은 로컬 소스와 바이트 단위로 모두 일치했다. CSS·JS도 동일하며 Windows판은 Git 체크아웃에 따른 CRLF 개행 차이만 있었다. 비교 시 텍스트 두 파일만 개행을 정규화했고 바이너리 이미지에는 정규화를 적용하지 않았다.

| 앱 ZIP | 바이트 | SHA-256 |
|---|---:|---|
| ChiDaanalyzer-macOS-arm64.zip | 102,602,919 | `2c16ac67308e257691527e14f3bbda3c69305012e0481a8655455c4dbaa7970f` |
| ChiDaanalyzer-Windows-x64.zip | 127,222,645 | `f45b4df67bee32e8916883326bf96ea2abff98538b52eb4407d74e01a95577ef` |

로컬 확인 기록은 `download-verification.json`, CI 실행 검사 기록은 각 OS 폴더의 `smoke.json`에 있다. macOS CI에서는 ZIP 두 방식 해제 후 서명 검사와 LaunchServices 앱 실행·서버 응답까지 통과했다. 이는 Apple 공증 통과를 의미하지 않는다.

## 남은 범위

새 앱으로 실제 방송 다운로드·장시간 전사·모델 추론 전체 흐름을 다시 실행하지는 않았다. Windows GPU 실기 시험, Apple 공증, Windows 서명은 진행하지 않았다. 이번 변경은 배경 표시이며 CI의 기본 실행 검사 범위와 실제 모델 처리 검증 범위를 구분한다.
