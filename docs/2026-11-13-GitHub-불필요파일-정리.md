## 영향과 예외

- 과거 앱 ZIP과 삭제한 Actions 첨부의 직접 다운로드 주소는 더 이상 사용할 수 없습니다. 최신 정식 다운로드는 유지합니다.
- 기존 SHA256SUMS는 과거 배포 구성의 증거이므로 삭제한 앱 ZIP 항목도 그대로 남깁니다. v1 릴리즈 설명에 이 점을 명시합니다.
- Git 이력 재작성은 하지 않습니다. 삭제한 문서와 이미지는 과거 커밋에 남으므로 이번 작업은 비밀정보의 완전 삭제나 저장소 이력 용량 축소 작업이 아닙니다.
- 앱 동작 및 결과 형식은 변경하지 않습니다. 새 OS 패키징과 실제 모델 추론은 수행하지 않습니다.
