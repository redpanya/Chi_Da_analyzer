## 디자인·화면·유지관리

- 기존 전단지·스티커 디자인을 유지했습니다. 왼쪽 차례를 다시 만들지 않았고 모든 설명을 기본으로 펼쳤습니다.
- 별도 임시 보관함에 가상의 12분 예시 영상·전사·채팅·화자·외부 결과를 구성했습니다. 사용자의 실제 VOD·개인 결과·인증정보는 촬영하지 않았습니다.
- 실제 앱 0.20.0 화면 17장(약 1.79MiB)을 촬영하고 31개 설명 바로 아래에 해당 부분을 표시했습니다. 이미지 본문은 수정하지 않고 CSS 표시 범위와 SVG 테두리·화살표를 사용합니다.
- 모든 화면에 설명용 예시임을 표시했습니다. 리포트는 ‘기존 결과 사용/미계측’ 예시로 구성했으며 실제 AI 속도·품질로 오해하지 않도록 안내합니다.
- 이전 공개 화면 파일은 기존 링크의 호환성을 위해 남겼지만 개정 본문에서는 새 화면만 사용합니다.
- 매뉴얼 브랜치에 `source/content.json`, `source/shots.json`, `source/images.json`, `scripts/build.py`, `scripts/check.py`를 포함했습니다. 삭제된 다른 outputs 폴더에 의존하지 않고 재생성·검사할 수 있습니다.
- 검색 안내 수를 하드코딩하지 않고 실제 주제·항목 수로 표시합니다. 필수 자원은 로컬 파일로 연결되며 분석·외부 AI·이메일 전송 코드는 매뉴얼에 없습니다.

## 영향과 예외 처리

- 앱 코드·실행 파일·GitHub 릴리스 첨부 파일·VOD 보관함·모델·수동 교정·기존 요약은 변경하지 않았습니다.
- 기존 `#setup`, `#import`, `#transcribe`, `#speakers`, `#explore`, `#summary`, `#comments`, `#help` 주제 링크를 유지하고 `#external`, `#reports`를 추가했습니다. 항목별 안내는 개정에 따라 재구성됩니다.
- 브라우저가 `file:` URL 자동 열기를 제한해, 허용된 정적 파일만 제공하는 `127.0.0.1` 미리보기에서 검증했습니다. 앱 API·폴더 목록·개인 자료는 미리보기에서 제공하지 않았습니다.
- 촬영 환경은 macOS입니다. Windows 설치·장치 옵션 안내는 현재 코드·배포 안내에 대조했으며 이번 매뉴얼 작업에서 Windows 실기기를 추가 검증하지 않았습니다.
- AI의 오류 가능성, 채팅 누락 검증과 허용의 차이, 상대 반응지수, 외부 결과의 구조 검사와 사실성 검증의 차이를 구분했습니다.
- 리포트에 VOD 번호가 포함되고 이메일 발송 시 발신 정보가 전달될 수 있음을 명시했습니다. 절대 익명·절대 무유출이라고 안내하지 않습니다.

## 검증

- 매뉴얼 생성: 11개 주제·62개 안내·31개 설명별 화면.
- 정합성 검사: 기본 펼침, 왼쪽 차례 없음, 중복 ID 없음, 내부 앵커·로컬 자원·이미지 설명·크롭/강조 경계 통과.
- JavaScript 문법 검사 통과. 기존 로컬 dist도 같은 생성·검사 통과.
- 내부 브라우저: 기본 62개 펼침, ZIP 검색 7개 결과, 댓글 편집 검색 2개 결과, 없는 검색어의 빈 상태, 검색 초기화, 모두 접기(0개 펼침)·다시 펼치기(62개), 이미지 확대·Esc 닫기, 외부 AI 주제 링크 확인.
- 표시 영역 기준 문서 가로 넘침 없음. 전사 설정·저장된 전사·외부 AI ZIP 버튼 크롭을 확대해 조작 위치와 설명을 대조했습니다.
- 설명용 앱에서 댓글 2개를 편집한 뒤 세 번째 항목이 맨 아래에 추가되는 것을 확인했습니다. 정상 JSON+잘린 JSON의 ZIP에서 오류 표시와 부분 저장 체크가 나타나는 것도 확인했습니다. 실제 외부 서비스에 전송하거나 새 사용자 결과를 저장하지 않았습니다.
- 앱 전체 회귀검사, Windows 실기기, 장시간 다운로드, 실제 Whisper/Gemma/화자 추론은 이번 문서 작업 범위에 포함하지 않습니다.
