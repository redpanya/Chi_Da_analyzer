# 최근 기능 통합 배포 및 OS 호환 검사

## 범위

현재까지 구현한 VOD 작업 설정·구간 다운로드, 세 분석 모드와 외부 AI 요청,
결과 탐색·댓글 편집, 클립 편집기, 자막·설치 글꼴·PNG 합성,
독립 영상 나누기와 전체/선택 오디오 트랙 보존을 두 OS 패키지에 반영한다.
릴리즈 태그는 `v0.20.0-preview.5`, 앱 표시 버전은 기존 `0.20.0`이다.
macOS Apple Silicon 및 Windows x64가 대상이며 DMG를 만들지 않는다.

사용자 영상·채팅·모델·전사·수동 교정·화자 배정·요약·편집 결과는 업로드하거나
수정하지 않는다. 개발 환경 전체 대신 배포용 체크아웃에 검토한 앱 파일만 반영한다.

## 확인된 문제와 보완

- 기존 FFmpeg의 `--disable-autodetect` 설정으로 PNG 디코더가 빠져 있었다.
  개발 Mac의 FFmpeg에서는 동작하던 자막/PNG 합성이 배포 FFmpeg 검사에서 실패했다.
  두 OS 빌드에 zlib를 명시하고 Windows 빌드 의존성을 추가한다.
- 기존 소스 내보내기는 글꼴 바이너리와 OFL 원문을 제외했다.
  출처 목록의 해시를 확인한 동봉 글꼴만 추가하고 사용자 설치 글꼴은 반출하지 않는다.
- 기존 Windows 검사는 최근 편집·분할 기능을 포함하지 않았다.
  OS별 네이티브 FFmpeg를 이용한 회귀 검사와 독립 실행 패키지 HTTP 검사를 추가한다.

## 검증 계획과 판정

- 기존 소스 회귀 검사와 신규 작업 설정·삭제·클립·글꼴·분할 검사.
- 가상 다중 오디오 영상의 전체/선택 트랙 분할: 영상·선택 오디오 패킷 SHA-256
  동일성, 제외 트랙 없음, 원본 파일 SHA-256 유지, 중단·재개.
- 실제 패키지에서 한글 글꼴 목록·한글/공백 자막 PNG 렌더링·PNG 클립 합성,
  선택 오디오 미리듣기 HTTP, 한글·공백 경로 검사.
- 배포 CSP와 개발 주석 옵션 차단, 포함 자산, ZIP·첨부 체크섬과 라이선스 자료 확인.

## 예외·영향 범위

- Windows는 GitHub Windows runner에서 빌드·실행한다. Mac에서의 검사만으로
  Windows 동작을 확정하지 않는다. 물리 Windows PC, GPU 추론, 브라우저 음향·재생,
  파일 선택창, 장시간 실제 VOD 처리는 별도 사용자 확인이 필요하다.
- 영상 나누기는 기존 지원 범위인 일정 프레임률 H.264/AAC MP4의 키프레임 경계에서
  스트림 복사한다. 클립 편집의 자막/효과 합성은 기존처럼 재인코딩한다.
- 기존 패키지·릴리즈는 덮어쓰지 않고 새 사전 릴리즈를 만든다.
- macOS 임시 서명만 적용하며 Developer ID 공증과 Windows Authenticode 서명은 없다.
