## 완료 내용

- `v0.20.0-preview.8`의 기존 릴리즈 ID `429060248`을 그대로 사용해 `v1`으로 전환했다. 공개 정식 릴리즈(`draft=false`, `prerelease=false`)이자 Latest다.
- 새 `v1` 태그는 preview.8과 같은 커밋 `38fed579e6377474e8d05437bdaf0674fa471f88`을 가리킨다. 재빌드하지 않았다. 앱 내부 버전 표시는 `0.20.0`을 유지한다.
- macOS·Windows 앱, OS별 고지·검증 기록, 네이티브·기타 대응 소스, SHA256SUMS까지 기존 자산 9개의 ID·파일명·크기·SHA-256이 모두 동일하다.
- 이전 앱 릴리즈 14개(공개 8개, 초안 6개)와 그 실행 파일을 삭제했다. Git 태그·소스 커밋은 삭제하지 않았다.
- README 및 배포용 README 원본, 공개 HTML 매뉴얼의 다운로드 링크와 버전 안내를 v1으로 변경했다. 설명 13개 주제·83개 안내·화면 37개와 기존 디자인은 유지했다.

## 유지한 지원 자료와 영향 처리

1. `speaker-tools-v1`: 앱의 `archive/speaker_tools.py`와 설치기에서 사용하는 고정 다운로드 경로다. 삭제하거나 태그를 바꾸면 v1 바이너리를 그대로 보존하는 조건에서 화자 도구 설치가 깨진다. 21개 기존 자산을 변경하지 않고 유지하고, 제목·설명에 설치 지원 자료임을 표시했다.
2. `license-supplement-20261020`: 과거 배포본의 라이선스·대응 소스를 계속 제공한다. 이전 앱 14개의 소스·고지·해시 자료를 삭제 전에 이곳에 보존했다. 기존 파일 3개는 유지하고, SHA-256이 동일한 파일을 공유해 37개 자산과 `source-manifest.json`을 추가했다. 총 41개 자산이다.

지원 자료는 앱 정식 릴리즈가 아니며 Latest가 되지 않는다. 현재 앱 정식 배포는 v1 하나다.

이전 버전의 원래 다운로드 주소는 더 이상 사용하지 않는다. 과거 대응 소스는 [소스 자료 릴리즈](https://github.com/redpanya/Chi_Da_analyzer/releases/tag/license-supplement-20261020)의 `source-manifest.json`에서 버전·소스 커밋·원래 이름·보관 이름·SHA-256을 찾아 받는다. 대응 소스 ZIP의 내용은 변경하지 않았다.

사용자 보관함·모델·원본 영상·채팅·분석 결과와 이미 설치된 앱에는 접근하거나 변경하지 않았다.

## 검증

- GitHub API: v1 정식·Latest 확인, 태그의 커밋 일치.
- 전환 전후: v1 자산 9개의 ID·이름·크기·해시 동일, 화자 도구 자산 21개 동일.
- 기존 로컬 배포 ZIP과 GitHub 해시 일치:
  - macOS: `12f1770f4315e6ee53063ba560c5ee9e8dc352f2f932ef2e8d153a9d38e2269a`
  - Windows: `f84a990ca1b8b61b1331ae9b5b2ee304339b037bc741cfb58eeaafae4e6a88d5`
- v1 macOS·Windows 실행 파일과 두 대응 소스 ZIP의 공개 다운로드 URL: HTTP 200.
- 이전 소스 보존: 내려받은 크기·SHA-256 및 ZIP 무결성 검사 통과, GitHub 업로드 후 모든 이전 자료의 크기·해시 대조 통과. 일시적인 TLS 시간 초과 1건은 재시도로 복구했다. 검증 완료 전 이전 릴리즈를 삭제하지 않았다.
- 정리 후 API 목록: v1과 지원 자료 2개만 남음. 이전 앱 릴리즈 14개 삭제 확인.
- 매뉴얼 생성·정합성 검사 통과. Pages [41163616673](https://github.com/redpanya/Chi_Da_analyzer/actions/runs/41163616673) 성공, 배포 커밋 `873b1dc3552f4b50325aa4f07da1329257104098`.
- 공개 매뉴얼 HTML과 로컬 산출물 전체 바이트 일치. SHA-256: `ea122e10b44c9e42b5a42800ed56f8921eba5241ffddc1291e5deaff5474b2a7`.
- 내부 브라우저에서 v1 배지와 v1 다운로드 링크 확인 후 확인용 탭은 닫았다. 앱·로컬 미리보기 서버는 실행하지 않았다.

## 검증 범위와 남은 사항

이번 작업은 기존 빌드의 정식 승격과 릴리즈 정리다. 앱 기능·Windows 실기·GPU·장시간 처리 검증을 새로 수행하지 않았으며 preview.8의 기존 검증 한계를 그대로 적용한다. 특히 Windows 전사 엔진의 네이티브 종료 문제가 모두 해결됐다고 판단하지 않는다. macOS Developer ID 서명·공증과 Windows Authenticode 서명 상태도 변경하지 않았다.
