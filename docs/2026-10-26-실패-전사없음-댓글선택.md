# 요약 실패·전사 없음 항목의 댓글 선택

작업일: 2026-10-26

## 요청과 원인

요약 실패와 사용 가능한 전사 없음 항목도 ‘댓글에 포함’을 선택해 댓글용 타임스탬프에 추가한다. 기존에는 완료 요약의 사용 가능 여부를 댓글 선택 허용 조건과 함께 사용하면서 실패·전사 없는 항목을 화면과 선택 대상 모두에서 제외했다.

## 수정 내용

- 유효한 시작·끝 시각을 가진 확정된 실패·전사 없음 항목도 체크박스가 표시되고 선택된다. 특정 VOD·제목·오류 문자열 예외 없이 기존 상태 플래그로 판단한다.
- 댓글은 `HH:MM:SS 요약 실패`, `HH:MM:SS 사용 가능한 전사 없음` 형식으로 추가된다. 실패 결과의 미검증 제목 대신 화면의 상태 문구를 사용하며 댓글에서 직접 제목을 바꿀 수 있다.
- 원문 대조 실패로 ‘요약 실패’로 표시되는 항목과 `copy_ready: false`인 실패 항목도 같은 방식으로 선택할 수 있다.
- 요약 사용 가능 여부와 댓글에 상태 문구를 넣을 수 있는지를 분리했다. 실패·전사 없음이 요약 성공 개수에 포함되거나 ‘대화 문맥 사용 가능’으로 안내되지 않는다.
- 제목 데이터가 없는 전사 없음 항목도 키·접근성 이름·댓글 줄을 안전하게 구성한다.
- 문맥 목록과 댓글 도움말, 미검증 초안 안내를 새 동작에 맞게 수정했다.

## 기존 기능 영향과 예외

- 기존 요약 JSON·원본·전사·화자 배정은 수정하지 않는다. 댓글 선택과 편집은 기존의 VOD·결과 버전별 댓글 초안 저장 경로를 사용한다.
- 직접 편집하지 않은 댓글은 시간순으로 생성한다. 직접 편집한 댓글은 보존하고 새 선택만 맨 아래에 추가한다. 같은 시각·제목이 이미 있으면 중복 추가하지 않는다.
- 편집 후 체크 해제는 사용자가 바꾼 줄을 자동 삭제하지 않는다. 기존 재생성 확인·필터 밖 선택 보존·버전 격리도 유지한다.
- 아직 이어지는 문맥(`provisional`)과 시각 확인 대상(`time_review`)은 기존처럼 선택하지 않는다. 새로 허용하는 실패·전사 없음 항목은 음수·비숫자·무한대 시각 및 시작보다 같거나 이른 끝 시각도 제외한다.
- 요약 실패가 아닌 관계 분석 실패·검토 중 요약까지 일괄 허용하지 않는다. 기존 정상 요약 선택 기준은 그대로다.
- 기존 결과도 화면을 다시 불러오면 적용된다. 전사나 요약을 다시 실행할 필요는 없다.

## 검증

- `node tests/test_context_copy.mjs` 통과: 정상·실패·전사 없음 선택, 상태 제목, 원본 VOD 시각 보정, 시간순 정렬, 해제, 직접 편집 뒤 추가, 중복 방지, 필터·폴링·버전 변경, 저장·복원과 클립보드 복사, 원본 불변.
- 실패·전사 없음의 잘못된 시각 및 처리 중·시간 확인 상태 제한, 요약 성공 개수와의 분리 확인.
- `node tests/test_context_review_ui.mjs` 통과: 실패 참고 근거·채팅 구분, 시각 없는 실패 항목 제한, 방송 설명 저장·VOD 전환 보호.
- `node tests/test_context_adaptive_ui.mjs` 통과: 문맥 보완·생략·보류 표시, 검토 중 내용 제한, 원문 보존.
- `node --check web/context.js` 통과.

개발 앱과 GitHub용 로컬 체크아웃에 반영했다. 실제 사용자 VOD의 재요약·브라우저 시각 확인·전체 기능 검사·앱 패키징·GitHub 게시 및 릴리즈 변경은 이번 작업에서 하지 않았다.
