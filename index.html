일단 이것만 알면 됨

앱 0.20.0 기준. 처음이라면 위에서 아래로 따라오세요.

요약 맛집 입장
치다 분석기, 뭐 하는 앱이에요?+

치지직 다시보기를 저장하고, 방송의 말을 글로 바꾼 뒤 주제별로 정리하는 앱이에요. 재미있던 반응 시각을 찾아 영상을 보고, 댓글에 붙일 타임스탬프도 만들 수 있어요.

기본 코스: VOD 등록 → 다운로드 → 원음 추출·전사 → AI 요약 → 영상 확인·댓글 복사. 화자 구분은 선택이에요.

전사 = 음성을 글로 옮기기 / 화자 구분 = 누가 말했는지 묶기 / 문맥 정리 = 같은 이야기끼리 요약하기. 네이버·치지직의 공식 앱은 아니에요.

이번 버전에서 바뀐 핵심+

주소 입력은 ‘VOD 리스트 등록’으로 모였어요. 여러 주소와 이미 저장한 VOD를 한 목록에 담고, 완료된 단계는 재사용할 수 있어요.

AI 문맥 정리는 ‘상세 문맥 정리’와 ‘타임스탬프’로 나뉩니다. 8번 ‘외부 AI 파일 분석’에서는 ZIP을 주고받아 외부 AI 결과도 가져와요.

새 로컬 비디오 첨부, 말소리 분리, 영상 구간 저장 기능은 현재 메뉴에서 제거됐어요. 이전에 만들어 둔 원본과 결과를 업데이트 때문에 지우지는 않아요.

빠르게 시작하는 최소 코스+

1 가져오기에서 VOD를 등록하고 ‘영상·채팅 다운로드만’으로 시작하세요. 완료되면 3 음성 전사에서 모델 준비 → 원음 추출 → 전체 전사를 진행합니다.

전사가 끝나면 6 AI 문맥 정리로 가세요. 자세히 읽으려면 ‘상세 문맥 정리’, 댓글용 주제 목록만 필요하면 ‘타임스탬프’를 선택해요.

여러 영상을 자동 처리하려면 필요한 모델을 먼저 준비한 뒤, 진행 범위를 ‘다운로드부터 AI 요약까지’로 등록하세요. 이 자동화는 상세 요약까지 진행해요.

이 설명서 보는 법+

궁금한 단어를 위 검색창에 넣어보세요. 설명은 처음부터 모두 열려 있고, 제목을 누르면 개별로 접을 수도 있어요.

화면은 관련 설명 바로 아래에 배치했어요. 주황색 표시를 따라 누르고, 이미지를 클릭하면 크게 볼 수 있어요. Esc로 닫습니다.

모든 화면은 0.20.0에서 촬영한 가상의 설명용 자료예요. 실제 방송·모델 품질·처리 속도를 보여주는 시험 결과가 아니며, Windows 화면은 일부 다를 수 있어요.

01

설치와 첫 준비

앱 ZIP을 풀고, 자료와 모델을 저장할 곳부터 정해요.

설치 드가자
내 OS에 맞는 파일 받기+

공개 릴리스에서 받으세요. https://github.com/redpanya/Chi_Da_analyzer/releases/tag/v0.20.0-preview.3

Apple Silicon Mac은 ChiDaanalyzer-macOS-arm64.zip, Windows 64비트는 ChiDaanalyzer-Windows-x64.zip을 선택해요. ‘Source code’는 실행 앱이 아니에요.

Mac은 macOS 14 이상을 빌드 대상으로 하며 Intel Mac용 파일은 없어요. Windows는 10/11 x64·AVX 지원 CPU 대상입니다. 현재는 사전 검증판이므로 기기별 동작과 AI 처리 성능은 다를 수 있어요.

압축을 풀고 앱 실행하기+

Mac은 ChiDaanalyzer.app을 응용 프로그램 폴더에 복사해 실행하세요. Windows는 ZIP 전체를 풀고 ChiDaanalyzer 폴더 안의 ChiDaanalyzer.exe를 실행해요.

앱이 연 브라우저 페이지를 사용하세요. 별도 Python 설치는 필요 없어요. 앱 폴더의 index.html을 직접 여는 방식은 아니에요.

실행 파일만 다른 곳에 옮기지 마세요. 함께 들어 있는 폴더·도구·라이선스 파일이 필요해요. 이 HTML 설명서는 앱과 별개입니다.

Mac 손상·확인되지 않은 개발자 경고+

현재 Mac 앱은 임시 서명만 있고 Apple 공증이 없어요. 인터넷에서 받은 앱에 실행 경고가 나타날 수 있습니다. 먼저 공식 릴리스 출처와 함께 제공되는 SHA-256 값을 확인하세요.

출처가 확인된 경우 시스템 설정 → 개인정보 보호 및 보안에 해당 앱의 ‘확인 없이 열기’가 제공되는지 확인할 수 있어요. 버튼이 없거나 실제 손상이 의심되면 다시 내려받고 오류 정보를 확인하세요.

보안 기능 전체를 끄지는 마세요. Windows도 Authenticode 서명이 없어 경고가 날 수 있어요. 서명·공증된 일반 배포본과 같은 실행 경험을 보장하지 않아요.

VOD 폴더와 모델 폴더 정하기+

1 가져오기 아래 ‘저장 폴더’에서 VOD 보관함 폴더를 지정하고 ‘폴더 확인’을 누르세요. 그 아래 공용 AI 모델 폴더는 ‘경로 적용’으로 변경해요.

보관함에는 VOD별 영상·채팅·분석 결과, 모델 폴더에는 여러 VOD에서 함께 쓸 AI 모델이 저장됩니다. 외장 디스크도 사용할 수 있어요.

처음이면 비어 있는 전용 상위 폴더를 선택하세요. 기존 보관함은 vod-번호 폴더들을 담는 상위 폴더를 선택합니다. 모델 경로만 바꿔도 이전 모델 파일이 자동 이사하지는 않아요.

모델 준비는 첫 사용 때+

전사 화면의 ‘전사 모델 준비·검사’, 요약 화면의 ‘요약 모델 준비·검사’를 눌러 필요한 모델을 받으세요. 화자 모델은 화자 구분을 사용할 때만 필요해요.

앱 ZIP에는 큰 AI 모델이 들어 있지 않아요. 준비를 마친 모델은 다음 실행에서도 재사용하며, 로컬 전사·요약은 내 컴퓨터에서 처리해요.

모델 다운로드에는 인터넷·저장 공간이 필요해요. 이미 준비한 모델이 다시 필요하다고 나오면 공용 모델 폴더와 외장 디스크 연결을 확인하세요. 각 모델에는 별도 이용 조건이 있습니다.

Windows CPU·GPU 선택+

Windows에서는 1 가져오기의 ‘Windows AI 처리 장치’에서 CPU만 사용 또는 CPU + GPU 가속(Vulkan)을 고르고 적용해요.

이 옵션은 음성 전사와 Gemma 요약에 적용됩니다. Mac은 기존 Metal 경로를 사용하므로 같은 Windows 선택창이 없어요.

CPU·GPU를 항상 100%로 만드는 기능은 아니에요. GPU 감지 실패·메모리 부족·실행 오류가 나면 드라이버를 확인하거나 CPU로 바꿔 재시도하세요. 화자 구분은 이 옵션의 적용 대상이 아닙니다.

업데이트와 안전한 종료+

이전 앱의 작업을 중단하고 앱을 종료한 뒤 새 앱으로 교체하세요. 기존 보관함과 모델 경로를 다시 확인하면 됩니다.

브라우저 탭만 닫아도 백그라운드 작업이 계속될 수 있어요. 앱을 완전히 종료하려면 실행 창 안내를 따르세요. Windows 실행 창에서는 Ctrl+C로 정리 후 종료합니다.

설정·모델은 앱 밖에도 저장돼요. 앱 폴더만 복사한다고 모든 자료가 이동하는 것은 아닙니다. 작업 중인 VOD 폴더를 탐색기에서 이동·수정하지 마세요.

02

VOD 리스트 등록과 이어받기

하나씩 입력해도, 여러 개를 한꺼번에 맡겨도 됩니다.

영상 모셔오기
주소를 여러 개 등록하기+

1 가져오기 → VOD 리스트 등록에 치지직 다시보기 주소 또는 naver.me 공유 주소를 붙여넣으세요. ‘＋ 주소 입력칸 추가’로 줄을 늘리고, −로 줄을 지웁니다.

위·아래 화살표로 순서를 정하고 작업 설정을 확인한 다음 ‘목록에 등록’을 누르세요. 등록 후 ‘순차 작업 시작·이어가기’를 눌러야 실제 작업이 시작돼요.

공개되어 접근 가능한 VOD가 필요해요. 삭제·비공개·접근 제한 자료는 주소만으로 받을 수 없습니다. 주소 줄 삭제와 보관함 파일 삭제는 다른 작업이에요.

다운로드만? 요약까지?+

진행 범위에서 ‘영상·채팅 다운로드만’ 또는 ‘다운로드부터 AI 요약까지’를 선택해요. 요약까지를 고르면 언어·발화 검출·용어 힌트·선택 화자 구분·Gemma 사고 여부가 나타나요.

자동화는 영상·채팅 → 원음 추출 → 전사 → 선택 화자 구분 → 채팅 반응 분석 → Gemma 상세 요약 순으로 진행해요. 한 VOD를 마친 뒤 다음 VOD로 넘어갑니다.

말소리 분리는 사용하지 않아요. 필요한 모델과 도구를 먼저 준비하세요. ‘화자 구분 실패 시 화자 불명 상태로 요약 계속’을 켜면 화자 실패 때문에 요약까지 모두 포기하지 않아도 돼요.

이미 받은 VOD도 목록에 넣기+

‘저장한 VOD 선택’을 누르고 원하는 VOD를 순서대로 체크한 다음 ‘선택 순서대로 가져오기’를 누르세요. 왼쪽 보관함의 ‘목록 등록’도 사용할 수 있어요.

작업 설정을 정한 뒤 ‘목록에 등록’하세요. 영상·채팅 등 유효한 완료 단계는 재사용하고, 필요한 다음 단계부터 처리합니다.

요약까지 진행하고 싶다면 진행 범위를 꼭 확인하세요. 이전 결과의 조건과 새 설정이 다르거나 파일이 불완전하면 해당 단계를 다시 처리할 수 있어요. 기존 결과는 보존합니다.

대기 목록 설정 바꾸기·일시정지+

아직 실행되지 않은 항목을 체크하고 설정을 바꾼 뒤 ‘선택한 대기 항목에 설정 적용’을 누르세요. 중간에 멈추려면 ‘일시정지’를 사용해요.

다시 진행할 때 ‘순차 작업 시작·이어가기’를 누르세요. 앱을 다시 켰다고 자동으로 작업이 재개되지는 않아요.

이미 실행 이력이 있는 항목의 조건을 바꾸려면 새 작업으로 등록해야 할 수 있어요. ‘목록에서 제거’는 대기 목록만 제거하며 받은 VOD 자료를 지우지 않습니다.

다운로드 완료 확인하기+

2 가져오기 진행에서 영상과 전체 제공 채팅의 상태를 각각 확인하세요. 영상 수신 뒤 검증·재생 준비가 끝나야 다음 단계로 넘어갈 수 있어요.

두 카드의 진행률과 소요 시간, 상태 문구를 확인한 뒤 ‘음성 전사 →’를 누릅니다. 채팅 반응만 먼저 보려면 ‘음성 건너뛰고 통합 분석 →’를 사용할 수 있어요.

수신량이 100%여도 검증이 남을 수 있어요. 영상이 준비되지 않았거나 ‘조치 필요’가 남아 있으면 상태 문구부터 확인하세요. 원본 MP4가 호환되면 재생과 음성 추출에 같은 파일을 사용해요.

중단·오류가 나면 어디서 이어가요?+

영상과 채팅 카드에서 ‘이어받기’ 또는 ‘다시 시도’를 누르세요. 여러 미완료 작업은 ‘미완료 작업 이어받기’로 재개할 수 있어요.

이미 받은 자료와 완료 조각을 활용합니다. 외장 보관함의 채팅 정리는 내장 임시 DB에서 처리하지만 최종 결과는 보관함에 남아요.

외장 디스크 연결, 쓰기 권한, 내장·외장 여유 공간을 먼저 확인하세요. 임시 파일이나 받은 채팅을 직접 삭제하지 마세요. 이어받기 가능한 범위는 작업 종류와 자료 상태에 따라 달라요.

전체 제공 채팅과 검증 필요의 차이+

‘전체 제공 채팅’은 치지직 서버가 다시보기에서 제공하는 범위를 모은 결과예요. ‘검증 필요’는 페이지 경계 등의 확인이 아직 해결되지 않았다는 뜻입니다.

자료 일부로도 분석하려면 해당 작업의 ‘일부 수집 자료로 분석 허용’ 또는 자동화의 ‘채팅 경계 검증이 필요한 일부 자료도 분석에 사용’을 선택하세요.

이 옵션은 누락을 복구하거나 완전성을 보장하지 않아요. 적은 반응이 실제로 조용했던 것인지 수집 부족인지 구분해야 합니다. 서버가 제공하지 않는 채팅까지 복원할 수는 없어요.

원본 저장과 VOD 삭제+

왼쪽 저장한 VOD에는 제목 뒤에 전체 길이(HH:MM:SS)가 붙어요. 2 가져오기 진행의 저장한 자료에서 영상·제공되는 채팅 파일을 내려받을 수 있어요.

‘VOD 삭제’는 해당 VOD 폴더의 원본과 관련 분석 결과를 함께 휴지통으로 보내는 기능입니다. 확인창에서 대상과 안내를 확인하세요.

한 개의 분석 결과만 지우려면 아래 전사·화자 버전 삭제 기능을 사용하세요. 실행 중에는 삭제가 제한될 수 있어요. 공용 AI 모델은 VOD 자료와 별개입니다.

03

음성을 글로 바꾸기

원음을 그대로 전사합니다. 화자 구분은 아직 안 해도 돼요.

말을 글로 쓱
원음 추출부터 시작+

3 음성 전사에서 오디오 트랙을 확인하고 ‘원음 추출’을 누르세요. 오디오가 여러 트랙이면 방송 대사가 있는 트랙을 선택해요.

영상과 같은 상대 시각을 유지하는 WAV를 만들고, 추출한 음성을 들어볼 수 있어요. 원본 영상은 그대로 남습니다.

말소리 분리 모델을 먼저 실행할 필요는 없어요. 잘못된 트랙을 선택하면 전사 내용이 적거나 다른 언어가 나올 수 있습니다.

전사 모델과 언어 선택+

‘전사 모델 준비·검사’를 눌러 Whisper large-v3-turbo 계열 모델을 준비하세요. 음성 언어는 한국어·자동 감지·영어·일본어 중 선택합니다.

한국어 방송이면 한국어로 시작하면 돼요. 여러 언어가 섞였거나 주 언어를 모르면 자동 감지를 검토하세요.

이 화면의 모델은 음성을 글로 만드는 도구예요. AI 문맥 정리의 Gemma 모델과는 역할이 다릅니다.

발화 검출: 표준·민감·끄기+

처음에는 ‘표준 · 기본’을 사용하세요. 작은 목소리가 자주 누락되면 ‘민감 · 작은 발화 포함’, 검출 자체를 우회해 비교하려면 ‘끄기 · 전체 오디오 처리’를 선택해요.

발화 검출은 소리가 말인지 먼저 골라 전사할 범위를 정하는 기능입니다. 민감으로 바꾸면 작은 발화를 더 포함할 수 있어요.

민감은 잡음도 더 포함할 수 있고, 끄기는 무음·배경음에서 없는 문장을 만들 위험과 처리량이 늘 수 있어요. 무조건 정확도가 높아지는 옵션은 아닙니다.

용어 힌트와 전체 전사+

용어 힌트에는 자주 나오는 사람·게임·아이템 이름 등을 짧게 적어보세요. 설정을 확인하고 ‘원음으로 전체 전사·이어받기’를 누릅니다.

진행률 아래에서 처리 범위와 걸린 시간을 확인해요. 같은 조건의 완료 조각은 이어서 활용할 수 있고, 조건을 바꾼 분석은 별도 결과로 남습니다.

힌트는 강제 치환 사전이 아니에요. 내용과 무관한 긴 설명은 피하고, 결과는 원음과 대조하세요. 지원 길이 안의 긴 영상도 PC 사양에 따라 오래 걸릴 수 있어요.

저장된 전사 선택·검색·교정+

‘저장된 전사’에서 날짜·모델·언어·원본 오디오·발화 검출 조건·발언 수를 보고 결과를 선택하세요. 검색으로 필요한 발언을 찾고 ‘음성 듣기’로 확인해요.

잘못된 텍스트는 ‘텍스트 교정’에서 수정할 수 있어요. 수동 교정을 반영한 새 요약을 만들 수 있으며, 기존 요약이 자동으로 다시 작성되지는 않아요.

이 페이지는 전사 자체를 보여줍니다. 화자 구분을 실행해도 이 전사 목록을 화자 이름으로 바꾸지 않고, 화자별 배정 결과는 4번 페이지에서 따로 확인해요.

전사 내보내기·개별 삭제+

‘현재 전사 내보내기 생성’으로 JSON·CSV·TXT를 만들 수 있어요. 필요 없는 버전은 선택한 뒤 ‘선택 전사 삭제’를 누릅니다.

삭제 대상 버전은 휴지통으로 이동하고 영상·채팅 원본과 기존 요약은 유지합니다. 확인창에서 대상과 연결 상태를 확인하세요.

화자 분석이나 진행 중인 외부 AI 작업이 참조하는 전사는 삭제가 제한될 수 있어요. 막히면 안내에 나온 연결 결과부터 확인하고, 작업 폴더를 수동으로 지우지는 마세요.

04

화자 구분은 하고 싶을 때만

이름이 없어도 내용 중심 요약은 가능합니다.

안 해도 됨
화자 구분을 건너뛰어도 되나요?+

네. 누가 말했는지보다 대화 내용이 중요하다면 바로 6 AI 문맥 정리로 가세요. 화자 정보를 ‘사용 안 함 · 전사 내용만 분석’으로 선택할 수 있어요.

화자 구분은 원음의 목소리 특징을 분석해 전사 시각에 연결하는 별도 작업입니다. 전사 문장만 보고 사람을 확정하는 기능은 아니에요.

여러 사람이 겹쳐 말하거나 목소리가 비슷하면 자동 분류가 틀릴 수 있어요. 화자인식 실패를 모두 손으로 고쳐야만 요약할 수 있는 것은 아닙니다.

실행 도구와 모델을 준비하기+

4 화자 구분의 ‘도구·모델 준비와 분석 설정’을 열고 엔진을 선택하세요. 먼저 실행 도구의 설치·검사 상태를 확인한 뒤 ‘선택 모델 준비·검사’를 누릅니다.

sherpa-onnx, pyannote.audio + Community-1, FluidAudio를 선택할 수 있어요. 도구와 모델은 다른 준비물이라 모델만 받아도 실행 도구가 없으면 시작할 수 없어요.

버튼은 준비 상태에 따라 ‘실행 도구 별도 설치’ 등의 이름으로 달라집니다. FluidAudio는 Apple Silicon Mac용이며, 추가 도구는 해당 OS 배포 파일이 제공될 때 설치할 수 있어요.

HF 로그인·이용 동의가 뜬다면+

Community-1 공식 모델을 처음 받는 경우, Hugging Face 계정으로 모델 페이지의 조건을 확인하고 접근 동의를 진행하세요. 앱 안내에 따라 로컬 인증도 완료해야 합니다.

웹사이트 로그인과 이 컴퓨터의 모델 다운로드 인증은 별개예요. 이미 모델이 저장되어 준비 완료라면 그 파일을 바로 사용할 수 있습니다.

비밀번호·토큰을 댓글이나 문의 메일로 보내지 마세요. 별도 동의가 없는 sherpa 모델도 라이선스가 없는 것은 아니며 각 모델의 조건은 유지돼요.

분석 실행과 버전 선택+

화자 수를 알면 입력하고, 모르면 0(자동)을 둔 뒤 ‘화자 분석·이어받기’를 누르세요. 완료 후 ‘화자 분석 버전’에서 엔진·날짜·화자 수·연결 전사를 확인해 열어요.

결과는 ‘화자 목록 / 배정된 전사 / 인식 실패’ 탭으로 나뉩니다. 다른 버전의 A화자가 같은 사람이라는 보장은 없어요.

전사 버전과 화자 버전의 연결을 확인하세요. 개별 결과를 지울 때는 ‘선택 화자 분석 삭제’를 사용하며 원본·전사·기존 요약은 남습니다.

대표 음성을 듣고 이름 붙이기+

화자 목록에서 ‘대표 음성 듣기’를 누르고 사람을 확인한 다음 이름을 입력해 ‘이름 일괄 저장’을 누르세요.

선택한 화자 분석 버전의 같은 화자 이름을 한꺼번에 바꿉니다. 배정된 전사 탭에서 실제 연결된 발언을 확인해요.

‘배정된 전사 0개’여도 감지된 음성 구간이 있어 대표 음성이 나올 수 있어요. 목소리 감지와 전사 연결은 다릅니다. 기존에 생성한 요약 문장을 자동으로 다시 쓰지는 않아요.

인식 실패는 듣고 필요한 만큼만 배정+

인식 실패 탭에서 발언 음성을 듣고 ‘화자 배정’을 열어 대상 화자를 선택하세요. 자동 화자 후보 묶음으로 후보를 좁혀 검토할 수도 있어요.

필요한 구간에는 ‘음향·문맥 후보 검토’를 사용할 수 있고, 변경은 되돌리기 기능으로 확인할 수 있어요. 수동 확정은 자동 추정보다 신중히 다뤄집니다.

묶음은 같은 사람일 확률(%)이 아니에요. 겹침·배경음·비슷한 목소리 때문에 잘못 묶일 수 있으니 후보만 보고 일괄 확정하지 마세요.

05

영상과 반응을 같은 시간축에서

긴 방송도 확대해서 필요한 순간만 살펴봐요.

여기였구나
채팅 반응 분석을 실행하기+

5 통합 분석·재생에서 ‘채팅 반응 분석’을 누르세요. 이미 현재 설정의 분석이 있으면 저장된 결과가 표시돼요.

자동화에서 요약까지 진행하면 채팅 반응 단계도 포함됩니다. 수동으로 이 페이지에 들어온 것만으로 새 분석이 항상 시작되는 것은 아니에요.

분석 기준 조정에서 집계 시간과 최소 반응 기준을 바꿀 수 있어요. 채팅이 적거나 일부만 수집됐다면 반응 후보가 적을 수 있습니다.

공통 시간축 확대·이동+

재생기 아래 공통 시간축에서 ‘전체 / 30분 / 10분 / 2분’ 또는 ＋·−로 범위를 조절하세요. 이전·다음 범위나 범위 중심 슬라이더로 긴 영상을 이동해요.

초록은 채팅량, 금색은 반응, 색상별 발언·화자와 주황 인식 실패를 같은 시각에서 확인합니다. 시간축을 누르면 영상 시각이 이동해요.

‘현재 위치’는 재생 위치 주변을 보여주고 ‘재생 위치 따라가기’는 표시 범위를 따라 움직여요. 화자 분석이 없어도 전사와 채팅으로 볼 수 있습니다.

재생·배속과 채팅 시각 보정+

재생 버튼과 배속을 사용하고, 반응 시각을 눌러 실제 영상을 확인하세요. 채팅이 일정하게 빠르거나 늦으면 ‘채팅 시각 보정’을 펼쳐 조절해요.

보정은 영상 기준의 채팅 비교 시각을 맞추는 용도입니다. 원본 채팅을 다시 쓰지 않아요. AI 문맥 작업에는 별도의 보정 설정도 있으니 같은 값을 확인하세요.

반응 폭증이 반드시 방금 대사 때문인 것은 아니에요. 화면 사건, 후원, 도배, 지연 반응 등 다른 원인일 수 있으므로 영상과 함께 판단하세요.

06

로컬 AI 문맥 정리

꼼꼼한 요약과 빠른 주제 목록, 목적대로 고르세요.

요약 드가자
상세 문맥과 타임스탬프 중 고르기+

6 AI 문맥 정리의 ‘상세 문맥 정리’는 대화 내용과 근거·채팅 반응을 읽기 위한 모드예요. ‘타임스탬프’는 대화 주제 변경 시각과 짧은 제목을 만드는 모드입니다.

빠른 타임스탬프는 전사만 추론하고 상세 근거 검토·채팅 요약을 생략합니다. 사고 끄기로 시작하며, 저장된 반응 분석의 🤩 표시는 연결할 수 있어요.

두 모드는 별도 탭·결과로 보존돼요. 정해진 1분·10분마다 무조건 자르는 방식이 아니라 같은 이야기인지 새 주제인지 판단합니다. 빠른 모드도 처리 시간은 자료와 PC에 따라 달라요.

어느 전사·화자 자료로 분석할지 선택+

‘새 문맥 정리에 사용할 데이터’에서 음성 전사를 고르세요. 날짜·모델·언어·발화 검출 조건·발언 수를 보고 버전을 구분할 수 있어요.

화자 정보는 사용하지 않거나, 선택한 전사와 연결된 분석 중 하나를 고릅니다. 선택한 전사의 수동 텍스트 교정을 반영하며 다른 페이지에서 보고 있던 버전을 바꾸지는 않아요.

이어하기는 처음 사용한 입력을 유지합니다. 다른 전사나 화자 결과로 비교하려면 ‘새로 정리’를 사용하세요. 기존 결과를 덮어쓰지 않습니다.

방송 배경 설명은 짧고 사실대로+

상세 문맥의 방송 배경 설명에 “두 사람이 근황 이야기를 나눈 뒤 협동 게임을 하는 방송”처럼 실제 배경을 적고 ‘설명 저장’을 누르세요.

게임명·방송 형태·참여자처럼 전사만으로 알기 어려운 맥락을 보조합니다. 선택 입력이므로 비워 두어도 진행할 수 있어요.

없는 사건이나 원하는 결론을 넣지 마세요. 배경 설명은 발언의 사실을 대신하지 않고, 빠른 타임스탬프 탭에서는 이 상세 설정이 표시되지 않아요.

Gemma 준비와 새 정리 시작+

‘요약 모델 준비·검사’로 Gemma 4 E4B를 준비하세요. 상세 모드는 사고 켜기가 기본이며 필요하면 체크를 끌 수 있어요. ‘전체 영상 새로 정리’를 눌러 시작합니다.

타임스탬프 탭에서는 ‘빠른 타임스탬프 새로 만들기’를 눌러요. 전사 내용을 바탕으로 정리하므로 화자 불명이어도 내용 중심으로 진행할 수 있습니다.

사고 켜기는 추론에 시간을 더 쓸 수 있지만 정확도를 보장하지 않아요. 요약의 문맥 보완은 분석용이며 원본 전사와 수동 교정을 몰래 바꾸는 기능이 아닙니다.

진행률·처리 로그·이어하기+

프로그래스 바 아래 소요 시간과 ‘처리 로그 열기’를 확인하세요. 완료된 문맥부터 읽고 선택할 수 있고, 중단했다면 가능한 작업에서 ‘이 정리 이어하기’를 사용해요.

목록이 영상 끝까지 보여도 경계 정리·근거 점검·후처리가 남아 있을 수 있어요. 최종 완료 여부는 목록 길이가 아니라 상태 문구와 로그로 확인하세요.

연속된 일부 문맥 오류는 실패 항목을 남기고 뒤 구간을 계속 처리하도록 합니다. 모델·디스크 등 작업을 지속할 수 없는 오류는 조치가 필요할 수 있어요.

대화 문맥과 채팅 반응을 나눠 읽기+

시간순 문맥 목록에서 제목과 대화 문맥, 채팅 반응을 함께 확인하세요. ‘채팅·원문 보기’를 열면 판단의 근거를 더 볼 수 있어요.

대화 요약은 전사 중심, 채팅 반응은 별도 근거입니다. ‘이 구간 재생’으로 오른쪽 영상에서 실제 장면을 확인할 수 있어요.

요약은 녹음에 없는 말이나 잘못된 의미를 만들 수 있습니다. 채팅의 추측·농담을 방송자의 발언 사실로 받아들이지 말고 중요한 내용은 원음으로 확인하세요.

🤩 반응지수와 필터 사용하기+

문맥에 반응 후보가 겹치면 🤩와 1~10 지수가 표시돼요. ‘🤩 채팅 반응 시각’을 누르면 해당 순간으로 이동합니다.

목록 위 반응지수 필터에서 ‘1개 이상’부터 ‘10개 이상’까지 고르면 기준 이상 항목만 볼 수 있어요. 문맥 안에서는 겹치는 반응의 최고 강도를 대표로 사용합니다.

이 VOD의 채팅 반응 안에서 계산한 상대 지수예요. 다른 영상과 절대 비교하거나 재미·정확도 점수로 해석하지 마세요. 필터에 가려진 댓글 선택 항목은 자동 해제되지 않아요.

붉은 요약 실패 항목과 이전 결과+

실패한 문맥은 붉고 굵은 ‘요약 실패’로 표시돼요. 참고할 원문·대략적인 단서가 있어도 완료된 요약으로 간주하지 마세요.

정상 구간은 먼저 확인할 수 있어요. 상태에 따라 이어하기 또는 새 정리를 사용하고, ‘보존한 문맥 정리’에서 이전 버전을 골라 ‘선택 정리 열기’를 누르세요.

요약 실패·사용 가능한 전사 없음도 댓글에 포함할 수 있어요. 시작 시각과 상태 문구가 추가되므로 영상을 확인하고 제목을 직접 고쳐주세요. 처리 중이거나 시각 확인이 필요한 항목은 아직 선택할 수 없어요.

댓글용 타임스탬프 만들기

체크하고, 말투 다듬고, 복사. 댓글은 내가 직접 올려요.

복붙 준비 완
댓글에 포함 체크하기+

문맥 또는 타임스탬프 목록에서 원하는 항목의 ‘댓글에 포함’을 체크하세요. 영상 아래 댓글용 타임스탬프에 HH:MM:SS 제목 형식으로 모입니다.

예: 00:04:00 협동 게임 규칙 정하기. 처음에는 선택 항목이 시간순으로 정리돼요. 요약 실패·전사 없음도 체크하면 00:04:00 요약 실패처럼 상태 문구로 추가됩니다. 내용은 직접 편집할 수 있어요.

복사할 내용은 현재 결과 버전에 연결돼요. 다른 결과로 바꾸면 그 버전의 선택·초안을 확인하게 됩니다.

직접 편집한 뒤에도 항목 추가+

댓글용 타임스탬프 텍스트에서 제목·말투·이모지를 직접 고칠 수 있어요. 편집 후 다른 항목을 체크하면 기존 글을 유지한 채 맨 아래에 추가합니다.

수정한 문장을 통째로 다시 만들지 않아요. 수동 편집 후 체크 해제와 본문의 내용이 다를 수 있으므로 최종 글을 직접 확인하세요.

시간순으로 다시 정리하고 싶으면 ‘선택 목록으로 다시 만들기’를 사용하세요. 이 동작은 직접 편집한 초안을 선택 목록으로 교체하므로 내용을 먼저 보관하세요.

클립보드 복사와 실제 댓글 붙여넣기+

‘클립보드 복사하기’를 누른 뒤 치지직 다시보기 댓글 입력칸에 붙여넣으세요. 복사가 막히면 ‘텍스트 전체 선택’을 누르고 Ctrl+C 또는 ⌘C로 복사해요.

앱은 댓글을 자동으로 게시하지 않아요. 붙여넣은 시각과 제목을 확인하고 사용자가 직접 등록합니다.

중복 줄·원치 않는 항목·잘못된 인물 이름을 마지막으로 확인하세요. 직접 편집한 초안은 목록의 체크 상태와 완전히 같지 않을 수 있어요.

외부 AI에 맡기고 결과 가져오기

8번 페이지에서 ZIP으로 왕복. API 키는 필요 없어요.

파일 들고 왕복
외부 AI 방식은 무엇이 다른가요?+

음성 전사까지 만든 뒤 8 외부 AI 파일 분석에서 자료 파일을 내보냅니다. 그 파일을 사용자가 ChatGPT·Gemini 등 원하는 서비스에 직접 전달해요.

외부 AI가 만든 결과 JSON을 다시 치다 분석기에 가져오면 로컬 결과와 별도로 열고, 영상 이동·댓글 복사를 사용할 수 있어요.

앱의 외부 API 호출·자동 업로드 기능은 없습니다. 외부 서비스의 비용·무료 한도·첨부 지원·개인정보 처리 조건은 이용자가 확인해야 해요. 로컬 Gemma 요약도 계속 사용할 수 있습니다.

1 — 입력과 결과 종류 선택+

내보낼 음성 전사와 선택 화자 정보를 고른 뒤 결과 종류를 ‘타임스탬프 · 전사만’ 또는 ‘상세 문맥 정리’로 정하세요.

상세 정리에서만 ‘채팅 본문 포함’을 선택할 수 있어요. 필요한 경우 채팅 시각을 보정하고 ‘분석 자료 만들기’를 누릅니다.

선택 화자는 익명으로 표시하지만 전사·채팅 본문에는 이름이나 개인정보가 남을 수 있어요. 외부로 보낼 필요가 있는 자료만 선택하고 파일 내용을 직접 확인하세요.

2 — 분할 JSON + 작업서 ZIP 저장+

자료를 만든 뒤 ‘분할 JSON + 작업서 ZIP 저장’을 누르세요. ZIP 안에는 작업서.txt와 번호가 붙은 자료 JSON 파일들이 들어 있어요.

작업서가 외부 AI에 줄 요청문입니다. 파일별로 분석하고 결과 JSON을 하나씩 만들도록 안내하며, 경계의 문맥을 살필 보조 자료도 포함합니다.

압축을 읽지 못하는 서비스라면 ZIP을 풀어 작업서와 자료를 첨부하세요. ‘기존 TXT 방식으로 저장’은 이전 방식이 필요한 사람을 위한 보조 메뉴예요.

3 — 외부 AI에게 파일 번호대로 요청+

작업서와 자료를 첨부하고 “작업서대로 파일 번호순으로 처리하고, 각 결과를 JSON 파일로 내려받게 해줘”라고 요청하세요.

완료한 결과 파일을 하나씩 내려받아 보관하세요. 중간에 멈췄다면 완료한 번호를 확인하고 다음 번호부터 이어서 요청하면 돼요.

한 번의 답변으로 전부 끝나거나 다운로드 파일을 생성할지는 서비스마다 달라요. “끝났다”는 문장만 믿지 말고 내보낸 자료 묶음 수와 받은 결과 파일을 비교하세요.

4 — 결과 JSON만 ZIP으로 묶기+

AI가 준 결과 JSON들을 한 폴더에 모아 ZIP으로 압축하세요. 파일이 하나면 JSON 하나를 그대로 가져와도 됩니다.

입력 자료 JSON, 작업서, 설명용 TXT를 섞지 말고 결과 JSON만 담으세요. 같은 내보내기 작업의 파일끼리 묶는 것이 좋아요.

ZIP은 압축 전·후 각각 10MiB 이내여야 해요. 크면 결과를 여러 ZIP으로 나눠 순서대로 가져오세요. 암호화 ZIP이나 지원하지 않는 압축 방식은 풀어서 다시 압축해야 합니다.

5 — 검사·미리보기 후 새 버전 저장+

결과 가져오기에서 JSON 또는 ZIP을 선택하고 ‘결과 검사·미리보기’를 누르세요. JSON 텍스트를 직접 붙여넣는 방법도 있어요.

정상 묶음·오류·누락 범위를 확인한 뒤 ‘새 결과 버전으로 저장’을 누릅니다. 결과는 6 AI 문맥 정리의 해당 탭에서 볼 수 있어요.

검사는 파일 구조·시각·입력 연결 등을 확인하는 절차예요. 요약의 사실성까지 보장하지 않습니다. 빈 화면이나 비활성 버튼이 보이면 아래 오류 문구와 결과 형식을 확인하세요.

일부 파일 오류? 정상 결과부터 저장+

정상 결과가 있고 일부만 실패했다면 오류 위치를 확인한 뒤 ‘오류 묶음은 제외하고 정상 결과만 부분 저장’에 체크하세요.

정상 부분을 먼저 저장하고, 나중에 누락·수정된 결과를 추가하면 같은 외부 작업의 기존 정상 부분과 합쳐 새 버전으로 저장합니다. 이전 버전은 남아요.

중간에서 잘린 JSON은 완성된 파일로 다시 받아야 해요. 다른 VOD·다른 내보내기 작업의 ID를 임의로 바꿔 맞추지 마세요. 받은 결과가 전체 범위를 다루는지도 별도로 확인하세요.

같은 외부 작업 다시 열기+

외부 작업 목록의 ‘자료 다시 열기’로 저장한 내보내기 파일을 다시 받을 수 있고, ‘결과 보기’로 연결된 결과를 열 수 있어요.

입력이 그대로라면 같은 외부 작업의 누락 파일을 이어서 가져오세요. 전사·화자 입력을 바꾸려면 새로운 내보내기를 만드는 편이 안전해요.

기존 Gemma 결과, 원문, 수동 교정과 화자 배정을 덮어쓰지 않습니다. 외부 AI가 원문을 어떻게 이용하는지는 해당 서비스의 정책에 따릅니다.

처리 시간 확인과 개선 제보

자동 전송 없음. 보내고 싶을 때만 JSON을 메일에 첨부해요.

제보는 선택
내 PC에서 얼마나 걸렸는지 보기+

7 리포트에서 실행 기록을 선택하고 ‘리포트 새로고침’을 누르세요. 현재 PC와 그 실행 당시 PC 사양, 단계별 상태·시간·처리량을 확인할 수 있어요.

전사·채팅 수, 영상 길이, 계측 가능한 텍스트·토큰 양을 함께 봅니다. 같은 VOD라도 설정·모델·장치가 다르면 속도가 달라져요.

이 기능 도입 전 기록은 없을 수 있어요. ‘기존 결과 사용’이나 ‘미계측’을 새로 처리한 속도처럼 해석하지 마세요. 화면 예시는 실제 성능 측정이 아닙니다.

JSON에 담기는 것과 빠지는 것+

‘이메일 첨부용 JSON 미리보기’를 눌러 내용을 확인하세요. VOD 번호, CPU·GPU·RAM·운영체제, 앱 버전·옵션, 단계별 시간·성공/실패 코드, 처리량 등이 들어갑니다.

영상·음성·전사·채팅·요약 원문, 닉네임·화자 이름, 파일 경로·로그인 정보, 로컬 상세 로그는 이메일 첨부용 사본에 포함하지 않아요.

VOD 번호로 어떤 영상을 분석했는지는 알 수 있어요. “개인정보가 절대 없다”는 뜻은 아닙니다. 제출 전에 JSON 미리보기를 직접 확인하세요.

동의하는 경우에만 이메일로 보내기+

내용 제공에 동의한다면 ‘JSON 파일 저장’ 후 redpanyaday@gmail.com 으로 직접 첨부해 보내주세요. 제목에 VOD 번호와 간단한 증상을 적으면 도움이 됩니다.

보내주신 정보는 치다 분석기의 속도·안정성·오류 개선에 사용해요. 보내지 않아도 모든 분석 기능을 사용할 수 있습니다.

파일 저장이나 이메일 링크 클릭만으로 발송되지 않아요. 메일을 보내면 발신 주소·표시 이름도 전달될 수 있습니다. 원문·토큰·전체 로그는 첨부하지 말고, 삭제 문의도 같은 주소로 보내주세요.

막혔을 때 여기부터

에러를 없애려고 원본부터 지우지는 말아요.

ㄱㅊ 다시 가보자
버튼이 안 눌리거나 다음 단계가 막혀요+

현재 선택한 VOD, 앞 단계 완료 상태, 모델·도구 준비 상태를 확인하세요. 실행 중인 다른 작업 때문에 버튼이 잠겨 있을 수도 있어요.

메뉴 제목 끝의 💡를 누르면 해당 기능 도움말이 겹쳐 열립니다. 진행 상태·오류는 화면에 남으므로 문구를 먼저 읽어보세요.

앱은 데스크톱 배치를 유지합니다. 창이 좁으면 오른쪽·아래 요소가 화면 밖에 있을 수 있으니 창을 넓히거나 가로 스크롤을 확인하세요.

외장 폴더·등록되지 않은 자료 오류+

보관함은 전용 상위 폴더를 선택하세요. 폴더가 실제로 마운트됐는지, 쓰기 가능한지, 기존 vod-번호 폴더의 한 단계 위인지 확인합니다.

채팅 작업 DB는 내장 임시 공간에서 처리하므로 내장 여유 공간도 필요해요. 최종 저장에는 외장 디스크의 쓰기 권한과 공간이 필요합니다.

기존 보관함과 낯선 파일이 섞인 경우 무작정 삭제하지 마세요. 먼저 전용 빈 폴더를 선택하거나 상태를 확인하고 받은 원본·채팅을 보존하세요.

전사에 없는 말·반복 문장이 보여요+

무음·음악·잡음·겹침에서 전사 오류가 생길 수 있어요. ‘음성 듣기’로 실제 반복 발화인지 먼저 확인하고 필요한 문장만 교정하세요.

기본 발화 검출로 시작하고, 작은 말이 빠질 때만 민감 설정을 비교해보세요. 실제 반복 발화를 중복 오류로 단정하지 않는 것이 중요해요.

AI 요약도 오류 전사의 영향을 받습니다. 문맥 보완은 보조 수단이므로 인물·사건·부정 표현이 중요한 내용은 원음으로 확인하세요.

시간은 움직이는데 Safari 영상이 멈춰요+

일단 재생 버튼을 직접 누르거나 해당 VOD를 다시 열어보세요. 같은 자료가 Chrome에서는 재생되는지도 비교해보세요.

브라우저의 재생·탐색 처리와 영상 코덱 상태에 따라 차이가 날 수 있어요. 발생 브라우저, 시각, 오류 문구를 기록하면 원인 확인에 도움이 됩니다.

메뉴의 시각이 바뀌었다고 실제 프레임·음성이 재생됐다는 뜻은 아니에요. 재다운로드나 원본 삭제를 먼저 진행하지 마세요.

요약이 끝나지 않거나 결과가 이상해요+

처리 로그에서 진행 단계·재시도·실패 구간을 확인하세요. 마지막 문맥까지 보여도 후처리가 남을 수 있어요. 모델과 저장 공간, 선택한 입력도 확인합니다.

특정 부분만 실패하면 정상 결과부터 보고 이어하기·새 정리 또는 외부 AI 부분 가져오기를 사용하세요. 전체가 멈춘 경우 상태 문구와 발생 시각을 기록해요.

모든 오류를 채팅이나 화자 구분 탓으로 단정할 수는 없어요. 문의할 때 리포트 사본을 활용하고, 개인 자료나 인증 토큰을 공개 게시하지 마세요.

내 자료와 라이선스+

앱의 기본 분석은 내 컴퓨터에서 진행되고, 외부 AI 업로드와 리포트 메일은 사용자가 직접 선택해 실행합니다. 실행 주소는 로컬 브라우저용이에요.

자체 코드는 MIT이며 동봉 도구·모델은 각각의 라이선스가 적용됩니다. https://github.com/redpanya/Chi_Da_analyzer/blob/main/THIRD-PARTY-NOTICES.md

앱의 로컬 주소를 외부에 공유하거나 공유기 포트 포워딩으로 공개하지 마세요. 콘텐츠 권리·치지직 이용 조건은 별도이며, 실행 파일 재배포에는 외부 구성요소의 고지·대응 소스 의무도 확인해야 해요.
