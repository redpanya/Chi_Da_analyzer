01

처음 쓰는 분을 위한 빠른 시작

처음에는 한 방송의 짧은 구간으로 등록부터 결과 저장까지 따라 해 보세요.

목차
네이버 및 치지직과 관계가 있나요?

치다분석기는 스트리머와 클리퍼를 위한 독립 도구입니다. 네이버 및 치지직과 제휴, 후원, 공식 인증 또는 운영 관계가 없습니다. 서비스의 공식 앱이나 공식 설명서로 오해하지 않도록 이 안내를 먼저 확인해 주세요.

확인할 점앱은 이용자가 선택한 공개 다시보기와 제공 채팅을 이 컴퓨터에서 다루도록 돕습니다.

주의네이버, 치지직 및 각 서비스 표장은 해당 권리자에게 있습니다. 서비스 정책과 자료 이용 권리를 확인한 뒤 사용하세요.

첫 VOD로 댓글용 타임스탬프 만들기

① 설정 → 저장 폴더에서 보관함을 선택하고 Whisper와 Gemma를 준비합니다.
② VOD 등록에 주소를 넣습니다. 영상과 채팅, 원음 추출, 음성 전사, AI 문맥을 선택하고 AI 모드는 ‘빠른 타임스탬프’를 고릅니다.
③ 등록 확인에서 목록에 등록하고 ‘목록 시작 또는 이어가기’를 누릅니다.
④ 완료되면 보관함에서 방송을 열고 분석 → 타임스탬프 → 댓글 목록을 선택합니다. 원하는 줄의 ‘댓글 담기’를 누르고 ‘클립보드 복사하기’로 옮깁니다.

확인할 점예제처럼 15분만 해보려면 다운로드를 지정 구간 00:15:00~00:30:00으로 설정하세요. 댓글에는 원래 방송의 시각을 사용합니다.

방송 하나의 장면을 영상으로 저장하기

보관함에서 방송을 열고 분석 → 전사 자막 또는 클립 후보에서 ‘담은 클립’ 탭을 선택하세요. 원하는 줄의 ‘클립 담기’ → ‘클립 편집기 열기’를 누릅니다. 구간의 시작과 끝을 확인한 다음 저장 → 영상 생성 시작을 누릅니다.

확인할 점완료 후 ‘저장 폴더 열기’에서 만든 파일을 확인하세요. 직접 시간을 아는 장면은 클립 편집기의 ‘구간 추가’에서도 넣을 수 있습니다.

영상 나누기, 클립 만들기, 믹스클립 중 무엇을 쓸까요?

파일 한 개를 앞에서부터 여러 파일로 나누려면 왼쪽 ‘영상 나누기’를 여세요. 한 방송 안에서 장면을 골라 자막을 입히려면 해당 VOD의 ‘클립 만들기’를 쓰세요. 서로 다른 방송의 장면을 한 파일에 모으려면 각 방송에서 ‘믹스클립 보내기’를 누르세요.

확인할 점영상 나누기는 VOD 등록이나 전사가 필요 없습니다. 믹스클립은 같은 보관함에 담은 구간들을 함께 사용합니다.

자료는 어디에 저장되나요?

다운로드 영상, 채팅, 전사, 화자 구분, 요약과 클립은 설정한 로컬 보관함에 저장됩니다. 분석을 위해 선택한 모델도 설정한 모델 폴더에 내려받습니다.

확인할 점앱을 닫아도 보관함 파일은 남습니다. 외장 디스크를 쓴다면 작업 중 연결해 두세요.

주의외부 AI 파일 분석은 사용자가 직접 파일을 내보내 다른 서비스에 전달하는 별도 선택 기능입니다. 자동으로 외부 AI에 방송 자료를 보내지 않습니다.

02

설치와 앱 업데이트

공식 배포 파일을 받고, 사용하는 운영체제에 맞게 앱을 교체합니다.

목차
공식 배포 파일 받기

앱 저장소의 최신 Releases에서 macOS Apple Silicon용 DMG 또는 Windows x64용 압축 파일을 받습니다. https://github.com/redpanya/Chi_Da_analyzer/releases/latest

확인할 점다운로드한 파일 이름과 버전을 확인하고, Windows는 압축을 푼 폴더 안 실행 파일을 엽니다.

주의소스 코드 압축 파일은 설치 앱이 아닙니다. macOS 배포본은 Apple Silicon용입니다.

macOS에서 처음 열기

Apple Silicon Mac에서는 DMG를 열어 ChiDaanalyzer.app을 응용 프로그램 폴더에 복사한 뒤 복사한 앱을 실행하세요.

확인할 점이 배포본은 Apple Developer ID 서명과 공증을 받지 않았습니다. 처음 열 때 확인 메시지가 나오면 공식 릴리스에서 받은 파일인지 확인하세요.

Windows 포터블 앱 실행하기

Windows x64용 ZIP 전체를 쓰기 가능한 폴더에 압축 해제한 뒤 ChiDaanalyzer.exe를 실행하세요. 앱은 자체 창에서 열립니다.

확인할 점실행 파일과 함께 풀린 폴더를 같은 위치에 두세요. 앱을 끝내기 전에 진행 상태에서 작업 중인 방송을 확인할 수 있습니다.

앱 설정에서 업데이트하기

설정 → 앱 정보 → 앱 업데이트에서 ‘업데이트 확인’을 누릅니다. macOS는 ‘DMG 다운로드’로 원하는 폴더에 받은 뒤 앱을 종료하고 Finder에서 기존 앱을 교체합니다. Windows는 ‘포터블 업데이트 다운로드’가 끝나면 ‘교체 후 재실행’을 누릅니다.

확인할 점다시 연 앱 정보에서 현재 버전을 확인하세요. 브라우저 실행 화면에서는 ‘최신 배포’ 링크를 이용합니다.

보관함 폴더와 모델 폴더

왼쪽 아래 설정을 열어 보관함과 모델 폴더를 확인합니다. 보관함에는 VOD별 원본과 결과가 들어가고, 모델 폴더에는 내려받은 분석 모델이 들어갑니다.

확인할 점처음에는 여유 공간이 충분한 로컬 디스크를 선택하면 관리하기 쉽습니다.

주의경로 변경은 기존 파일을 옮기지 않습니다. 예전 자료를 계속 쓰려면 실제 파일이 있는 폴더를 지정해야 합니다.

화면과 메뉴 둘러보기

앱 왼쪽 메뉴에서 VOD 등록, 보관함, 진행 상태, 영상 나누기와 믹스클립으로 이동합니다. 왼쪽 아래 테마 버튼으로 밝은 화면과 어두운 화면을 전환할 수 있습니다.

확인할 점좁은 창에서는 일부 작업 메뉴가 현재 작업 메뉴 영역에 표시됩니다.

주의운영체제의 확대 설정에 따라 한 화면에 보이는 내용이 달라집니다.

라이선스와 사용설명서 찾기

설정 → 앱 정보에서 ‘사용설명서’ 또는 ‘라이선스 고지 열기’를 선택하세요. 동봉 도구, 내려받는 모델, 글꼴의 고지를 각각 확인할 수 있습니다.

확인할 점공식 릴리스의 첨부 파일에도 운영체제별 고지와 대응 소스가 있습니다.

03

모델과 실행 도구

하려는 작업에 필요한 항목만 공용 AI 모델 폴더에 준비하세요.

목차
기능별 필수 모델 고르기

설정 → 저장 폴더 → 모델 및 실행 도구를 엽니다. 말소리를 전사할 때는 음성 전사의 ‘(필수) Whisper’, 이 PC에서 AI 문맥을 만들 때는 ‘(필수) Gemma’를 설치합니다.

확인할 점영상 다운로드와 영상 나누기에는 이 두 모델이 필요 없습니다. 영상 처리용 FFmpeg와 ffprobe는 앱에 들어 있습니다.

Silero VAD와 sherpa 실행 도구가 필요한 경우

발화 검출을 ‘표준’ 또는 ‘민감’으로 설정하면 Silero VAD가 원음에서 말소리 구간을 골라 Whisper에 전달합니다. ‘끄기’를 고르면 전체 오디오를 전사합니다.

확인할 점자동화에서 발화 검출에 필요한 도구나 모델이 없으면 해당 단계에서 준비한 뒤 이어갑니다. 처음 실행할 때는 다운로드 시간과 여유 공간을 고려하세요.

화자 구분 엔진 고르기

기본 sherpa-onnx, pyannote Community-1, Apple Silicon용 FluidAudio 중 기기에서 지원되는 엔진을 고릅니다. ‘실행 도구’와 해당 ‘모델’의 준비 상태를 함께 확인하세요.

확인할 점Community-1을 처음 받을 때는 Hugging Face에서 모델 이용 조건에 동의하고 이 컴퓨터의 다운로드 인증을 준비해야 합니다. Windows의 pyannote는 CPU로 실행합니다.

설치 파일을 확인하거나 삭제하기

모델 및 실행 도구에서 ‘설치됨’, ‘일부 파일 있음’, ‘미설치’와 저장 용량을 확인합니다. 정리할 항목의 ‘삭제’를 누르고 이름을 확인하세요.

확인할 점삭제한 모델을 다음에 쓰려면 다시 설치합니다. 이미 저장한 전사와 분석 결과는 열 수 있습니다. 목록은 현재 선택한 공용 AI 모델 폴더 기준입니다.

주의사용 중인 항목은 관련 작업이 끝난 뒤 삭제하세요.

Windows에서 처리 장치 바꾸기

설정의 처리 장치에서 ‘CPU만 사용’ 또는 ‘CPU + GPU 가속 (Vulkan)’을 고르고 ‘적용’을 누릅니다. ‘GPU 다시 확인’으로 감지 결과를 볼 수 있습니다.

확인할 점변경은 다음 작업부터 적용됩니다. GPU 실행 중 실패했다면 CPU로 같은 단계를 다시 시도해 비교할 수 있습니다.

04

VOD 등록과 자동화

주소 입력, 처리 선택, 등록 확인을 거쳐 여러 방송을 처리합니다.

목차
새 VOD 주소 입력

왼쪽 VOD 등록을 누르고 공개 다시보기 주소를 붙여 넣습니다. 주소 입력칸 추가로 여러 항목을 만들고 위아래 버튼으로 처리 순서를 정할 수 있습니다.

확인할 점저장한 VOD 선택을 사용하면 이미 보관한 자료를 다시 목록에 넣을 수 있습니다.

주의서비스에서 접근할 수 없는 영상이나 제거된 영상은 가져오지 못할 수 있습니다. 주소를 여러 개 등록해도 서비스 접근 권한이 생기는 것은 아닙니다.

작업 단계 선택

처리할 작업 선택에서 영상과 채팅 다운로드, 원음 추출, 음성 전사, 화자 구분, AI 문맥 분석 중 필요한 단계를 체크합니다.

확인할 점처리 설정은 지금 새로 등록할 항목에 적용됩니다.

주의화자 구분은 선택 사항입니다. 화자를 건너뛰어도 전사와 문맥 분석을 진행할 수 있습니다.

분석 모드 고르기

AI 문맥에서는 빠른 타임스탬프, 상세 문맥, 클립 후보 모드를 원하는 조합으로 선택합니다.

확인할 점시간을 찾는 목적이면 타임스탬프, 장면 흐름을 정리하려면 상세 문맥, 편집할 구간을 찾으려면 클립 후보를 선택하세요.

주의결과는 입력한 전사, 채팅 범위, 선택 설정을 바탕으로 생성됩니다. 후보와 요약은 원본 장면을 확인해 판단하세요.

등록 전에 내용 확인

‘등록 확인’에서 방송 주소, 화질, 구간, 처리 단계와 AI 모드를 확인한 뒤 ‘목록에 등록’을 누릅니다. 등록된 VOD 아래의 ‘목록 시작 또는 이어가기’로 실행합니다.

확인할 점선택한 마지막 단계까지 끝난 방송은 등록 목록에서 빠집니다. 결과는 보관함 또는 진행 상태의 ‘완료 결과’에서 확인하세요.

대기 작업 수정과 일시정지

대기 설정을 바꾸려면 ‘대기 항목 설정 변경’에서 대상을 고른 뒤 ‘선택한 대기 항목에 설정 적용’을 누르세요. 한 항목만 중단하려면 ‘이 항목 중단’, 등록 목록 전부를 잠시 멈추려면 ‘목록 전체 일시정지’를 선택합니다.

확인할 점대기, 중단, 오류 또는 일부 완료인 항목은 목록에서 상태를 확인하고 이어서 처리할 수 있습니다.

기존 보관 자료를 이어 쓰기

보관함에서 VOD를 열고 필요한 후속 단계만 선택하거나 자동화 목록에 등록합니다.

확인할 점이미 완료한 다운로드와 처리 결과를 다시 사용할 수 있습니다.

주의입력 자료나 분석 설정을 바꿨다면 예전 결과가 새 입력을 반영하는지 확인하고 필요하면 다시 분석하세요.

방송 여러 개가 함께 처리되는 순서

같은 방송에서는 선택한 앞 단계가 끝나야 다음 단계로 넘어갑니다. 방송 A가 다운로드를 마치고 원음 추출이나 전사로 넘어가면 방송 B의 다운로드를 시작할 수 있습니다.

확인할 점다운로드는 한 번에 1개, AI 문맥 분석은 1개, 전사는 최대 3개입니다. 클립 저장과 영상 나누기는 이 개수에 포함되지 않습니다. 같은 파일을 변경해야 하는 작업은 먼저 실행된 작업이 끝날 때까지 기다립니다.

05

다운로드, 화질과 분석 범위

받아 둘 영상의 범위와 이미 받은 영상에서 분석할 범위를 각각 정합니다.

목차
화질과 전체 또는 지정 구간

작업 설정의 다운로드 항목에서 최대 화질을 선택하고 전체 영상 또는 지정 구간을 고릅니다. 구간은 시:분:초 형식으로 입력합니다.

확인할 점예를 들어 00:15:00부터 00:30:00까지를 지정하면 해당 구간을 중심으로 자료를 받습니다.

주의구간 경계와 수신 방식에 따라 지정 범위 밖의 영상 조각도 내려받을 수 있습니다. 선택한 화질은 최대 화질입니다.

채팅 자료 범위 이해

다운로드가 끝나면 영상과 서비스가 제공한 전체 채팅 상태를 각각 확인합니다.

확인할 점채팅 자료를 분석에 사용하면 반응 시점과 전사 내용을 함께 살펴볼 수 있습니다.

주의삭제되거나 제공되지 않은 메시지를 복원하지 않습니다. 일부 구간 경계를 검증하지 못한 자료는 화면에 표시된 주의 내용을 확인하세요.

전체 다운로드 뒤 부분 분석

VOD 화면에서 전체 또는 부분 분석 설정을 열고 분석할 시간 범위를 선택합니다. 분석에 필요한 음성 처리와 AI 모드를 정한 뒤 진행합니다.

확인할 점영상을 전체 보관하면서 분석량을 줄일 수 있습니다.

주의부분 분석은 구간별 결과를 만듭니다. 기존 전체 결과를 덮어쓰는 것으로 보지 말고 대상 범위를 확인하세요.

동시 다운로드 개수 1~32 설정하기

VOD 등록 → 처리 선택에서 ‘동시 다운로드 개수’를 입력합니다. 한 방송에서 동시에 받을 영상 조각의 개수이며 기본값은 1입니다. 전체 영상과 지정 구간 모두에 적용됩니다.

확인할 점HLS 조각이나 부분 요청을 지원하는 MP4에서 병렬로 받을 수 있습니다. 부분 요청 미지원이나 기존 단일 수신 이어받기에서는 한 연결을 사용할 수 있습니다.

주의숫자를 높여도 송신 서버, 네트워크, 저장 장치 여건에 따라 속도가 달라집니다.

수신 속도와 처리 배속 읽기

영상의 진행 표시에서 MB/초는 서버에서 데이터를 받는 속도입니다. 처리 배속은 자르기, 인코딩 등에서 실제 영상 길이를 얼마나 빠르게 처리하는지 나타냅니다.

확인할 점네트워크 수신이 끝난 뒤에도 구간 결합과 검사가 진행될 수 있습니다. 지정 구간의 경계를 정확히 복사할 수 없으면 재인코딩합니다.

받아 둔 영상을 다른 화질로 교체하기

자료 준비 → 영상/채팅에서 ‘다른 화질로 다시 받기’를 엽니다. 새 화질과 동시 다운로드 개수를 정하고 기존 영상을 보존할지 고른 뒤 ‘영상만 다시 받기’를 누르세요.

확인할 점새 영상이 검증된 뒤 교체됩니다. 채팅, 전사, 문맥 결과는 이어서 쓸 수 있습니다. 이전 영상도 필요하면 ‘기존 영상 보존’을 선택하세요.

진행 중 작업 이어가기

자료 준비 → 영상/채팅에서 영상과 채팅을 따로 확인하세요. 중단한 쪽의 ‘이어받기’를 누르면 저장된 자료를 확인한 뒤 진행합니다.

확인할 점지원되는 지정 구간 병렬 수신은 정상 조각을 재사용하고 실패한 조각을 다시 받습니다. 조건이 달라졌거나 서버가 부분 요청을 지원하지 않으면 단일 수신을 쓸 수 있습니다.

같은 방송을 다른 범위로 받기

전체 영상이 보관함에 있어도 지정 구간으로 다시 등록하면 구간 자료는 따로 관리됩니다. 저장한 자료를 고를 때 같은 VOD 번호라도 제목에 붙은 시간 범위와 화질을 확인하세요.

확인할 점같은 범위를 복구하려면 기존 항목에서 이어받기를, 화질만 바꾸려면 ‘다른 화질로 다시 받기’를 선택하세요.

06

보관함과 진행 상태

저장한 방송을 찾고, 현재 작업이나 중단 원인을 같은 화면에서 확인하세요.

목차
제목, 채널, VOD 번호로 찾기

보관함 검색창에 방송 제목 일부, 채널명 또는 VOD 번호를 넣습니다. ‘진행 중’, ‘확인 필요’, ‘저장된 자료’로 좁히거나 최근 작업순과 방송일 최신순을 바꿉니다.

확인할 점방송 행을 열면 선택한 VOD의 ‘준비’, ‘분석’, ‘작업’으로 이동할 수 있습니다. 목록이 비면 필터와 보관함 경로를 확인하세요.

자료 준비의 다섯 단계 읽기

선택한 방송에서 ‘1 준비’를 엽니다. 영상/채팅 → 원음 추출 → 음성 전사 → 화자 구분 → AI 문맥 순서로 각 행의 ‘확인’을 눌러 설정과 상태를 엽니다.

확인할 점원음 추출 완료는 WAV가 준비됐다는 뜻입니다. 글로 옮긴 결과는 음성 전사의 상태에서 따로 확인하세요. 화자 이름이 필요 없는 분석은 화자 구분을 생략할 수 있습니다.

문맥 사용 가능과 확인 필요 구분하기

‘문맥 사용 가능 (일부 확인)’인 방송을 열고 분석 결과를 확인하세요. 완료한 항목은 바로 사용할 수 있습니다. 중단 또는 일부 실패한 범위는 해당 결과 탭의 ‘결과 설정’에서 확인합니다.

확인할 점보관함 상태는 방송의 요약 표시입니다. 영상, 채팅, 원음, 전사가 어디까지 준비됐는지는 ‘준비’에서 단계별로 볼 수 있습니다.

작업 상세에서 최근 기록 읽고 이어가기

왼쪽 ‘진행 상태’에서 대상 방송의 ‘상세’를 누르세요. 오른쪽 패널에 현재 단계, 경과 시간과 최근 기록이 표시되며 열린 상태에서도 갱신됩니다. 중단 또는 실패한 작업에 이어하기 동작이 있으면 이 패널에서 실행합니다.

확인할 점완료한 자료는 재사용합니다. 외부 AI 항목은 결과 파일의 수신 현황을 보고 미수신 파일을 가져오세요. ‘결과 보기’가 있으면 저장된 결과를 열 수 있습니다.

등록 목록 제거, 믹스 구간 제거, VOD 삭제

등록 목록에서 제거하면 해당 등록 항목이 빠집니다. 믹스 카드의 ×는 그 믹스 구간만 뺍니다. 보관함의 방송 행에서 ‘삭제’를 누르면 확인 창에 대상 제목과 VOD 폴더가 표시됩니다.

확인할 점VOD 삭제를 확인하면 해당 폴더의 영상, 채팅, 전사, 분석과 편집 자료가 휴지통으로 이동합니다. 공용 모델과 폴더 밖으로 복사한 파일은 남습니다.

주의삭제한 방송을 참조한 믹스 구간은 원본을 다시 찾을 때까지 저장에 쓸 수 없습니다.

07

원음 추출과 음성 전사

원하는 오디오 트랙을 확인한 뒤 시간 정보가 있는 발언 목록을 만듭니다.

목차
원음 오디오 추출

준비 → 원음 추출에서 오디오 트랙을 고른 뒤 오른쪽의 ‘원음 추출’을 누르세요. 추출이 끝나면 같은 화면 아래 ‘추출한 음성과 저장 자료’에서 듣거나 WAV를 저장할 수 있습니다.

확인할 점게임 소리와 마이크가 각각 다른 트랙에 담겼다면 대화가 들리는 트랙을 고르세요. 한 트랙에 섞인 배경음은 추출한 WAV에도 들어갑니다.

전사 모델과 언어 설정

준비 → 음성 전사에서 전사 모델을 준비하고 음성 언어를 선택합니다. 발화 검출과 용어 힌트를 확인한 뒤 전체 전사 또는 이어받기를 실행하세요.

확인할 점고유명사가 자주 틀리면 실제로 등장하는 사람 이름이나 게임 용어를 짧게 넣으세요. 작은 목소리가 빠지면 발화 검출 ‘민감’과 기존 결과를 비교할 수 있습니다.

인명과 게임 용어가 반복해서 틀릴 때

전사를 시작하기 전 ‘용어 힌트’에 실제로 나올 이름, 게임 용어와 약칭을 500자 이내로 입력하세요. 이미 만든 전사의 한두 문장만 틀렸다면 해당 발언을 교정하는 편이 빠릅니다.

확인할 점힌트는 인식을 돕지만 올바른 표기를 보장하지 않습니다. 자막으로 쓸 장면은 원음과 비교하세요.

전사 검색과 영상 확인

분석 → 전사 자막에서 ‘전사 내용 검색’으로 발언을 찾습니다. 재생할 줄을 선택한 뒤 원음과 비교하고 ‘재생 위치 따라가기’로 재생 중인 발언을 목록에서 확인하세요.

확인할 점처리 중에도 완료된 조각부터 읽을 수 있습니다. 누락 또는 음성 인식 오류가 있는 범위는 음성 전사 화면에서 확인하세요.

잘못 인식한 이름이나 발언 고치기

전사 자막에서 발언의 ‘내용근거’를 누른 뒤 원음을 들어 보세요. 문구를 고친 뒤 ‘교정 저장’을 누르세요. 되돌리려면 ‘원문으로 복원’을 씁니다.

확인할 점이미 생성된 AI 요약을 바꾸려면 교정한 전사를 입력으로 골라 새 분석을 실행하세요. 클립 편집기에서 고친 자막은 그 편집 초안에 적용됩니다.

여러 결과 버전 관리

전사와 화자 화면에서 사용할 결과 버전을 선택해 비교합니다. 지울 버전이 맞는지 확인한 뒤 선택 버전을 정리합니다.

확인할 점기존 버전을 보존한 채 새 설정으로 다시 처리할 수 있습니다.

주의다른 분석 결과가 참조 중인 버전을 지우면 후속 활용에 영향을 줄 수 있으므로 사용 여부를 먼저 확인하세요.

08

화자 구분과 배정 검토

같은 사람의 발언을 묶고 싶을 때 선택하는 단계입니다.

목차
화자 구분은 필요할 때 실행

준비 → 화자 구분에서 엔진과 모델을 준비합니다. ‘전체 화자 구분’에서 참여 인원을 알면 입력하고, 자동으로 찾으려면 0으로 둔 뒤 화자 분석을 시작합니다.

확인할 점완료 후 해당 화자 분석 버전을 열면 화자 목록, 배정된 전사, 인식 실패에서 결과를 나누어 볼 수 있습니다.

화자 이름과 배정 검토

대표 음성을 듣고 화자 이름을 수정합니다. 인식 실패 항목은 직접 듣고 배정하거나 불명 상태를 유지합니다.

확인할 점화자 보정 후보는 검토를 돕는 제안입니다.

주의유사도나 자동 배정 결과를 동일인 확률로 해석하지 마세요. 이름 변경이 이전 AI 문장을 자동으로 고치지는 않습니다.

인식 실패를 한 묶음씩 정리하기

인식 실패에서 음성을 듣고 같은 사람으로 판단되는 항목을 배정하세요. 후보 묶음을 한꺼번에 배정할 때는 검색 범위와 대상 화자를 먼저 확인합니다.

확인할 점일괄 배정은 다른 페이지에 있는 해당 묶음에도 적용됩니다. 잘못 배정했으면 ‘마지막 변경 되돌리기’를 사용하세요.

여러 사람이 한 화자로 묶였을 때

배정된 전사에서 원음을 확인하고 시작과 끝을 지정합니다. ‘범위를 새 화자로 분리’하거나 대상 화자를 선택해 범위 배정을 저장합니다. 같은 사람이 두 화자로 나뉘었으면 대상과 합칠 화자를 확인한 뒤 합칩니다.

확인할 점범위 배정은 지정 시각과 겹치는 전사 행에 적용됩니다. 배정과 이름을 고쳐도 원음과 전사 본문은 보존됩니다.

09

분석 결과와 공통 시간축

목록에서 장면을 찾고 같은 시점의 영상, 전사, 채팅을 함께 확인합니다.

목차
분석의 네 목록에서 장면 찾기

선택 VOD → ‘2 분석’에서 전사 자막, 상세 문맥, 타임스탬프, 클립 후보를 전환합니다. 문맥 목록에서 제목이나 본문을 검색하고 ‘시각 찾기’에 HH:MM:SS를 입력하면 가까운 장면을 찾을 수 있습니다.

확인할 점결과 제목과 요약을 읽고 자세한 근거는 ‘내용근거’에서 확인하세요. 목록과 미리보기 사이의 경계선을 옮기면 다른 결과 탭에도 같은 너비가 적용됩니다.

결과 설정에서 이전 결과와 보류 사유 찾기

조회할 결과 탭을 먼저 선택하고 ‘결과 설정’을 여세요. 선택 결과의 버전, 처리 기록과 결과 안내를 확인하고, 사용할 수 있는 이전 버전을 골라 볼 수 있습니다.

확인할 점전사 근거가 부족해 보류한 채팅 반응이나 일부 실패 항목을 찾을 때도 이 패널부터 보세요. 다른 모드의 분석을 보고 있다면 먼저 탭을 바꾸세요.

통합 분석과 재생 열기

공통 시간축에서 전체, 30분, 10분, 2분 중 표시 범위를 고릅니다. ‘현재 위치’로 재생 지점에 맞추고 주변 채팅량, 반응과 선택한 AI 클립 후보를 비교하세요.

확인할 점‘재생 위치 따라가기’를 켜면 재생에 맞춰 표시 범위가 이동합니다. 다른 메뉴로 이동하면 재생이 멈춥니다.

채팅 반응 분석

저장한 채팅을 분석해 반응이 몰린 시점과 반응 후보를 확인합니다. 필요하면 채팅 경계 확인 안내와 분석 설정을 검토합니다.

확인할 점후보 시점을 영상과 전사에서 다시 열어보면 확인이 빠릅니다.

주의채팅 반응은 영상 내용에 대한 투표가 아닙니다. 인사, 별도 대화, 후원 등 다른 원인이 있을 수 있습니다.

채팅 반응 시각이 영상과 어긋날 때

원인이 분명한 반응 하나를 골라 실제 장면과 시각을 비교하세요. 채팅 시각 보정에 초 단위 값을 넣고 ‘보정 적용’ 뒤 이웃한 반응에서도 맞는지 확인합니다.

확인할 점반응지수는 같은 영상 안에서 강한 반응을 찾는 단서입니다. 웃음이나 채팅 급증의 원인은 앞뒤 대화와 화면에서 확인하세요.

클립 후보 검토하기

클립 후보에서 영상을 재생해 시작과 끝을 확인하고 내용근거에서 원문과 후보 이유를 확인하세요. 검토 필터에서 채택, 보류, 제외 또는 미검토 항목을 볼 수 있습니다.

확인할 점‘채택 담기’는 채택한 구간을 모을 때 사용합니다. 개별 장면만 담으려면 오른쪽 ‘담은 클립’ 탭을 선택하고 해당 줄의 ‘클립 담기’를 누르세요.

반응지수와 실제 장면 비교하기

상세 문맥이나 후보를 읽을 때 반응지수가 있는 결과라면 결과 설정에서 기준을 골라 목록을 좁힙니다. 반응이 올라온 시점 앞뒤를 재생해 방송에서 무슨 일이 있었는지 확인하세요.

확인할 점채팅이 제공되지 않거나 아직 반응 분석이 없으면 지수를 표시할 수 없습니다. 빈 지수를 반응이 없었다는 뜻으로 읽지 마세요.

로컬 AI 문맥 분석

같은 전사로도 시간표, 대화 요약, 편집 후보를 따로 만들 수 있습니다.

목차
빠른 타임스탬프

방송에서 다시 찾아볼 만한 시점을 짧은 제목과 함께 정리합니다. 결과를 눌러 영상과 대화를 확인합니다.

확인할 점긴 방송에서 검색할 시간대를 좁히는 데 쓸 수 있습니다.

주의시간표는 자동 생성 결과입니다. 실제 장면을 확인하고 필요한 시간을 직접 조정하세요.

상세 문맥 정리

상세 문맥 모드는 전사와 선택된 보조 자료를 바탕으로 대화 흐름과 맥락을 정리합니다.

확인할 점관심 구간을 선택해 원문을 확인하면서 결과를 검토합니다.

주의요약은 사실 확인이나 발언의 완전한 기록을 대신하지 않습니다. 중요한 표현은 원음과 전사에서 확인하세요.

클립 후보에 채팅을 함께 쓰기

클립 후보의 새 분석에서 사용할 전사를 고르고 ‘채팅도 후보 찾기에 사용’을 선택합니다. 채팅이 급증한 구간에서 어떤 말이 오갔는지 함께 탐색합니다.

확인할 점반응은 있지만 주변 전사가 없는 구간은 보류될 수 있습니다. ‘결과 설정’에서 보류 사유를, 후보의 ‘내용근거’에서 선택된 근거를 확인하세요.

분석 입력과 방송 상황 정하기

확인할 점예를 들어 타임스탬프 요청에 ‘각 제목을 한 줄로 짧게’라고 쓸 수 있습니다. 방송 상황은 세 모드가 공유하고 추가 요청은 모드별로 저장됩니다.

Gemma 사고 옵션과 새 분석 시작

이 PC에서 분석하려면 요약 모델 준비 상태를 확인하고 필요한 모드를 시작하세요. ‘사고 켜기’는 모델이 답을 만들기 전에 추론에 더 시간을 쓰도록 하는 선택입니다.

확인할 점처리량과 장치에 따라 시간이 달라집니다. 모델이 요약한 이름이나 발언을 인용할 때는 원문과 영상을 대조하세요.

이어하기와 새 버전 고르기

중간에 멈춘 분석은 해당 버전에서 ‘이 정리 이어하기’ 또는 클립 분석 이어하기로 남은 범위를 처리하세요. 다른 전사나 요청을 쓰려면 ‘새 분석’으로 시작합니다.

확인할 점이어하기는 처음 선택한 입력을 사용합니다. 이전 결과와 새 결과는 ‘결과 설정’의 입력과 버전 정보로 구분하세요.

댓글 목록과 담은 클립

오른쪽 탭을 먼저 고르면 왼쪽 목록에서 누를 담기 버튼이 바뀝니다.

목차
댓글 담기와 클립 담기 전환하기

분석의 네 결과 탭 어느 곳에서든 오른쪽 ‘댓글 목록’을 고르면 왼쪽 줄에 ‘댓글 담기’가 표시됩니다. ‘담은 클립’을 고르면 같은 자리에 ‘클립 담기’가 표시됩니다.

확인할 점한 장면을 두 곳에 각각 담을 수 있습니다. 이미 담은 줄은 ‘댓글에서 제거’ 또는 ‘클립에서 제거’로 바뀝니다.

댓글의 제목과 시작 시각 고치기

‘댓글 다듬기’를 열어 줄별 제목을 고치거나 시각 수정에서 시작 시각과 선택 사항인 끝 시각을 입력하세요. 채팅 반응 시각이 더 알맞으면 그 시각을 시작으로 지정할 수 있습니다.

확인할 점예를 들어 시작을 00:12:30으로 바꾸면 댓글 목록에서 해당 시각순으로 정리됩니다. 분석 결과의 원래 구간은 그대로입니다.

목록 구간 이어 재생하고 댓글 복사하기

‘목록 구간 이어 재생’으로 담은 구간만 차례로 본 뒤 ‘클립보드 복사하기’를 누르세요. 다시보기 댓글 입력란에 붙여넣고 제목과 시각을 읽어 본 뒤 직접 게시합니다.

확인할 점끝 시각을 비운 줄도 복사할 수 있습니다. 시작과 끝이 모두 있어야 그 줄을 이어 재생할 수 있습니다.

클립 담기 버튼이 비활성일 때

준비 → 영상/채팅에서 재생용 영상이 완료됐는지 먼저 확인합니다. 담은 클립 탭에서 ‘다시 불러오기’를 누르고 결과 버전이 현재 입력과 맞는지 확인하세요.

확인할 점저장 중에는 잠시 기다리세요. 이전 영상이나 전사에서 만든 항목은 입력 시각이 달라질 수 있으므로 현재 버전에서 장면을 확인한 뒤 담으세요.

외부 AI로 분석하고 결과 가져오기

보낼 자료를 직접 선택하고, 돌아온 결과를 검사해 새 버전으로 저장합니다.

목차
외부 AI 파일 분석

선택 VOD → ‘3 작업’ → ‘외부 AI 파일 분석’을 여세요. 입력 전사, 선택 화자와 결과 종류를 고릅니다. 타임스탬프는 전사를 사용하며 상세 문맥과 클립 후보에는 채팅을 포함할 수 있습니다.

확인할 점화자 이름을 익명으로 표시해도 전사나 채팅 본문에 이름이 남을 수 있습니다. 외부 서비스에 제공할 내용을 확인하세요.

작업서와 분할 JSON 보내기

‘분석 자료 만들기’를 누르고 ‘분할 JSON + 작업서 ZIP 저장’으로 받으세요. ‘요청문 복사’로 복사한 문구와 ZIP을 사용할 외부 AI에 직접 전달합니다.

확인할 점작업서.txt와 분할 입력 전체를 처리한 뒤 각 묶음에 대응하는 결과 JSON을 ZIP으로 돌려달라고 요청하세요. 앱은 계정 연결이나 업로드를 대신하지 않습니다.

결과 JSON 또는 ZIP 검사 후 저장하기

같은 방송의 외부 작업을 열고 ‘결과 가져오기’에서 결과 파일을 고르거나 JSON을 붙여넣습니다. 검사 미리보기에서 묶음 수와 오류를 보고 ‘새 결과 버전으로 저장’을 누릅니다.

확인할 점저장한 결과는 분석의 해당 탭에서 재생하거나 댓글과 클립에 담을 수 있습니다. 결과 파일은 압축 전과 후 각각 10 MiB 이내여야 합니다.

주의검사는 입력과의 대응, 시각, 파일 형식을 확인합니다. 분석 내용은 원본 영상에서 검토하세요.

몇 개 묶음만 돌아왔거나 검사에 실패했을 때

외부 작업 목록에서 수신한 묶음과 누락한 번호를 확인하세요. 부분 저장 옵션을 선택하면 정상 결과부터 저장할 수 있습니다. 미수신 묶음의 보완 ZIP을 받아 남은 작업을 요청하고 같은 외부 작업에 결과를 추가하세요.

확인할 점진행 상태의 외부 AI ‘상세’에서도 수신 상태를 확인할 수 있습니다. 외부 AI 서비스 안의 계산 시간이나 진행률은 앱에 표시되지 않습니다.

주의다른 방송 또는 다른 작업의 결과를 섞거나 식별 번호를 고치지 마세요.

한 방송의 클립 편집

구간을 고르고 화면과 자막을 다듬은 뒤 편집 초안이나 영상을 저장합니다.

목차
클립 편집 화면 열기

보관함에서 방송을 열고 작업 → 클립 만들기로 들어갑니다. 분석 중이라면 ‘담은 클립’ 탭에서 ‘클립 편집기 열기’를 누르세요.

확인할 점미리보기 아래 ‘담은 구간’에 이 방송에서 골라 둔 장면들이 표시됩니다.

직접 구간을 추가하고 시작과 끝 다듬기

구간 단계에서 기존 카드를 고르거나 ‘구간 추가’에서 직접 구간을 추가하세요. 시작과 끝을 입력하거나 영상을 멈춘 뒤 해당 칸의 ‘현재 시각으로’를 누르고 ‘구간 변경 적용’을 누릅니다.

확인할 점‘앞으로 5초’는 시작을 앞당기고 ‘뒤로 5초’는 끝을 늦춥니다. ‘원래 구간’으로 처음 범위를 다시 불러올 수 있습니다.

담은 구간의 순서 바꾸기와 제거

미리보기 아래에서 카드를 잡아 원하는 카드 앞이나 뒤에 놓습니다. ‘담은 구간 이어 보기’로 연결을 확인하세요. 한 구간을 빼려면 해당 카드의 ×를 누르세요.

확인할 점구간을 뺀 직후 ‘되돌리기’를 사용할 수 있습니다. 원본 영상이나 분석 목록의 발언은 지워지지 않습니다.

한 구간만 편집하거나 여러 구간에 프리셋 쓰기

카드를 선택하고 화면이나 자막을 수정하면 현재 구간에 반영됩니다. 같은 설정을 다른 구간에도 쓰려면 프리셋 단계 맨 위에서 ‘현재 구간’, ‘여러 구간 선택’, ‘담은 구간 전체’ 중 하나를 고르세요.

확인할 점적용 직전에 표시된 구간 제목과 개수를 읽고 프리셋을 적용하세요. 여러 구간 중 하나만 다른 디자인이어야 한다면 적용 대상에서 빼세요.

세로 영상에 게임과 얼굴을 함께 배치하기

화면 단계에서 세로 비율과 분할 배치를 선택합니다. 게임과 얼굴 영역을 각각 원본에서 잡고 위 게임 높이로 두 영역의 비율을 맞춥니다.

확인할 점미리보기에서 얼굴이 잘리는지, 게임의 중요한 글자가 남는지 확인하세요. 원본 전체가 필요하면 원본 비율을 선택하세요.

음량, 화면 효과, PNG 이미지 합성

화면 단계에서 색감과 음량을 듣고 조절합니다. PNG 이미지를 추가하면 위치, 크기와 투명도를 맞출 수 있습니다.

확인할 점PNG는 10 MB 이하로 준비하세요. 투명 배경을 쓰면 영상 위에 로고만 얹을 수 있습니다.

전사 자막 불러오기

자막 단계에서 전사 결과를 선택하고 현재 구간의 문장을 확인합니다. 자막 크기와 위치, 색상과 효과를 맞추고 미리보기를 재생해 두 줄로 넘어가는 긴 문장도 확인하세요.

확인할 점한 방송의 편집기는 같은 전사 버전을 기준으로 구간별 자막을 가져옵니다. 전사 원문을 고칠 때는 분석의 전사 자막을 이용하세요.

설치 글꼴을 고르고 자막 디자인 재사용하기

자막에서 언어와 글꼴, 굵기를 고르세요. 방금 설치한 글꼴이 보이지 않으면 ‘설치 글꼴 다시 불러오기’를 누릅니다. 테두리나 그림자처럼 반복해서 쓸 조합은 ‘템플릿 저장’으로 이름을 붙이세요.

확인할 점자막 템플릿에는 색상과 효과가 들어갑니다. 글꼴, 크기와 위치까지 여러 구간에 맞추려면 편집기의 프리셋 적용 대상을 이용하세요.

초안, MP4와 자막 파일 저장하기

편집을 이어 하려면 저장 → ‘편집 초안 저장’을 누릅니다. 영상이 필요하면 구간별 또는 한 영상 저장을 선택하고 ‘저장 공간 확인’ 후 ‘영상 생성 시작’을 누르세요. 자막 파일이 필요하면 SRT와 ASS 저장도 선택하세요.

확인할 점완료 후 ‘저장 폴더 열기’에서 파일을 찾습니다. ASS 자막의 글꼴과 효과는 불러오는 편집기에 따라 달라질 수 있습니다.

빠른 저장과 정확한 저장 고르기

원본 비율 그대로 구간을 따로 저장할 때 빠른 저장을 쓸 수 있는지 확인하세요. 자막, 효과 또는 정확한 시작 프레임이 필요하면 편집 내용을 반영하는 저장을 선택하세요.

확인할 점재인코딩을 생략하는 방식은 원본 키프레임의 영향을 받습니다. 짧은 구간이라면 만든 파일의 시작과 끝을 직접 재생해 보세요.

14

여러 방송을 섞는 믹스클립

서로 다른 VOD의 장면을 한 편으로 엮으려면 각 방송에서 구간을 보내고 믹스 편집기에서 순서를 정합니다.

목차
두 방송의 클립을 믹스로 보내기

① 첫 번째 방송에서 분석 → 담은 클립을 열고 장면을 담습니다. ‘믹스클립 보내기’를 누릅니다.
② 두 번째 방송도 같은 방법으로 보냅니다.
③ 왼쪽 주 메뉴의 ‘믹스클립’을 눌러 믹스 편집기를 엽니다.

확인할 점보낼 때 화면은 현재 방송에 머뭅니다. 방송별 담은 클립도 계속 사용할 수 있습니다.

믹스 카드의 순서 바꾸고 이어 보기

미리보기 아래 ‘믹스 구간’에서 카드를 잡아 원하는 위치에 놓습니다. 카드의 방송 제목과 구간 번호로 순서를 확인한 뒤 ‘믹스 순서 미리보기’를 누르세요.

확인할 점다른 카드를 선택하면 편집 단계는 유지되고 미리보기와 설정 대상이 선택한 구간으로 바뀝니다.

×로 믹스에서 한 구간만 빼기

‘믹스 구간’에서 뺄 카드의 ×를 누르세요. 현재 편집하던 카드를 뺐다면 다음에 표시된 카드 제목을 확인하고 작업을 이어갑니다.

확인할 점해당 구간은 이 믹스에서만 빠집니다. 그 방송의 ‘담은 클립’이나 이미 만든 영상 파일에는 영향을 주지 않습니다.

현재 믹스 구간과 프리셋 적용 대상 구분하기

구간의 길이, 화면과 자막을 직접 바꿀 때는 해당 카드를 먼저 고르세요. 여러 장면의 모양을 맞출 때는 프리셋 → ‘프리셋 적용 구간’에서 현재 구간, 여러 구간 선택 또는 믹스 전체를 선택하세요.

확인할 점대상 개수와 제목을 확인한 뒤 적용합니다. 클립 편집기와 프리셋을 함께 쓰지만 방송별 담은 목록과 믹스 목록은 따로 관리합니다.

방송마다 다른 자막과 화면 맞추기

카드를 옮겨 가며 자막 단계에서 해당 방송의 전사 결과를 확인하세요. 원본 비율이나 자막 위치가 다른 장면은 그 구간의 화면과 자막을 개별 조정하세요.

확인할 점같은 프리셋을 적용한 구간도 자막 문장과 원본 영상은 각 방송의 자료를 사용합니다.

컷 또는 디졸브로 한 영상 저장하기

저장 단계에서 구간 수와 순서를 확인합니다. 장면을 즉시 바꾸려면 컷, 앞뒤 장면이 잠깐 겹치며 바뀌게 하려면 디졸브를 선택합니다. ‘믹스 전체를 한 영상으로 저장’을 누르세요.

확인할 점다음에 편집만 이어 하려면 ‘믹스 편집 저장’을 사용하세요. 영상 생성이 끝나면 ‘저장 폴더 열기’에서 완성 파일을 찾습니다.

믹스에서 원본 영상을 찾을 수 없다고 나올 때

카드에 표시된 방송 제목을 확인하고 해당 보관함이 있는 디스크를 연결하세요. 보관함에서 해당 방송의 영상을 재생해 봅니다. 복구할 수 없는 구간은 믹스 카드의 ×로 뺀 뒤 저장하세요.

확인할 점이미 저장한 믹스 파일은 원본이 없어도 재생할 수 있습니다. 구간을 다시 편집해 새 영상을 만들 때는 해당 원본이 필요합니다.

15

영상 파일 나누기

파일 하나를 여러 조각으로 저장합니다. 반복 분할과 직접 분할점을 함께 쓸 수 있습니다.

목차
영상 나누기 시작

왼쪽 ‘영상 나누기’에서 원본 파일을 선택하세요. 불러온 영상의 길이와 오디오 트랙을 확인한 다음 분할점을 지정합니다.

확인할 점보관함 등록이나 전사는 필요 없습니다. MP4, M4V, MOV, MKV, WebM 파일도 내부 코덱에 따라 처리 가능 여부가 달라집니다.

시간 또는 재생 위치로 분할점 정하기

예를 들어 한 시간 영상의 중간을 나누려면 00:30:00으로 이동한 다음 ‘현재 위치에 분할점 추가’를 누릅니다. 일정한 길이가 필요하면 간격으로 분할점을 만든 뒤 개별 지점을 조정하세요.

확인할 점분할점 하나를 두면 두 파일이 생깁니다. 목록에서 시작과 끝, 지점의 수를 확인하세요.

요청 시각과 실제 분할 시각 비교하기

저장 전에 분할표에서 지정한 시각과 실제로 사용할 시각을 비교하세요. 재인코딩 없이 나누면 원본의 키프레임에 맞춰 경계가 달라질 수 있습니다.

확인할 점대사의 첫 음절까지 정확히 잘라야 한다면 클립 만들기에서 구간을 직접 정하고 정확한 저장을 사용하세요.

분할된 오디오와 출력 위치

‘미리듣기 트랙’으로 들을 소리를 확인한 뒤 ‘저장할 오디오’에서 출력에 넣을 트랙을 고르세요. 출력 폴더와 생성 예정 파일을 확인한 다음 분할을 시작합니다.

확인할 점미리듣기에서 고른 트랙과 파일에 넣는 트랙은 서로 다른 설정입니다.

중단 후 완료 파일 유지하고 다시 시도

같은 작업 화면에서 중단 사유와 완료 파일을 확인하고 ‘완료 파일 유지하고 다시 시도’를 누르세요. 끝난 뒤 ‘출력 폴더 열기’로 결과를 확인합니다.

확인할 점영상 나누기는 최근 작업 기록을 보관하지 않습니다. 앱을 다시 연 경우에는 원본과 출력 폴더를 직접 선택하세요.

16

실행 리포트와 오류 기록

특정 방송에서 어떤 작업이 끝났고 어디서 멈췄는지 확인한 뒤 공유할 자료를 고릅니다.

목차
VOD별 실행 리포트 확인

보관함에서 해당 방송을 열고 작업 → 결과 리포트 보내기 → 실행 리포트를 선택하세요. 작업 종류, 상태와 처리 시간을 확인하고 필요한 리포트를 저장합니다.

확인할 점실행 리포트는 이 VOD를 기준으로 합니다. 외부 서비스에서 파일을 분석한 시간까지 측정하는 기능은 아닙니다.

현재 방송의 오류 기록 확인

같은 화면에서 오류 기록을 여세요. 오류가 발생한 기능과 시각, 반복 횟수를 살피고 제보할 항목만 고릅니다. 기록이 필요하면 설정의 오류 진단 로그 저장 여부를 확인하세요.

확인할 점기록을 켜기 전의 오류는 소급 수집하지 않습니다. 비어 있으면 방송 선택과 기록 설정을 먼저 확인하세요.

첨부할 JSON을 보고 직접 보내기

‘첨부할 JSON 미리보기’를 열어 포함되는 항목을 읽고, 제공에 동의하는 경우 파일을 저장하세요. 제보하려면 저장한 파일을 메일에 직접 첨부합니다.

확인할 점로컬 상세 메시지와 제보용 사본의 내용은 다릅니다. 입력 내용이나 개인 정보가 있는지 첨부 전에 확인하세요.

17

자주 막히는 지점

화면에 나온 상태를 기준으로 다음에 확인할 곳을 찾으세요.

목차
작업이 대기인데 다시 시작해야 하나요?

진행 상태 → 상세에서 대기 사유를 읽으세요. 다른 방송이 다운로드 또는 AI 분석 중이거나 전사 세 자리가 차 있으면 해당 자리가 날 때 자동으로 진행됩니다. 같은 파일을 변경하는 작업도 먼저 작업이 끝나야 합니다.

확인할 점외장 디스크 연결 해제나 저장 공간 부족으로 중단된 경우에는 원인을 해소한 뒤 해당 작업만 이어가세요.

새 설정을 골랐는데 이전 분석 결과가 보일 때

분석의 결과 설정을 열어 선택한 결과의 전사 버전, 모드와 생성 시각을 확인하세요. 원하는 버전을 선택하고, 입력이 바뀌었다면 새 분석을 시작하세요.

확인할 점새 결과가 필요한 경우에도 기존 버전은 참고할 수 있습니다. 버전 삭제 전에 현재 보고 있는 결과를 확인하세요.

외장 디스크를 다시 연결했는데 보관함이 비어 있을 때

설정 → 저장 폴더에서 원래 VOD들이 들어 있는 보관함을 다시 선택하세요. 보관함 화면을 열고 새로고침한 뒤 VOD 번호로 검색합니다.

확인할 점설정한 모델 경로가 같은 외장 디스크라면 모델 목록도 확인하세요. 다른 빈 폴더를 선택한 상태에서 자료를 다시 받을 필요는 없습니다.

클립 저장이 시작되지 않을 때

저장 단계에 나온 사유부터 확인하세요. 담은 구간이 있는지, 끝 시각이 시작보다 뒤인지, 해당 영상이 재생되는지, 저장 공간이 충분한지 순서대로 확인합니다.

확인할 점믹스는 여러 방송의 원본을 읽으므로 문제가 표시된 카드의 방송을 먼저 확인하세요.

Windows에서 처리 도구가 종료되고 로그가 비어 있을 때

선택한 VOD의 실행 리포트 또는 오류 기록에서 실패한 단계, 시각과 종료 코드를 확인하세요. GPU 가속을 사용했다면 설정에서 CPU만 사용으로 바꿔 같은 단계가 진행되는지 확인합니다.

확인할 점제보할 때는 앱 버전, 작업 종류, 모델과 재현되는 조건을 적어 주세요. 종료 코드 하나만으로 메모리 부족이라고 단정하기는 어렵습니다.

다운로드와 로컬 분석에는 언제 인터넷이 필요한가요?

다시보기와 채팅을 받을 때, 처음 모델을 설치할 때, 앱 업데이트를 확인할 때 인터넷을 사용합니다. 영상과 모델이 준비된 후 로컬 전사와 문맥 분석은 이 컴퓨터에서 진행합니다.

확인할 점앱 자체를 쓰기 위해 공유기 포트를 열 필요는 없습니다. 외부 AI와 이메일 제보는 사용자가 내보낸 파일을 직접 전달할 때만 이뤄집니다.

재생 시각만 움직이고 화면이 멈춰 있을 때

준비 → 영상/채팅에서 재생용 영상이 완료됐는지 확인하고 원본 파일이 있는 디스크를 연결하세요. 지정 구간 자료라면 목록의 시각이 저장한 방송 범위에 들어 있는지도 확인하세요.

확인할 점원본을 재생할 수 있으면 결과 목록으로 돌아가 장면을 다시 선택하세요. 다른 화질로 교체하는 중에는 기존 영상의 준비 상태도 확인하세요.
