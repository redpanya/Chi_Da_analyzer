다시보기를 AI로 요약. 처음이라면 이 안내부터 차근차근 따라오세요. 기준: v0.18.0-preview.5 · 작성 2026-10-16

일단 읽어봐
이 앱이 하는 일+

치지직 다시보기나 내 비디오를 가져와 음성을 글로 바꾸고, 이야기별 요약과 시청자 반응을 함께 봅니다.

시간을 누르면 저장한 영상의 그 장면으로 이동합니다.

영상 장면 자체를 이해하는 분석이 아니라, 전사·채팅 텍스트 중심 정리예요.

가장 쉬운 루트+

가져오기 → 가져오기 진행 → 음성 전사 → 통합 분석·재생 → AI 문맥 정리 → 댓글 복사

화자 구분은 건너뛰어도 요약할 수 있어요.

첫 사용은 짧은 VOD로 익히면 부담이 적어요. 긴 영상의 처리 시간은 PC와 발화량에 따라 달라집니다.

1. 앱 준비+

설치와 준비: 내 운영체제에 맞는 ZIP을 풀고 앱을 엽니다.

앱 이름은 ChiDaanalyzer. 화면에서는 치 다 분석기로 보여요.

현재 사전 검증판입니다. 미서명·미공증 경고와 비공개 배포 제한을 ‘설치와 준비’에서 먼저 확인하세요.

2. 방송 가져오기+

영상 가져오기: 링크 또는 내 비디오를 선택하고 영상·채팅을 저장합니다.

왼쪽 저장한 VOD 목록에 방송이 추가됩니다.

채팅은 치지직이 현재 제공하는 범위만 받을 수 있습니다.

3. 말을 글로+

음성 전사: 원음 추출 → 전사 모델 준비 → 전체 전사 순서로 누릅니다.

시간이 붙은 대사 목록이 나옵니다.

자동 전사는 이름·외래어·겹친 말이 틀릴 수 있어요. 필요한 부분은 듣고 교정하세요.

4. 누가 말했지?+

화자 구분: 필요할 때만 사용합니다.

A화자·B화자를 실제 이름으로 바꿀 수 있어요.

사람 이름을 저절로 알아내는 기능은 아닙니다. 불명 화자는 그대로 두어도 돼요.

5. 반응 찾기+

분석과 재생: 채팅 반응 분석 후 검색어와 시간축으로 탐색합니다.

웃음·반복 표현·채팅 급증 구간을 찾습니다.

반응이 많다고 그 대사 때문에 웃었다고 확정하지는 않아요.

6. 요약과 댓글+

AI 문맥 정리 → 댓글 만들기 순서로 읽어주세요.

문맥별 제목·내용을 읽고, 고른 제목을 댓글용 시간표로 복사합니다.

치지직 댓글에 자동으로 등록하지 않습니다. 붙여넣기와 게시 여부는 직접 결정해요.

화면 읽는 법+

💡 = 설명 열기 / 회색 버튼 = 준비가 안 됐거나 다른 작업 중 / 진행 막대 아래 = 상태·시간

💡 창은 닫기 또는 Esc로 닫을 수 있어요.

스크린샷의 회색 버튼은 촬영 당시 전사가 진행 중이기 때문입니다. 화면 예시의 방송·진행 시간은 내 작업과 다를 수 있어요.

이 설명서 보는 법+

위에서 아래로 읽거나, 검색으로 궁금한 내용을 찾아보세요.

모든 설명은 처음부터 펼쳐져 있습니다. 필요하면 제목을 눌러 접을 수 있어요. 검색은 이 설명서 안에서만 작동합니다.

관련 화면을 해당 설명 바로 아래에 붙였습니다. 주황색 테두리·화살표가 조작 위치를 가리킵니다. 이미지는 클릭해 확대하고 Esc로 닫습니다.

내 자료는 어디에?+

영상·채팅·결과는 내 PC의 VOD 보관함, 공용 모델은 별도 AI 모델 폴더에 둡니다.

AI 처리용 모델을 받은 뒤 전사·요약은 로컬에서 진행합니다.

VOD·채팅·모델을 처음 받을 때는 인터넷이 필요해요. 이 HTML 설명서는 앱과 별개이며, 내 방송 자료를 읽거나 수정하지 않습니다.

01

설치와 준비

현재 배포는 비공개 사전 검증판입니다. 공개 출시판처럼 경고 없이 실행된다고 보장하지 않습니다.

설치 드가자
다운로드 위치+

관리자가 안내한 GitHub Releases에서 운영체제에 맞는 파일을 받으세요.
https://github.com/redpanya/Chi_Da_analyzer/releases

Mac: ChiDaanalyzer-macOS-arm64.zip
Windows: ChiDaanalyzer-Windows-x64.zip

비공개 저장소 접근 권한이 없으면 404처럼 보일 수 있어요. 관리자에게 배포 파일 또는 접근 권한을 요청하세요.

Mac 실행+

ZIP을 풀고 ChiDaanalyzer.app을 응용 프로그램 폴더로 복사한 뒤 실행합니다.

Apple Silicon Mac용입니다. 빌드 대상은 macOS 14 이상입니다.

Intel Mac용 파일은 현재 배포 대상이 아닙니다. 실제 확인된 OS 범위는 릴리스 안내를 따르세요.

Mac 경고가 뜨면+

배포 출처와 제공된 SHA-256을 확인하세요. 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 ‘확인 없이 열기’ 제공 여부를 확인합니다.

현재 임시 서명만 있고 Developer ID 서명·Apple 공증은 없습니다.

버튼이 없거나 ‘손상됨’ 경고가 계속되면 멈추고 관리자에게 알려주세요. 보안 기능 전체를 끄거나 앱 파일을 임의로 고치지 마세요.

Windows 실행+

ZIP 전체를 한 폴더에 풀고 그 안의 ChiDaanalyzer.exe를 실행합니다.

Windows 10/11 x64, AVX 지원 CPU가 필요합니다. 별도 Python 설치 없이 실행하도록 구성됩니다.

exe 하나만 바탕화면으로 옮기지 마세요. 함께 들어 있는 폴더·파일이 필요합니다. Windows 전자서명도 현재 없습니다.

브라우저가 열리면+

분석 앱이 자동으로 연 주소를 사용하세요. 앱 폴더의 index.html을 파일 탐색기에서 직접 여는 방식은 아닙니다. 이 HTML 설명서와는 별개예요.

주소가 127.0.0.1로 시작하면 내 컴퓨터에서 열린 앱 화면입니다.

포트·주소는 실행마다 바뀔 수 있어요. 예전 북마크보다 앱이 새로 연 화면을 사용하세요.

VOD 보관함+

1 가져오기 → VOD 보관함 폴더에 저장 위치를 넣고 ‘폴더 확인’을 누릅니다.

VOD마다 별도 폴더가 만들어집니다.
예시: Windows C:\VOD / Mac ~/Movies/VOD

새로 시작할 때는 비어 있는 전용 상위 폴더가 편해요. 영상·채팅·추출 오디오·결과까지 저장할 여유 공간을 확보하세요.

AI 모델 폴더+

공용 AI 모델 폴더 경로를 확인하고, 바꾸려면 새 경로 입력 → ‘경로 적용’을 누릅니다.

전사·화자·요약 모델을 여러 VOD가 같이 사용합니다.

경로 변경만으로 기존 모델이 이동하지는 않아요. 작업 종료 후 기존 모델을 복사해 옮기거나 새 위치에서 다시 준비하세요.

공간 감 잡기+

모델 외에도 영상 복사본·추출 WAV·분석 결과 공간이 필요합니다.

전사 모델 약 547MiB / Gemma 모델 약 4.98GB. 실제 화면의 요구량을 우선하세요.

로컬 비디오의 복사·호환 변환이 필요하면 원본 크기의 최대 3배 이상 공간을 준비하세요. 모델 용량과 작업 여유 공간은 별도입니다.

Windows GPU 옵션+

가져오기 → Windows AI 처리 장치에서 CPU만 사용 또는 CPU + GPU 가속 (Vulkan)을 선택합니다.

GPU 옵션은 전사와 Gemma 요약에 적용됩니다. CPU도 일부 연산을 처리해요.

지원 그래픽 드라이버가 필요합니다. 감지 실패·메모리 부족·오류가 생기면 CPU로 바꾸고 재시도하세요. 화자 구분에는 이 옵션이 적용되지 않습니다.

Mac AI 처리+

Mac에서는 지원되는 Metal 엔진을 사용합니다.

Windows의 CPU/GPU 선택 메뉴가 없는 것이 정상입니다.

GPU 사용량이 커지고 CPU가 낮아도 이상이라고 단정할 수 없어요. 계산 종류와 모델 배치가 다릅니다.

첫 모델 준비+

각 단계의 ‘모델 준비·검사’ 버튼으로 필요한 모델만 받습니다.

‘준비됨’이면 이미 받은 모델을 사용할 수 있습니다.

전사와 요약 모델은 서로 달라요. 화자를 건너뛰면 화자 모델도 꼭 받을 필요 없습니다.

업데이트·종료+

작업이 끝나거나 안전하게 중단된 뒤 앱을 종료하고 새 버전으로 교체합니다.

기존 보관함과 모델 폴더를 다시 선택해 사용합니다.

Windows에서는 브라우저만 닫아도 작업이 계속됩니다. 실행 창에서 Ctrl+C로 정리 후 종료하세요. 앱 폴더를 옮기는 것만으로 모델·자료까지 이사되지는 않아요.

02

영상 가져오기

1 가져오기 → 2 가져오기 진행. 영상과 채팅의 상태를 각각 확인해 주세요.

영상 모셔오기
링크로 받기 ①+

‘＋ 새 VOD 가져오기’ → ‘치지직에서 다운로드’를 선택합니다.

치지직 VOD 주소를 입력하는 칸이 보입니다.

치지직 다시보기 주소 또는 naver.me 공유주소를 사용할 수 있어요. 접근 가능한 공개 VOD를 준비하세요.

링크로 받기 ②+

주소를 붙여넣고 ‘정보 확인’을 누릅니다. 방송 제목·길이·저장 위치를 확인합니다.

원하는 방송인지 확인한 뒤 시작할 수 있습니다.

잘못된 방송이면 시작 전에 주소를 바꾸세요. 삭제·비공개·제공 종료 VOD는 가져오지 못할 수 있습니다.

링크로 받기 ③+

‘영상·채팅 다운로드 시작 →’을 누릅니다.

2 가져오기 진행에서 영상과 전체 제공 채팅을 각각 받습니다.

파일 수신 후 검사·재생용 준비가 이어질 수 있어요. 용량만 다 찼다고 완료는 아닙니다.

내 비디오 ①+

‘내 비디오 사용’ → ‘비디오 파일’에서 저장해 둔 영상을 고릅니다. 같은 방송의 치지직 VOD 주소도 입력합니다.

영상은 내 파일에서 복사하고 채팅은 연결한 VOD에서 받습니다.

원래 선택한 비디오 파일은 보존합니다. 로컬 파일만으로 치지직 채팅을 자동 추정하지는 않아요.

내 비디오 ②+

전체 영상이면 시작 시각 0. 잘라 둔 연속 구간이면 원래 VOD에서 그 구간이 시작된 초를 입력합니다.

예시: 원래 방송의 10분부터 시작하는 파일 → 600초.

같은 VOD의 연속 영상이며 중간 편집·배속 변경이 없다는 확인을 체크하세요. 여러 구간을 이어 붙인 편집본은 채팅 시간축이 맞지 않을 수 있습니다.

내 비디오 ③+

‘정보 확인’ 후 ‘비디오 복사·전체 채팅 받기 →’을 누릅니다.

현재 제공 채팅을 받고, 내 영상 범위에서 함께 탐색합니다.

재생 호환이 필요하면 별도 파일을 만들 수 있어요. 처음·중간·끝에서 영상과 채팅 시각이 맞는지 확인하세요.

완료 확인+

영상과 채팅 카드에 ‘완료’가 표시되는지 확인합니다.

‘음성 전사 →’로 이동합니다. 요약이 필요 없으면 ‘음성 건너뛰고 통합 분석 →’도 가능합니다.

영상·채팅 중 하나가 미완료면 해당 카드의 상태 문구를 먼저 읽어주세요.

중단·재개+

‘중단’ 또는 ‘모두 중단’ 후 정리를 기다립니다. 재개할 때 ‘이어받기’ 또는 ‘미완료 작업 이어받기’를 누릅니다.

완료된 자료를 유지하고 필요한 작업을 이어갑니다.

내 비디오 복사가 끊겼다면 동일 파일을 다시 첨부해야 할 수 있어요. 실행 중 VOD 폴더를 이동하거나 지우지 마세요.

전체 채팅의 뜻+

‘전체 제공 채팅’은 현재 서버가 제공하는 범위를 끝까지 확인했다는 뜻입니다.

삭제되거나 미제공된 채팅까지 복원한다는 뜻은 아닙니다.

‘검증 필요’는 경계 검사 상태를 확인해야 한다는 뜻이에요. 삭제 후 재다운로드보다 먼저 재시도·진단 안내를 확인하세요.

파일이 1개 또는 2개+

호환 MP4면 원본 하나로 재생·음성 추출을 함께 합니다. 필요할 때만 재생용 사본을 만듭니다.

원본 파일과 기존 결과를 유지합니다.

재생용 파일을 수동 삭제해 용량을 줄이면 연결이 깨질 수 있어요. 앱의 자료 관리 흐름을 이용하세요.

촬영 화면 안내+

가져오기·로컬 영상 입력·완료 확인 설명 바로 아래의 화면을 참고하세요.

진행 화면의 수치·방송 제목은 예시 자료의 실제 상태입니다.

전사 작업이 진행 중이라 일부 시작 버튼이 회색으로 촬영되었습니다. 다운로드 속도 예측값으로 사용하지 마세요.

03

음성 전사

음성 전사 = 말소리를 시간 정보가 있는 텍스트로 바꾸는 작업. 현재 신규 말소리 분리 단계는 없습니다.

말을 글로 쓱
시작 전+

영상 준비가 끝난 VOD를 고르고 ‘3 음성 전사’로 이동합니다.

원음 추출 / 전사 모델·언어 / 전사 옵션·시작이 보입니다.

다른 작업 중이면 버튼이 잠깁니다. 진행 상태를 확인하고 완료·중단 정리 후 시작하세요.

1. 원음 추출+

오디오 트랙을 고르고 ‘원음 추출’을 누릅니다. 하나뿐이면 기본 트랙을 사용하세요.

영상 시각과 무음을 유지한 WAV가 만들어집니다.

추출은 음성을 파일로 꺼내는 단계예요. 음악 제거·사람별 음성 분리는 하지 않습니다. 여러 트랙이면 방송 음성이 있는 트랙을 확인하세요.

2. 모델 준비+

‘전사 모델 준비·검사’를 누르고 준비 완료를 기다립니다.

Whisper large-v3-turbo 계열 모델을 사용합니다.

모델 준비는 첫 사용 또는 모델 누락 시 필요해요. 파일은 공용 AI 모델 폴더에 저장됩니다.

3. 음성 언어+

한국어 방송은 한국어를 먼저 사용하세요. 필요하면 자동 감지·영어·일본어를 선택합니다.

선택한 언어로 전사합니다.

자동 감지는 만능 번역 기능이 아닙니다. 혼합 언어·노래·고유명사는 원음 확인이 필요해요.

발화 검출: 표준+

처음에는 ‘표준 · 기본’을 사용합니다.

말이 있다고 판단한 범위를 중심으로 처리합니다.

작은 목소리나 노래는 빠질 수 있습니다. 누락이 보이면 다른 옵션으로 비교해 보세요.

발화 검출: 민감+

작은 말이 자주 빠질 때 ‘민감 · 작은 발화 포함’을 선택합니다.

작은 발화를 더 넓게 포함할 수 있습니다.

소음도 포함되고 처리량이 늘어날 수 있어요. 무조건 정확도가 올라가는 옵션은 아닙니다.

발화 검출: 끄기+

검출 없이 전체 오디오를 처리해야 할 때 선택합니다.

무음도 포함해 처리합니다.

처리 시간과 무음 구간에서의 잘못된 전사 위험이 커질 수 있어요. 기본 사용에는 표준을 권합니다.

용어 힌트+

방송에 실제 나오는 인물명·게임 용어를 짧게 넣습니다. 화면 기준 500자 이내입니다.

인식에 참고하는 힌트가 됩니다.

문장을 강제로 고치는 사전이 아니에요. 추측한 이름이나 너무 많은 힌트는 오인식을 늘릴 수 있습니다.

전체 전사+

‘원음으로 전체 전사·이어받기’를 누릅니다.

진행 막대, 경과 시간, 보존된 범위, 현재 조각 끝을 확인할 수 있습니다.

최대 20시간 입력을 지원하도록 구성되어 있지만 실제 시간·메모리 부담은 PC와 자료에 따라 달라요.

멈췄다 이어가기+

‘음성 작업 중단’으로 정리한 뒤 같은 설정에서 이어받습니다.

같은 설정으로 완료된 조각을 재사용합니다.

설정을 바꾸면 별도 결과로 처리될 수 있어요. 이전 전사와 수동 교정은 보존됩니다.

오타 확인·교정+

전사 내용에서 ‘음성 듣기’로 원음을 확인하고 ‘텍스트 교정’을 펼쳐 수정합니다.

원문과 교정 내용을 보존하며 현재 내용에 교정을 반영합니다.

반복 발화가 실제로 있었는지도 듣고 판단해 주세요. 시간 링크는 문장 구간 추정이며 단어 단위 정밀 정렬은 아닙니다.

검색·내보내기+

전사 내용 검색 또는 ‘현재 전사 내보내기 생성’을 사용합니다.

저장된 전사 목록에서 이전 버전도 확인할 수 있습니다.

교정 후 새 내보내기를 생성하세요. 예전에 저장한 파일이 자동으로 바뀌지는 않습니다.

04

화자 구분

요약만 보고 싶다면 이 단계는 패스해도 됩니다. 모든 불명 화자를 수동으로 정리할 필요는 없어요.

안 해도 됨
기능 이해+

음성 특징으로 화자를 나누고 전사의 시간과 연결하는 기능입니다.

A화자·B화자 같은 임시 구분이 만들어집니다.

전사 텍스트만 읽어 사람을 확정하는 방식은 아닙니다. 겹친 말·비슷한 목소리·짧은 발언은 실패할 수 있어요.

기본 배포 모델+

처음에는 sherpa-onnx를 사용합니다. ‘선택 모델 준비·검사’로 필요한 모델을 받습니다.

다운로드한 모델이 있으면 ‘바로 사용 가능 (오프라인)’ 안내가 나옵니다.

기본 ZIP은 sherpa 중심입니다. 개발 화면의 pyannote·FluidAudio 선택지가 모든 배포본에서 바로 실행된다는 뜻은 아니에요.

HF 로그인이 뜨면+

Community-1 계열을 별도로 준비하는 경우 Hugging Face 모델 페이지에서 이용 동의 후 로컬 인증을 완료해야 합니다.

모델 페이지: https://huggingface.co/pyannote/speaker-diarization-community-1

웹 로그인만으로 앱의 로컬 인증이 끝나는 것은 아닙니다. 계정·이용 동의는 본인이 진행하고 토큰을 채팅이나 공개 문서에 올리지 마세요.

모델이 이미 있으면+

준비 상태가 ‘모델 준비 완료 · 바로 사용 가능’이면 분석 단계로 넘어갑니다.

매번 로그인하거나 모델을 다시 받을 필요는 없습니다.

‘모델 있음’과 ‘실행 엔진 있음’은 다를 수 있어요. 엔진 누락 안내가 나오면 배포 안내를 확인하세요.

분석 시작+

전체 전사를 마친 뒤 ‘알고 있는 화자 수’를 입력하고 ‘화자 분석·이어받기’를 누릅니다. 모르면 0입니다.

0은 자동 추정. 분석은 조각별로 처리됩니다.

화자 수를 입력해도 분리가 완벽해지지는 않아요. 정확한 수를 모르면 억지로 지정하지 않아도 됩니다.

이름 붙이기+

화자 이름과 대표 음성에서 듣기 버튼으로 목소리를 확인하고 이름을 저장합니다.

같은 분석 버전의 동일 화자 전체에 이름이 적용됩니다.

새 분석의 A화자가 이전 분석의 A화자와 같다고 보장하지 않습니다. 버전이 달라지면 다시 확인하세요.

0개 발언?+

감지된 음성은 있지만 전사 행과 연결되지 않았을 수 있습니다. 대표 음성부터 들어보세요.

음성 구간과 배정된 전사 개수는 서로 다른 정보입니다.

0개가 곧 목소리 없음이라는 뜻은 아니에요. 삭제하거나 다른 사람으로 단정하지 마세요.

화자인식 실패+

‘화자인식 실패 · 듣고 배정하기’에서 원음을 듣고 대상 화자를 선택해 저장합니다.

배정한 발언은 아래 배정된 전사 목록으로 이동합니다.

모르면 그대로 남겨두세요. AI 요약은 화자가 불명이어도 내용 중심으로 사용할 수 있습니다.

묶음·후보 검토+

자동 후보 묶음이나 ‘필요한 구간만 · 음향·문맥 후보 검토’를 필요한 부분에 사용합니다.

후보는 제안이며 자동 확정하지 않습니다.

묶음은 동일인 확률 보장이 아닙니다. 여러 대표 음성을 듣고 일괄 배정 대상 개수·범위를 확인하세요.

저장·보존+

화자 분석 버전에서 이전 결과를 열 수 있습니다. 수정 후 ‘현재 이름·교정 포함 내보내기’를 다시 생성하세요.

기존 전사·수동 배정·이전 결과를 보존합니다.

인식 실패를 전부 해결하는 데 시간을 쓰기보다, 이름이 중요한 구간만 검토하는 방식이 편해요.

05

분석과 재생

통합 분석은 시간으로 찾아보는 화면, AI 문맥 정리는 이야기로 읽는 화면입니다.

여기저기 눌러봐
반응 분석+

‘5 통합 분석·재생’ → ‘채팅 반응 분석’을 누릅니다.

저장된 채팅에서 급증·반복 단어·ㅋㅋ·ㅎㅎ 등의 반응 후보를 찾습니다.

요약에서 🤩를 보고 싶다면 반응 분석 결과도 준비해 주세요.

일부 채팅만 있으면+

수집 범위가 일부인 경우 ‘일부 수집 자료로 분석 허용’을 선택할 수 있습니다.

확보한 범위로 분석합니다.

없는 채팅을 복원하지는 않습니다. 일부 범위의 결과를 영상 전체 반응으로 해석하지 마세요.

기준 조정+

기본 결과가 너무 많거나 적으면 ‘분석 기준 조정’을 펼쳐 확인합니다.

기준에 따라 반응 후보의 개수·강도가 달라집니다.

처음에는 기본값을 사용하고, 변경 전후 결과가 어떻게 달라지는지 영상으로 확인하세요.

통합 검색+

검색어를 넣고 ‘통합 검색’을 누릅니다. 검색 범위에서 전체 자료·반응 후보·채팅·전사·화자를 고릅니다.

해당 내용의 시각과 검색 결과가 나옵니다.

화자 분석이 없어도 채팅과 전사를 검색할 수 있어요. 반응 후보 보기·자료 새로고침도 활용하세요.

클릭해서 이동+

검색 결과·시간 표시·시간축을 클릭합니다. 직접 ‘이동 시각’에 HH:MM:SS를 입력해도 됩니다.

저장한 영상이 해당 위치로 이동합니다.

브라우저 자동재생 제한으로 바로 소리가 안 나면 재생 버튼을 눌러주세요.

공통 시간축+

초록은 채팅량, 금색은 반응, 발언 색은 화자, 주황은 인식 실패, 줄무늬는 미처리·미확인 범위입니다.

채팅과 대사가 어느 지점에 모이는지 볼 수 있어요.

빈 구간이 반드시 무음이라는 뜻은 아닙니다. 처리 범위 표시도 함께 확인하세요.

앞뒤 문맥+

앞뒤 문맥 10초·30초·60초를 고르거나 ‘재생 위치 따라가기’를 켭니다.

선택 순간의 채팅 원문과 발언을 함께 볼 수 있습니다.

요약 제목만 믿기보다 앞뒤 대사를 같이 보면 오해를 줄일 수 있어요.

재생·배속+

재생, 시작, 중간, 끝 3초 전, 배속 0.5~2배를 활용합니다.

빠르게 훑거나 중요한 장면을 천천히 확인할 수 있습니다.

이 화면의 시간 선택이 새 클립 파일 저장을 뜻하지는 않습니다. 현재 신규 구간 저장 기능은 제공하지 않습니다.

채팅 시각 보정+

일정하게 밀린 경우 ‘채팅 시각 보정’을 펼쳐 적용합니다. 양수는 뒤로, 음수는 앞으로 이동합니다.

앱의 이 탭·VOD에서 채팅과 반응의 표시 시각을 맞춥니다.

영상·전사 원본을 바꾸지 않습니다. AI 문맥 작업의 보정은 별도 설정입니다. 먼저 시작·중간·끝을 비교하세요.

채팅 저장+

아래 ‘채팅 내보내기’에서 JSON·CSV·TXT·JSONL을 선택합니다.

타임스탬프가 있는 채팅 파일을 저장할 수 있습니다.

다운로드한 원본 영상이나 채팅의 이용·공유 범위는 자료의 권한을 확인해 주세요.

06

AI 문맥 정리

Gemma 4 E4B 유지 · 대사 중심 기본 · 화자 구분 없이도 사용 가능. 원본 전사를 덮어쓰지 않습니다.

요약 드가자
입력 이해+

대화의 흐름은 전사 텍스트를 중심으로 정리하고, 채팅 반응 설명은 채팅 원문을 바탕으로 따로 정리합니다.

같은 이야기는 이어 붙이고 새 주제는 나눠 시간순 목록으로 보여줍니다.

화면 장면 자체를 보는 모델이 아닙니다. 전사에 없는 시각적 상황이나 정확한 발언자를 알아낸다고 보장하지 않아요.

시작 준비+

전체 전사를 완료하고 ‘6 AI 문맥 정리’로 갑니다. ‘요약 모델 준비·검사’를 누릅니다.

Gemma 4 E4B · 모델 준비됨 상태를 확인합니다.

전사 모델과 별도로 약 4.98GB 요약 모델이 필요합니다. 모델 저장 경로는 가져오기 페이지에서 확인하세요.

사고 켜기+

기본 ‘사고 켜기’를 사용합니다. 필요하면 끄고 새 정리 결과를 비교합니다.

체크 변경은 새 정리에 적용됩니다.

사고 모드는 내부 추론을 더 사용하므로 시간이 늘 수 있어요. 품질·속도 차이는 자료마다 달라 일정 배수로 보장하지 않습니다.

새로 정리+

‘전체 영상 새로 정리’를 누릅니다.

시간순 문맥 목록에 처리된 항목이 표시됩니다.

상위·하위 주제를 새로 나누는 방식은 아닙니다. 길이는 고정 1분이 아니라 이야기 흐름에 따라 달라져요.

진행 상황+

진행 막대 아래 경과 시간과 ‘처리 로그 열기’를 확인합니다.

로그를 접거나 펼쳐 현재 처리 상태를 확인할 수 있습니다.

완료된 항목부터 살펴볼 수 있어요. 아직 이어지는 이야기는 주제 전환·영상 끝에서 경계와 내용이 달라질 수 있습니다.

일부 요약 실패+

붉은 굵은 글씨의 ‘요약 실패’는 해당 항목의 정리가 실패했다는 표시입니다.

일부 항목 오류가 있어도 가능한 다음 구간을 계속 처리합니다.

디스크 부족·엔진 종료 같은 전체 실행 오류는 중단될 수 있어요. 완료 항목은 확인하고, 실패는 정상 요약처럼 사용하지 마세요.

중단·재개+

필요하면 ‘문맥 작업 중단’을 누르고 정리를 기다립니다. 재개할 때 해당 결과에서 ‘이 정리 이어하기’를 누릅니다.

이미 처리한 범위를 보존하며 이어갑니다.

이어하기는 그 결과에 저장된 모델·설정을 사용합니다. 새 설정을 적용하려면 새로 정리하세요. 모든 실패가 자동 복구된다는 뜻은 아닙니다.

문맥 읽기+

시간 범위 → 제목 → 내용 순으로 읽고 ‘이 구간 재생’으로 확인합니다.

원문·채팅·보완·생략·보류 근거를 펼쳐 볼 수 있습니다.

전사 오타를 앞뒤 대사로 보완하더라도 추론 오류가 남을 수 있어요. 인물·사건·부정 표현은 특히 원음을 확인하세요.

🤩 읽는 법+

문맥과 겹치는 반응의 상대 강도를 1~10개의 🤩로 표시합니다.

해당 VOD 안의 최고·최저 반응을 기준으로 하며 문맥 안 최고점을 표시합니다.

재미의 절대 점수·요약 정확도·원인 증명은 아니에요. 다른 VOD의 🤩 개수와 직접 비교하지 마세요.

반응 시각+

문맥에 표시된 반응 시각을 누르면 그 순간으로 이동합니다.

제목의 시작 시각보다 더 구체적인 반응 순간을 찾을 수 있습니다.

문맥 밖의 가까운 최고점은 인접 반응으로 표시될 수 있어요. 채팅 폭증은 도네이션·화면·외부 이슈 때문일 수도 있습니다.

반응 필터+

시간순 문맥 목록 위에서 ‘🤩 반응지수 → 3개 이상’처럼 선택합니다.

그 기준 이상인 문맥만 표시합니다. 전체를 고르면 실패·지수 없는 항목도 다시 보입니다.

필터로 숨겨져도 댓글 선택과 편집한 초안은 유지됩니다. VOD·결과 버전 변경 시 필터는 전체로 돌아갑니다.

이전 결과+

‘보존한 문맥 정리’에서 고르고 ‘선택 정리 열기’를 누릅니다.

기존 결과는 당시 방식과 설정으로 보존됩니다.

새 전사 교정·화자 이름 변경이 예전 요약 문장까지 자동으로 고쳐주는 것은 아닙니다. 필요하면 새 결과를 만들어 비교하세요.

07

댓글 만들기

체크 → 제목 다듬기 → 복사 → 치지직 댓글에 붙여넣기. 게시 전 원영상에서 시간을 확인해 주세요.

복붙 준비 완
1. 항목 선택+

시간순 문맥 목록에서 완료된 항목의 ‘댓글에 포함’을 체크합니다.

오른쪽 영상 아래 ‘댓글용 타임스탬프’에 선택한 항목이 시간순으로 모입니다.

처리 중·실패 상태를 완료된 요약으로 취급하지 않습니다. 먼저 재생해서 제목과 장면이 맞는지 확인하세요.

2. 제목 편집+

‘체크한 문맥의 시작 시각과 제목’ 입력칸에서 내용을 직접 고칩니다.

원래 AI 요약과 영상 재생 시각은 그대로이고 댓글 초안만 수정됩니다.

시간도 직접 바꾸면 장면 링크가 달라질 수 있어요. 가능하면 HH:MM:SS 형태를 유지하세요.

형식 예시+

00:03:20 첫 미션 시작
00:12:05 모두 웃었던 한마디
00:24:40 오늘 이야기 마무리

위 문구는 기능 설명을 위한 가상 예시입니다. 실제 방송 요약이 아닙니다.

제목은 짧고 구체적으로 다듬으면 읽기 편해요. 스포일러·인물명·오해할 표현도 게시 전에 확인하세요.

3. 복사+

‘클립보드 복사하기’를 누른 뒤 치지직 다시보기 댓글 창에 붙여넣습니다.

Mac ⌘V / Windows Ctrl+V로 붙여넣을 수 있습니다.

이 앱은 댓글을 자동 게시하지 않습니다. 치지직에서 내용과 공개 범위를 직접 확인해 게시하세요.

복사가 안 되면+

‘텍스트 전체 선택’을 누르고 Mac ⌘C / Windows Ctrl+C로 직접 복사합니다.

입력칸의 편집된 텍스트 전체를 복사합니다.

클립보드 권한이나 브라우저 제한으로 자동 복사만 실패할 수 있어요.

선택을 바꿨는데?+

직접 편집한 초안은 체크 목록이 바뀌어도 자동으로 덮어쓰지 않습니다.

작성해 둔 문구가 보호됩니다.

선택 목록과 초안이 달라질 수 있으니 복사 전에 최종 내용을 확인하세요. 필터로 숨겨진 선택도 남을 수 있습니다.

다시 만들기+

현재 선택 목록으로 처음부터 만들고 싶으면 ‘선택 목록으로 다시 만들기’를 누릅니다.

선택한 시작 시각·제목으로 초안을 새로 구성합니다.

직접 다듬은 내용을 유지하려면 먼저 따로 복사해 두세요. 새로 만들면서 편집 초안이 바뀝니다.

초안 보관+

댓글 초안은 VOD·요약 버전별로 이 컴퓨터에 저장됩니다.

같은 환경에서 다시 확인할 수 있습니다.

다른 PC나 브라우저로 자동 동기화되는 Google 문서가 아닙니다. 중요한 초안은 별도 문서에도 복사해 두세요.

내 비디오 주의+

잘라 둔 로컬 영상은 원래 치지직 VOD와 시작 시각이 다를 수 있어요.

댓글로 옮기기 전 실제 치지직 VOD에서 시각이 맞는지 확인합니다.

연결할 때 입력한 시작 시각이 정확한지도 점검하세요. 편집본이나 다른 VOD에 같은 시간표를 그대로 붙이지 마세요.

08

막혔을 때

삭제·재설치 전에 상태 문구를 읽고, 기존 자료를 유지한 채 복구하는 순서로 접근해 주세요.

막혔다고? ㄱㅊ
버튼이 회색+

같은 앱에서 진행 중인 다운로드·전사·분석이 있는지 확인합니다.

완료 또는 중단 정리 후 다시 확인하세요.

전사가 없으면 AI 요약을 시작하지 못하는 등 선행 자료가 필요한 버튼도 있습니다.

등록되지 않은 자료+

보관함 경로가 VOD 개별 폴더인지, 새 전용 상위 폴더인지 확인합니다.

처음 시작은 빈 상위 폴더, 기존 보관함은 등록 정보가 있는 기존 상위 폴더를 선택합니다.

비어 있는데 계속 오류가 나면 폴더 안을 무작정 지우지 말고 경로·버전·문구를 기록해 문의하세요.

영상 조치 필요+

영상 카드의 자세한 이유를 읽고 최신 배포본에서 ‘다시 시도’ 또는 ‘이어받기’를 실행합니다.

이미 받은 파일을 검사·복구할 수 있습니다.

‘재생용 영상 길이’ 같은 오류만 보고 원본을 삭제하지 마세요. 계속되면 media/probe.json과 오류 문구로 진단을 요청합니다.

채팅 검증 필요+

채팅 카드에서 재시도하고 제공 범위·경계 검사 상태를 확인합니다.

완료인지, 일부 수집인지, 확인이 필요한지 구분합니다.

계속되면 diagnostics/chat-audit.json의 진단값을 관리자에게 전달합니다. 공개 문의에는 채팅 본문이나 개인 경로를 불필요하게 올리지 마세요.

모델 준비 실패+

AI 모델 폴더의 쓰기 권한·여유 공간·인터넷 상태를 확인한 뒤 해당 모델의 준비·검사를 다시 누릅니다.

이미 받은 정상 모델은 재사용합니다.

HF 이용 동의·인증이 필요한 모델은 별도 절차가 있어요. 비밀번호나 인증 토큰을 문의 글에 넣지 마세요.

전사가 느려요+

진행률뿐 아니라 보존된 범위와 현재 조각 끝이 바뀌는지 확인합니다.

긴 영상·노래·많은 발화·CPU 처리에서는 오래 걸릴 수 있습니다.

작업 시간을 영상 길이와 동일하게 가정하지 마세요. 반복 시작보다 정상 중단 후 설정을 바꾸는 편이 안전합니다.

없는 말·오타+

문제 구간의 ‘음성 듣기’로 확인하고 텍스트 교정을 사용합니다.

원문을 유지하면서 교정 내용을 남길 수 있습니다.

발화 검출 끄기·과한 힌트는 오인식을 늘릴 수 있어요. 실제 반복 발화를 중복으로 단정해 모두 지우지 마세요.

화자가 자꾸 틀려요+

인물 확인이 필요한 구간만 듣고 배정합니다. 나머지는 불명으로 둬도 됩니다.

화자 미분석·불명 상태에서도 내용 중심 요약이 가능합니다.

겹쳐 말한 음성·짧은 대사·비슷한 음색을 완벽히 분리한다고 보장하지 않습니다.

요약이 멈춘 것 같아요+

진행 막대 아래 로그를 열고 현재 상태·오류·경과 시간을 확인합니다.

일부 실패는 목록에 표시하고 다음 구간을 처리합니다.

엔진 종료·메모리·디스크 오류면 원인을 해결한 뒤 해당 결과의 이어하기를 사용하세요. 자료를 삭제해 처음부터 시작할 필요는 없습니다.

🤩 항목이 없어요+

통합 분석의 채팅 반응 결과가 있는지 확인하고 반응지수 필터를 ‘전체’로 바꿉니다.

반응이 겹치지 않거나 지수가 없는 항목도 볼 수 있습니다.

🤩가 없다고 요약 실패는 아닙니다. 요약의 내용과 채팅 반응은 다른 정보예요.

시간이 안 맞아요+

영상의 처음·중간·끝을 비교하고 로컬 영상 시작 시각·편집 여부부터 확인합니다.

일정한 차이는 채팅 시각 보정으로 탐색을 맞출 수 있습니다.

점점 어긋나면 단순 초 보정 문제와 다를 수 있습니다. 통합 화면 보정과 문맥 작업 보정은 서로 별도입니다.

외장 드라이브+

작업 전에 연결하고 보관함·모델 경로가 맞는지 확인합니다.

드라이브 연결이 유지되어야 영상·모델을 읽을 수 있습니다.

작업 중 분리하지 마세요. 재연결 후 경로가 바뀌었다면 가져오기에서 확인합니다.

백업·삭제+

백업은 작업 종료 후 VOD 폴더 전체를 복사합니다. 삭제는 앱의 ‘VOD 삭제’에서 대상 번호와 안내를 확인합니다.

해당 VOD의 관련 자료를 휴지통으로 보냅니다. 공용 모델과 폴더 밖 원본은 별도입니다.

전사·수동 교정·요약까지 포함되는 삭제입니다. 영상만 지우는 버튼이 아니니 필요한 결과를 먼저 백업하세요.

문의할 때+

앱 버전 / Mac·Windows와 OS 버전 / 누른 버튼 / 오류 문구 / 발생 시각 / 화면을 정리합니다.

예: “0.18.0 / Windows 11 / 원음 추출 / 오류 문구 / 영상은 완료”

영상 전체나 계정 토큰보다 진단에 필요한 최소 정보를 먼저 주세요. 현재 PC 사용 상황도 알려주면 도움이 됩니다.

안내 기준+

설명과 화면은 앱 0.18.0, 배포 v0.18.0-preview.5 기준입니다.

설치 지원 범위와 실행 제한은 해당 버전의 릴리스 안내를 확인하세요.

전사·화자·요약의 품질과 처리 시간은 자료와 PC에 따라 달라요. 촬영 화면의 진행 수치를 내 작업 시간으로 예상하지 마세요.
